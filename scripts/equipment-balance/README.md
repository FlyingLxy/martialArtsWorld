## 当前精确预算合同

```text
T = 25000/153 ≈ 163.39869281045753
N60 = 10900/153
B60 = 4400/153
E60 = 5250/153
A60 = 2775/153
S60 = 1675/153
G60 = 14100/153
blueAffix60 = A60/4 = 925/204
blueBase60 = B60-blueAffix60 = 14825/612
```

60 级精品 +0 参考总预算为 100；终局期望预算为 T，装备占比 G60/T=56.4%，预算增长约 63.4%。各级 EP 池按 `B(L)/B60` 缩放；消费同级百分比／百分点价格时使用 `localEP=globalEP/r(L)`、`r(L)=P(L)/100`。显示小数不能反填常量，静态标价不等同于已证明的真实战力。

打造只放大白板。当前文档台阶为 `4%／6%／9%／457/4400`，满打造白板倍率 `193/88`；套装累计为 `S(L)×3/12、S(L)×7/12、S(L)`，混搭为 `S(L)×10/12`。属性单位与具体效果需在真实角色中复验。

## 后续获得模拟授权后的运行方式

以下仅说明已有命令，本轮没有执行。必须先同步规则差异并保存旧结果版本，再运行新规则验收：

```bash
npm run balance:equipment:v0.1
```

默认每品阶 100,000 组完整六槽打造。调试命令为：

```bash
EQUIPMENT_SIM_RUNS=1000 npm run balance:equipment:v0.1
```

当前脚本只有默认正式运行会覆盖 `v0.1-results.json`；设置 `EQUIPMENT_SIM_RUNS` 的调试运行仅输出终端。正式运行会核对批准的打造哈希、五档分位和两份公开文档中的历史结果行，任一漂移会在写文件前失败。后续更新不能通过随意放宽断言或改写批准值掩盖规则变化；应记录新版本、预期差异和输入哈希，保留可复查的历史快照。

经济标价仍为 `R(L,slot)=12×H(L)×slotShare(slot)`；H 是同级主动战斗每小时银两毛收入，市场成交价不参与打造计价。概率、掉级、怜悯、材料、公开保底及候选耐久规则以《装备与打造》为准，静态成本分位不能替代联合经济压力测试。
