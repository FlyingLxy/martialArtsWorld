# 装备数值校准 v0.1

这个目录保存装备系统的可复现数值校准资产，不是正式游戏运行时代码。它验证：

- 1～60 级分段成长、六槽 EP 和五品阶的白板／词条分账；
- 终局七类战力按 `63 + 37 + 48 + 20 + 12 = 180 EP` 精确闭合；
- 精品 `+0` 到神兵满打造的总战力与装备占比闭合；
- 打造四结果、隐藏怜悯、银两和四档材料的分布；
- 2／4／6 套装预算、单件升品上限、概率属性上限；
- 普通成品、定向紫橙的公开保底，以及候选耐久修理比例；
- 15% 冷却额外推进率在整数行动机会中的实际期望。

## 运行

```bash
npm run balance:equipment:v0.1
```

默认每个品阶模拟 100,000 组完整六槽打造，并覆盖每组的六件装备。调试时可降低样本数：

```bash
EQUIPMENT_SIM_RUNS=1000 npm run balance:equipment:v0.1
```

只有默认的 100,000 组正式运行会覆盖 [`v0.1-results.json`](v0.1-results.json)；通过
`EQUIPMENT_SIM_RUNS` 发起的调试运行只输出到终端，绝不覆盖正式快照。随机种子固定为
`20260905`；结果逐文件记录五份输入文档和模拟脚本自身的 SHA-256，并记录冷却模拟样本数，
便于发现“文档或算法改了但快照没重跑”。正式运行还会核对完整打造快照哈希、五档
P50／P90／P99 批准值以及两份公开文档中的结果行，任一漂移都会在写文件前失败。

## 口径

- `H(L)`：L 级标准玩家主动战斗每小时银两毛收入。
- `R(L, slot) = 12 × H(L) × slotShare(slot)`。
- `B(L)`：L 级六件精品 `+0` 装的总 EP。
- 60 级精品 `+0` 标准角色归一为 100 EP：非装备 63 EP，六件装备 37 EP（白板 32、六条期望蓝词条 5）。
- `affixRoll = 1` 的终局标准档案为 180 EP：等级／属性点／天赋精确为 `32.4／9／21.6`，装备白板／打造／词条／套装为 `37／48／20／12`；界面一位小数显示合计 100.1% 只是舍入现象。
- 神兵全词条 80%／120% 理论对齐边界为角色 176／184 EP、装备占比约 64.20%／65.76%；脚本以 66% 为实例极值护栏。
- 打造收益相对每件装备的 `+0` 白板加算，不能放大随机词条、套装、技能等级或特殊效果。
- 现有 `1200／112／42／100` 解释为 60 级精品 `+0` 标准角色，不再称作裸装。
- 打造的公开界面只展示基础概率和最坏掉级；连续失败使用隐藏怜悯，不展示计数。
- “单件升一品不超过 2%”按同等级、同套装、共同打造等级和期望词条滚值计算相对当前角色收益；120% 对齐高滚值另列诊断，不混进品阶期望门槛。
- 暴击率按 `1 EP = 2.50` 个百分点换算；六槽各一条暴击词条时，期望滚值提供 `+12.5pp`，六条 120% 对齐高滚值提供 `+15pp`。
- 修理档案按 60 场有奖励普通战斗／小时、每场全身耐久 `-1`、100 场无精英和死亡额外损耗计算；精英与死亡另做压力测试。

## 边界

本脚本完成的是基准曲线、预算和经济分布校准。它不会假装已经替代 750 构筑战斗模拟：装备技能等级、十套具体事件、四维换算和十派满装镜像仍要接入后续战斗模拟版本，才能通过最终上线硬关卡。
