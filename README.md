# 泡点江湖

仿 2000 年前后那种**文字江湖聊天室**的网页游戏——挂着页面就长功力，一屋子人一边泡点一边胡侃。

那类游戏（"江湖聊天室"／"文字江湖"，1997 年就有了，算是中国网页游戏的鼻祖）的招牌样子：
左上人物状态，左下各处房间和人数，中间大聊天室分上下屏，右边此地人物，底下一排虚拟动作。这里照着还原了一套。

## 开服

```bash
node server.js          # 或者双击「开服.command」
```

零依赖，不用 npm install。开起来后：

- 自己玩：<http://localhost:8080>
- 叫上朋友：开服时会打印局域网地址，也可以随时双击「查地址.command」看
- `Ctrl+C` 会存档再关服

给别人的地址有两种，**主机名那个更稳**（IP 是 DHCP 分的，换个网络或过几天就变）：

```
http://172.16.112.200:8080          ← IP，会变
http://你的机器名.local:8080         ← 主机名，不会变
```

**连不上最常见的原因是代理**。Clash／Surge 这类工具会把局域网地址也吃掉，尤其当你的网段不在它的例外列表里
（默认例外通常只有 `192.168.0.0/16`，而公司网络常是 `172.16.x.x`）。让访问的人打开「绕过局域网地址」，
或把 `172.16.0.0/12` 加进代理例外。另外确认 macOS 防火墙没拦（系统设置 → 网络 → 防火墙）。

## 存档

所有人共用服务端的一个 `data.json`，每人的角色按**名号 + 暗号**各自独立，换台机器、换个浏览器，
用同样的名号暗号登录就接着玩。写盘时机：每 30 秒一次、有人掉线时、贴告示／寄信／留影时立刻写、`Ctrl+C` 关服再写一次。

写盘是**原子**的：先写 `data.json.tmp` 并 fsync，再 rename 顶替，同时把上一份留成 `data.json.bak`。
所以断电或者 `kill -9` 都不会写出半截文件；万一主文件真坏了，下次开服会自动认出来并从 `.bak` 恢复
（终端里会打印"※ 主存档坏了，是从备份恢复的"）。最坏情况丢 30 秒进度。

**登录规则**：名号是唯一标识，名号 + 暗号对上就读回那个角色，换机器换浏览器都一样。暗号错会直接拒绝；
名号不存在时会先问一句"要新建吗"——因为老玩家把名字打错一个字的话，闷声建个新号会让人以为存档没了。

暗号只存 sha256，但局域网里走的是 HTTP 明文，**别用你在别处用的密码**。

头一回进的人随便起个名号和暗号，敲回车就算注册。存档在服务器的 `data.json`，每 30 秒自动写盘。

## 一个人也玩得下去

这套东西是特意补的——小服最常见的情形就是你一个人上线，而社交功能全指望"此刻还有别人在"：

- **衙门悬赏**：客栈找捕头接一桩，海捕文书上写明宰几只、在哪一带出没，够数回来领赏钱和打造材料
- **客栈告示板**：底下频道选「告示」贴一张，离线也留得住，新人进来能看见江湖上都发生过什么
- **书信**：给任何人写信，**对方不在线照样收得到**，还能随信捎银子；上线时会提示有几封未读
- **擂台留影**：在擂台留下自己的影子，**它会使你会的武功**，你不在时替你应战；别人挑了你的擂，战报会以信件送到你手上。打影子不输银子

所以一个人上线也有事做：看看有没有人回你的告示、有没有信、影子守擂赢了没、悬赏还差几只。

## 玩法

**泡点**是核心：**到了能修行的地方就自动开始**，每两秒长一次经验，**页面开着就一直涨，关掉就停**
（当年就是这个规矩，所以房间里才总有人）。打架时自动停，打完自动接着泡；换个地方也自动接着来。
想歇着就点「收功歇会儿」，换个地方又会重新开始。

| 去处 | 修行 | 门槛 |
|---|---|---|
| 悦来客栈 | 在客栈打杂听闲话 | 1 级 |
| 竹林小径 | 竹下盘膝打坐 | 5 级 |
| 后山瀑布 | 立于瀑下练功 | 15 级 |
| 本门后山 | 面壁参悟本门心法 | 30 级 |
| 塞北风雪谷 | 踏雪立桩 | 45 级 |
| 西域星宿海 | 观星吐纳 | 60 级 |

### 泡点

每 2 秒结算一跳，一跳能得 `场地基础值 × max(0.25, 1 − (你的等级 − 场地门槛) × 3.5%) × (1 + 悟性 × 2%)` 点——
等级超出场地门槛越多衰减越狠（最低剩两成半），所以到点就该挪窝。泡点时随机触发奇遇（捡钱、顿悟、走火入魔、遇高人）。

速度在界面上直接看：场景描述下面那行实时显示「每分钟约多少点 · 还差多少点 · 约多久升级」，
顶上「玩法」里有一张按你当前等级和悟性算好的各场地对照表。

### 门派与武功

3 级后去**山门**拜入五派之一，入门有属性加成，之后能上本门后山修行、学本门武功、下山械斗赚帮贡。**入了不能改**。

每派 **8 门**武功，门槛 3／8／15／22／30／40／48／60。前面的花银子学，40 级的**绝学**要 300 帮贡，60 级的**镇派绝技**要 600 帮贡（帮贡靠械斗攒）。
武功不只是伤害倍率，各有路数：

| 门派 | 路数 | 代表招 |
|---|---|---|
| 少林 | 硬打硬挨 | 金钟罩（两回合受伤减半）、狮子吼（震得对方一回合动不了）、易筋经（伤敌带回血） |
| 武当 | 借力打力 | 太极拳／太极剑（把挨的伤三成到五成还回去）、纯阳无极功（出招反涨内力） |
| 峨眉 | 快，连招 | 峨眉刺／飘雪穿云掌（有机会连出两招）、九阴白骨爪（吸走伤害三成补自己） |
| 丐帮 | 刚猛破防 | 缠字诀／亢龙有悔（无视对方大半防御）、降龙十八掌（暴击率大增） |
| 华山 | 招招见血 | 玉女峰剑／独孤九剑（必中，躲不开，且暴击极高） |

### 战斗

**默认自动**——遇敌自己打完，适合挂机刷怪。想认真打就点「改成自己出招」：每回合列出你会的招，看内力和场面挑一门，
**10 秒不点就替你出默认招**（威力最高的那门），不会卡住。切磋也一样，双方各按各的设置来，围观的人全程看得见。

### 掉落、行囊与打造

打怪除了银子，还有一成二的机会掉装备、三成五掉**精铁**，20 级往上的硬点子身上才有**玄晶**。捡到的东西进**行囊**（12 格，顶栏进），可以换上、扔掉，或者拿到长街摆摊卖。

**打造**要银子 **加材料**：+1 到 +4 使精铁，+5 往上非玄晶不可，越往上越贵、成算越低，+5 起失败还要掉一级，+9 封顶。所以想变强就得出门打怪——冒险和变强是连着的。

野外**寻敌**打怪（怪会按你的等级挑，不会让新手撞上越级的），洛阳**擂台**挑守擂高手（自己选对手，最高 68 级），**赌坊**押大小，**铁匠铺／兵器行**买兵器护甲。

**跟人玩**：左下角哪个房间人多就去哪儿（点一下直接到，不用一格格走）。右边点某人名字选中他，底下那排就对他生效——抱拳、敬酒、大笑、怒视、送花、打量、塞钱、悄悄话，以及**切磋**（在洛阳擂台下战书，对方应战就当场比试，满屋子人都看得见）。

聊天分频道：世界（全服）、本地（同一地方）、门派（同门）；悄悄话直接打 `/对方名字 要说的话`。
中间**上屏**是全服公共信息（聊天、打斗、公告），**下屏**只显示你自己的收益和私事。

## 文件

| 文件 | 说明 |
|---|---|
| `server.js` | 服务端：游戏逻辑 + HTTP + SSE 推送，零依赖 |
| `game-data.js` | 数据表：门派、武功、地图、怪物、装备、虚拟动作、数值公式（前后端共用） |
| `public/index.html` | 客户端：全部界面和交互 |
| `data.json` | 存档，开服后自动生成 |
| `solo-单机版.html` | 早期做的单机版，双击就能玩，不用开服，存档在浏览器里 |

想加东西基本都在 `game-data.js` 里：加个房间就往 `MAP` 里加一条，加门武功往 `SKILLS` 加，怪物在 `MOBS`，虚拟动作在 `ACTS`，升级和战斗公式在 `F`。

## 已知的取舍

- 必须开着页面才涨经验（离线不算），这是故意的——不然房间里就没人了
- 暗号在服务端只存 sha256，但整套东西是给自己人局域网玩的，没做防刷和限流，别直接挂公网
