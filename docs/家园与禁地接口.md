# 家园与禁地接口

> 状态：玩法框架已定；第4项价格、概率、数量与周帽推荐见[家园与禁地经济表](家园与禁地经济表.md)，均待评审与验证，不代表上线配置已通过。
>
> 用途：统一[家园系统](家园系统.md)与[禁地](禁地.md)之间的物品、时间、次数、结算和权限边界。
> 两篇文档出现重复描述时，以本文为准。第5项时间/断线与扣发边界分别以[时钟与断线恢复合同](时钟与断线恢复合同.md)、[资源事务与幂等合同](资源事务与幂等合同.md)为准；仍属待评审文档，未做断线或崩溃实测。

## 一、两套系统各自负责什么

- **大世界**：泡点、门派、任务、普通战斗和长期成长。
- **家园**：离线后勤、加工、展示和可选择的社交风险。
- **禁地**：有次数上限的主动单人试炼；本局选择只在本局生效。

家园不能变成更高效的泡点场，禁地不能变成无限材料矿。两者的互相导流只能通过有限的材料、消耗品、见闻和收藏完成，不能新增一条无限经验管。

两套系统的基础循环分别是：

```text
家园：回宅 → 领取离线产物 → 重新安排生产 → 整理携带物资 → 出门
禁地：入场整备 → 选路与战斗 → 管理局内资源 → 过层／撤出 → 结算收藏
```

家园的生产决策不要求玩家在线等待；禁地的决策发生在节点和战斗中，不与泡点同时运行。

## 二、物品分层

### 2.1 材料

所有矿石、草药、鱼类材料和禁地材料的数量，最终都记在玩家的材料账本 `p.mats`。家园库房只是材料的存放和操作界面，不复制一份独立数量。

- 未加工原矿可以暂存在矿袋、晒矿场或矿窖。
- 晒矿场是唯一可被偷的原矿位置。
- 精铁、玄晶、丹药和已经炼制的材料不可被偷。
- `mat` 产出是当地矿物、药材或伴生物，不是可以采集、封存或运输的“元息”。

### 2.2 消耗品

消耗品分为三类：

1. **大世界消耗品**：商店金疮药等，不能带入禁地。
2. **家园消耗品**：首批只有四菜，古墓每局食袋2份。药袋容量候选2份，但首批准入家园药目录为空，实际可带0；回气丹、止血散、解毒丸和药圃仍受D01限制，不因预留药袋自动开放。
3. **禁地临时补给**：用冥钱在禁地内购买，只在当前局有效，离开禁地立即消失。

家园消耗品进入禁地后仍然消耗真实库存，不会因为失败返还。这样家园能影响禁地准备，但不能用大世界商店药品绕过禁地的补给决策。

本轮使用候选：真实食物每日合计8份（大世界/古墓共享）、每局古墓最多2份、每战最多1份；局内两药合计每局最多6次、每战最多2次；单战所有消耗品合计最多2次，各占行动。未进入战斗时，恢复类物品只能在安全场景或古墓节点间使用，不能覆盖大世界风险场景持续损耗。首批具体库存、满仓和层主封存边界统一读取经济表。

### 2.3 本局状态

禁地的奇物、临时强化、冥钱和禁地补给全部存放在当前 `dungeon.run` 中，不进入玩家永久背包。禁地材料只有在结算时才进入 `p.mats`。

## 三、时间与刷新

- 作物、药圃和熔炉使用服务端时间戳，离线继续推进。
- 家园每日次数、钓鱼次数、挖宝次数、偷盗次数统一在每日 **5:00** 刷新，与日常任务一致。
- 禁地周次数和材料周帽在北京时间每周一05:00刷新；20级开放时初始化4次，之后每周补4、最多8。进入成功时扣次数，不因撤出、掉线或失败返还；跨周在途局材料仍扣入场period的周帽，不能换新周领取。
- 家园没有必须当天领取的奖励。作物成熟后保留 24 小时，之后只损失该格作物，不影响其他格子、库房和生产队列。

首批已经开放的作物与共享加工按服务端现实时间推进：到期只变为可收/枯萎或订单ready，领取才一次入账；不补离线泡点XP、银两、公共摸矿或日常有效秒。人在合法公共点修行而熔炉同时加工，在线修行仍独立按实际有效秒计算。后续药圃、钓鱼等沿首版范围表的待裁边界，不因本节列举时间规则而开放。

古墓断线冻结最多24小时，恢复**最后耐久行动检查点**，保留HP/MP、CD、节点、奇物、随机step和已用食物；旧“从本场开始重开”的描述不再适用。真实已用物资不退，未用食物锁在最终结算一次释放。明确SSE关闭/最后lease到期停止本局后续动作，静默断网按10秒在线观察边界；查询与重连不改冻结截止，明确续局才恢复。停服不补战斗回合，具体运行态、24小时到期、食物锁与入局周帽读取时钟合同§8。

## 四、禁地中的家园物资

进入禁地时增加一个“携带物资”步骤：

1. 选择本局奇物。
2. 从食袋、药袋中选择有限数量的家园消耗品。
3. 进入本层入口商店。

携带物资的上限按“每局槽位”计算，不按玩家拥有数量计算。局内补给仍可用冥钱购买；两者不共用数量，也不允许把禁地临时补给带出。

古墓入场不要求拥有家园、食物或家园药。浅探无票；深入/绝境各需摸金令1。首票可由40级后每周完成5份合法共享日常取得，无需先通浅探；兑换与持票上限读取经济表。免费预览只展示规则，确认后创建run、扣次数/票并锁种子，才展示实际5选2结果，不能取消重抽。

家园消耗品只提供恢复、解状态或一次性小幅辅助，不提供永久属性、不改变禁地地图种子，也不直接跳过层主机制。

## 五、生产与结算的共同规则

- 所有生产和奖励都必须明确“生成、存放、领取、消耗、失败”五个状态。
- 队列满时不能扣材料；开始生产后，原料立即扣除并锁定。
- 公共四项加工与家园精铁加工共用角色一个队列，家园不额外提供第二个并发炉；精铁同配方原矿3+木炭1+3两，30分钟必成，时间到后领取一次。
- 失败或撤出时，只按禁地结算规则处理当前局战利品，不回滚家园已经消耗的物资。
- 交易、雇工、偷盗和奖励发放都以一次事务完成，不能出现双方都保留物品的复制结果。
- 所有每日／每周上限必须明确是按角色、账号还是服务器；默认按角色，跨角色共享的方案另行拍板。

## 六、版本边界

### 家园 MVP

- 私宅场景、回宅与访客只读参观。
- 菜园、库房、一个熔炉队列。
- 基础原矿来源和原矿炼精铁。
- 展示架、宅院名和留言簿至少有一项非生产功能。

### 家园 MVP+

- 持竿钓鱼、宝箱、藏宝图和挖宝。
- 洛阳／河阴渡／万国码头的正式钓点。

### 后续

- 药圃、场景 `mat` 副产、多水域鱼种、矿窖、偷盗、雇工、NPC 入住和公共家园。

### 禁地第一版

- 乱葬岗古墓、三层节点图、三档难度、奇物、层主、撤出和断线续局。
- 禁地不依赖家园社交、钓鱼或公共家园才能通关；家园物资只是有限的备战选择。
