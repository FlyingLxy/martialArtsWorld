# 玩法与核心循环

其他文档回答的是"这游戏有什么"——世界观、战斗规则、装备数值、地图场景。
这一篇回答**"玩家上线之后干什么"**，以及各系统怎么咬合成一天、一周、一个月。

## 一、为什么需要这篇：一次实测

把已经设计的系统按各自文档的频次加起来：

| | 每天 | 每周 |
|---|---:|---:|
| 日常任务 5 次 | 12 分钟 | |
| 门派任务 | 8 分钟 | |
| 家园（种收、药圃） | 6 分钟 | |
| 钓鱼 | 10 分钟 | |
| 挖宝 5 次 | 8 分钟 | |
| 打造与洗词条 | 5 分钟 | |
| 市场摆摊采购 | 4 分钟 | |
| 主线推进 | 15 分钟 | |
| 禁地 4 次 | | 60 分钟 |
| 秘境 | | 90 分钟 |
| 帮派械斗 | | 40 分钟 |
| **合计** | **68 分钟** | **190 分钟** |

**每天约 95 分钟主动操作。** 而[设计原则第一条](原则.md)写的是
"这游戏的核心是**待着**，不是玩着"。

十来个有工作的朋友，每天 95 分钟的必做清单，会先把人累走。
**每个系统单独看都合理，加在一起就变成了另一个游戏**——
这正是需要一篇统管全局的文档的原因。

## 二、定案：挂机本位，主动全可选

```
底层   泡点          挂着就涨，关掉就停，不需要任何操作
必做   ≤15 分钟／天   只有日常任务和门派任务
可选   想玩才玩       禁地 · 家园 · 钓鱼 · 挖宝 · 秘境 · 械斗 · 市场
```

**"可选"必须是真的可选。** 一个玩法只要不做就明显落后，它就不是可选的，
只是没写在必做清单上而已。守住这一点靠下面两条硬规则。

### 规则一：凡是限次的，一律可攒存，不清零

| | 每期发放 | 攒存上限 |
|---|---:|---:|
| 日常任务 | 5 次／天 | 15 次（三天量） |
| 禁地 | 4 次／周 | 8 次（两周量） |
| 挖宝 | 5 次／天 | 20 次 |
| 钓鱼 | 不限次 | — |

**重置制**：今天没做 = 永久损失 → 每天被追着跑 → 这就是 FOMO 的来源。
**攒存制**：今天没做 = 存着 → 周末一次补完 → **错过不损失，只是延后**。

这一条几乎单独决定了这个游戏对上班族友不友好。
出差一周回来还能补上，和出差一周回来永久落后一周，是两个游戏。

### 规则二：主动玩法产出横向，不产出纵向

主动玩法给的东西**不能是"不做就战力落后"的东西**：

| 给什么 | 例子 | 为什么可以 |
|---|---|---|
| ✅ 材料 | 矿石、草药、打造材料 | 可交易，不玩的人可以买 |
| ✅ 外观与称号 | 家园装饰、钓鱼纪录、禁地称号 | 不影响战力 |
| ✅ 故事与见闻 | 案卷、残页、隐藏对话 | 满足想探索的人 |
| ✅ 社交资本 | 帮贡、声望、串门 | 靠关系而非在线时长 |
| ⚠️ 装备与经验 | 禁地掉落、秘境奖励 | **必须压到"挂机也拿得到，只是慢"** |

对最后一档，沿用[经济与成本](经济与成本.md)的那把尺子：
**任何产出先问"这是泡点的几倍"，超过 5 倍就要警惕。**

## 三、四个时间尺度

| 尺度 | 玩家在做什么 | 设计职责 |
|---|---|---|
| **秒级** | 泡点 tick、一回合出招 | 手感 |
| **分钟级** | 一场战斗、一次打造、一次钓鱼 | 单次行为的爽点 |
| **小时级** | 一次上线：看看谁在、聊两句、清日常、挂上 | **社交发生在这一层** |
| **天级** | 日常、家园收成、市场挂单 | 明天还来的理由 |
| **周级** | 禁地、秘境、械斗、任务链推进 | 值得期待的高光 |
| **月级** | 升级、毕业装、主线章节 | 长期目标 |

**小时级是最重要也最容易被忽略的一层。** 这是个聊天室起家的游戏，
"上线看看谁在"本身就是玩法。所有主动内容都不该把人从公共频道拽走太久——
这也是[禁地](禁地.md)定成"一局一刻钟"而不是"一局两小时"的原因。

## 四、玩家动词表

玩家能做的全部事情，以及它们各自的定位：

| 动作 | 一次多久 | 类型 | 主要产出 | 必做？ |
|---|---|---|---|---|
| 泡点 | 持续 | 挂机 | 经验、少量银两 | 底层 |
| 打坐疗伤 | 30 秒 | 挂机 | 恢复 | — |
| 聊天／看谁在 | 随意 | 社交 | 关系 | 底层 |
| 日常任务 | 1~2 分钟／次 | 主动 | 银两、材料、帮贡 | **必做** |
| 门派任务 | 8 分钟 | 主动 | 帮贡 | **必做** |
| 打怪 | 十几秒 | 主动 | 经验、掉落 | 可选 |
| 切磋 | 1~2 分钟 | 社交 | 名次、乐子 | 可选 |
| 帮派械斗 | 40 分钟 | 社交 | 帮贡、声望 | 可选 |
| 打造／洗词条 | 数秒 | 主动 | 战力 | 可选但强 |
| 市场摆摊采购 | 数分钟 | 经济 | 银两、装备流通 | 可选 |
| 禁地 | 15 分钟 | 主动 | 材料、称号、故事 | 可选 |
| 秘境 | 定时 | 主动 | 材料、装备 | 可选 |
| 家园种收 | 数分钟 | 挂机为主 | 材料 | 可选 |
| 钓鱼 | 10 分钟 | 主动 | 材料、纪录 | 可选 |
| 挖宝 | 数分钟 | 主动 | 材料、故事 | 可选 |
| 串门／偷菜 | 数分钟 | 社交 | 材料、乐子 | 可选 |
| 任务链／主线 | 不定 | 主动 | 故事、解锁 | 可选 |

**必做只有两行。** 这是这份文档最重要的一张表——
以后任何人想再加一行"必做"，都要先来这里改，并说明为什么值得。

## 五、三种人的一天

设计要同时对这三种人成立：

**上班族（每天 20 分钟）**
```
早上   开着泡点去上班
午休   清 5 次日常（8 分钟）
晚上   挂上，聊两句，看看市场，睡前收家园
周末   把攒的禁地次数一次打完
```

**学生／闲人（每天 3 小时）**
```
全程泡点，中间穿插打怪、切磋、打造
禁地当天就打完，钓鱼挖宝随手做
在公共频道待着，是聊天室的主力
```

**周末玩家（一周上两次）**
```
攒了 15 次日常、8 次禁地，一次性清完
主线推两章，跟人切磋几场
不会因为工作日没上线而永久落后
```

三种人**都不会掉队**，只是节奏不同——这是攒存制换来的。

## 六、系统咬合图

```
        泡点 ────────────► 经验、少量银两
          │
          ▼
        等级 ──► 属性点 ──┐
                        ├──► 战力 ◄── 装备 ◄── 打造 ◄── 银两 + 材料
        天赋 ────────────┘                              ▲      ▲
                                                        │      │
        日常／门派任务 ──► 银两、帮贡 ───────────────────┘      │
        禁地／秘境／家园／钓鱼／挖宝 ──► 材料 ──────────────────┘
                                        │
        市场 ◄──────────────────────────┘   （不玩的人可以买）
```

**关键闭环**：材料有多个来源，且**可交易**。
所以不玩家园的人可以买矿，不打禁地的人可以买高阶材料——
这正是"可选"能成立的经济基础。若某种材料只能自产不能买，
产它的那个玩法就自动变成必做。

> 例外：[装备与打造](装备与打造.md)规定高档打造的稀有材料**买不到、只能自己打**。
> 这是有意为之的门槛，但也意味着**冲最高档打造的人必须玩禁地**。
> 这是唯一一处"可选变必做"，仅限终局追求，可以接受。

## 七、加新玩法前的三问

沿用[经济与成本](经济与成本.md)的三问，再加两条：

1. **它的产出是泡点的几倍？** 超过 5 倍就要警惕。
2. **它的银两出口在哪？** 只进不出的玩法一律不加。
3. **它有没有上限？** 无上限产出必然被刷爆。
4. **它是必做还是可选？** 若是必做，第四节那张表要改，并说明为什么。
5. **它索取多少主动时间？** 加进第一节那张表重算，
   **每日必做总额不得超过 15 分钟**。

## 待拍板

1. **每日必做实测 20 分钟，超了 5 分钟。** 要么日常 5 次压到 8 分钟内完成，
   要么把门派任务并进日常那 5 次里（做门派日常也算日常次数）。倾向后者。
2. **禁地攒存 8 次会不会太多？** 一次性打 8 局是两小时，
   跟"一局一刻钟"的轻量定位冲突。或许攒存上限设 6。
3. **秘境是定时开放的，天然无法攒存**，这跟规则一冲突。
   要么接受它是唯一的例外（错过就错过），要么给"补办门票"。
4. **离线泡点做不做？** 现在是"关掉就停"。若做离线收益，
   挂机本位会更彻底，但也会削弱"上线看看谁在"这一层社交。
