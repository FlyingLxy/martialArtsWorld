# 玩法与核心循环

其他文档回答的是"这游戏有什么"——世界观、战斗规则、装备数值、地图场景。
这一篇回答**"玩家上线之后干什么"**，以及各系统怎么咬合成一天、一周、一个月。

## 一、为什么需要这篇：一次实测

把已经设计的系统按各自文档的频次加起来：

| | 每天 | 每周 |
|---|---:|---:|
| 日常任务 5 次 | 12 分钟 | |
| 门派任务 | 8 分钟 | |
| 家园（种收、药圃） | 6 分钟 | |
| 钓鱼 | 10 分钟 | |
| 挖宝 5 次 | 8 分钟 | |
| 打造与洗词条 | 5 分钟 | |
| 市场摆摊采购 | 4 分钟 | |
| 主线推进 | 15 分钟 | |
| 禁地 4 次 | | 60 分钟 |
| 秘境 | | 90 分钟 |
| 帮派械斗 | | 40 分钟 |
| **合计** | **68 分钟** | **190 分钟** |

**每天约 95 分钟主动操作。** 而[设计原则第一条](原则.md)写的是
"这游戏的核心是**待着**，不是玩着"。

十来个有工作的朋友，每天 95 分钟的必做清单，会先把人累走。
**每个系统单独看都合理，加在一起就变成了另一个游戏**——
这正是需要一篇统管全局的文档的原因。

## 二、定案：挂机本位，主动全可选

```
底层   泡点          挂着就涨，关掉就停，不需要任何操作
必做   ≤15 分钟／天   只有日常任务和门派任务
可选   想玩才玩       禁地 · 家园 · 钓鱼 · 挖宝 · 秘境 · 械斗 · 市场
```

**"可选"必须是真的可选。** 一个玩法只要不做就明显落后，它就不是可选的，
只是没写在必做清单上而已。守住这一点靠下面两条硬规则。

### 规则一：凡是限次的，一律可攒存，不清零

| | 每期发放 | 攒存上限 |
|---|---:|---:|
| 日常任务 | 5 次／天 | 15 次（三天量） |
| 禁地 | 4 次／周 | 8 次（两周量） |
| 挖宝 | 5 次／天 | 20 次 |
| 钓鱼 | 不限次 | — |

**重置制**：今天没做 = 永久损失 → 每天被追着跑 → 这就是 FOMO 的来源。
**攒存制**：今天没做 = 存着 → 周末一次补完 → **错过不损失，只是延后**。

这一条几乎单独决定了这个游戏对上班族友不友好。
出差一周回来还能补上，和出差一周回来永久落后一周，是两个游戏。

### 规则二：主动玩法产出横向，不产出纵向

主动玩法给的东西**不能是"不做就战力落后"的东西**：

| 给什么 | 例子 | 为什么可以 |
|---|---|---|
| ✅ 材料 | 矿石、草药、打造材料 | 可交易，不玩的人可以买 |
| ✅ 外观与称号 | 家园装饰、钓鱼纪录、禁地称号 | 不影响战力 |
| ✅ 故事与见闻 | 案卷、残页、隐藏对话 | 满足想探索的人 |
| ✅ 社交资本 | 帮贡、声望、串门 | 靠关系而非在线时长 |
| ⚠️ 装备与经验 | 禁地掉落、秘境奖励 | **必须压到"挂机也拿得到，只是慢"** |

对最后一档，沿用[经济与成本](经济与成本.md)的那把尺子：
**任何产出先问"这是泡点的几倍"，超过 5 倍就要警惕。**

## 二之一、单轴问题：所有玩法都接到同一个出口

看第六节那张咬合图会发现一件事：**每一条路径最后都指向"战力"**。

```
泡点 → 经验 → 等级 ─────┐
任务 → 银两 ────────────┼──► 战力 ──► 打更高级的怪 / PVP 赢
禁地·家园·钓鱼 → 材料 ──┘
```

于是这个游戏只有一种"变强"，也只有两个用途：**打更高级的怪、切磋赢**。
玩法看着很多，动机只有一个——**这就是单轴**。

单轴的后果很具体：
- 战力落后的人做什么都没意思，因为唯一的尺子上他就是矮
- 不想打架的人**没有位置**，而这是个聊天室起家的游戏
- 所有系统互相替代（禁地和家园都产材料 → 只玩产出率高的那个）

### 病根不是玩法不够，是出口只有一个

零件其实都已经散落在文档里了——见闻录、称号、风云榜、留言簿、
收藏、图鉴、声望、纪录。但它们都是**挂在别的系统上的奖励**，
没有一个被当成独立的追求。**把它们提上来当终点，单轴就破了。**

### 五条平行的追求线

| 线 | 回答的问题 | 怎么积累 | 终点 |
|---|---|---|---|
| **战力** | 你多能打 | 等级、天赋、装备、打造 | 打得过、赢得了 |
| **名望** | 你是谁 | 事迹、称号、首杀、榜单 | 名字被人认得 |
| **见闻** | 你知道什么 | 见闻录、残页、隐藏对话、图鉴 | 集齐、看透真相 |
| **家业** | 你有什么 | 银两、家园、藏品、商路 | 富甲一方、宅子好看 |
| **人情** | 谁认你 | 师徒、结拜、帮派、串门、留言 | 一呼百应 |

**这五条不可互相折算。** 名望不能换战力，家业不能换名望——
一旦能换，玩家就会算出哪条最划算，五条又坍缩回一条。
（唯一允许的是**银两**，它本来就是通货，但银两只能买材料和服务，买不到名望和见闻。）

### 让它们成立的唯一机制：被看见

在十来个人的服务器上，**"被别人看见"就是回报**。
战力有排行榜，所以有人追；如果另外四条没有展示位，它们就等于不存在。

所以每条线都必须有明确的露出位置：

| 线 | 在哪被看见 |
|---|---|
| 战力 | 风云榜·战力 |
| 名望 | **名字旁挂称号**；风云榜·名望；事迹进[编年史](编年史.md) |
| 见闻 | 见闻录完成度可查看；风云榜·见闻 |
| 家业 | 家园可串门；市场挂单署名；风云榜·家业 |
| 人情 | 师承关系公开；帮派名册；留言簿 |

**具体做法：把「风云榜」从单一战力榜改成可切换的五榜**，
点某个玩家能看到他的「江湖名帖」——五条线一览。
这件事技术上极便宜（右栏已经有风云榜位置），
但它是五条线能不能立住的**唯一支点**。

### 名望线的具体设计：展示面是有地价的

**这是个聊天室游戏，名字是全游戏曝光最高的一块地。**
你发的每句话都带着它。按每天被看到的次数排序：

| 展示面 | 每天被看到 | 能放什么 | 地价 |
|---|---|---|---|
| **聊天里的名字** | 几百次 | 颜色、称号、前缀符号 | **最贵** |
| 此地人物列表 | 几十次 | 称号、当前状态 | 贵 |
| 登入／离开广播 | 每次上线 | 称号 + 一句自定义 | 中 |
| 风云榜 | 几次 | 名次 | 中 |
| 市场挂单署名 | 逛市场时 | 称号 | 低 |
| 江湖名帖（个人页） | 偶尔被点开 | 全部成就、事迹、收藏 | 低但容量大 |

**地价决定门槛**：聊天里的名字最贵，所以只有最难得的成就才配挂上去；
名帖容量最大但没人天天看，适合放全部记录。
**别把所有成就都往名字上堆**——满屏都是称号，等于都没有。

### 名字怎么变

三层，从便宜到贵：

| 层 | 内容 | 获得难度 |
|---|---|---|
| **称号** | 名字前后一段小字（灰色，不跟正文抢） | 大量成就都给 |
| **名字变色** | 名字本身换色 | 少数成就才给 |
| **前缀符号** | 名字前一个小记号（如首杀标记） | 极稀有／唯一 |

**但要守住一条：聊天室是用来读字的。**

- 颜色总数**控制在 6~8 种**，且必须在深浅两种主题下都清晰
- **不做闪烁、跑马灯、渐变**——它们会毁掉阅读
- 只变**名字**的颜色，正文一律保持默认色
- 称号用**灰色小字**，视觉上退到名字后面

一屏消息里如果一半名字在发光，那这个"面子"就通货膨胀了。
**稀缺才是面子的来源，不是特效强度。**

### 成就系统

成就是**名望的唯一来源**，也是把零散行为变成"事迹"的机器。四类：

| 类 | 例子 | 给什么 |
|---|---|---|
| **里程碑** | 钓满 100 条鱼、打造到高档、走遍所有场景 | 称号 |
| **首个** | 全服第一个满级、第一个通关绝境、第一个凑齐某套装 | **变色 + 前缀符号 + 进[编年史](编年史.md)** |
| **稀奇** | 子时在乱葬岗挂满两小时、连续大失败三次还继续打 | 称号（怪的、好笑的） |
| **长期** | 连续 30 天上线、单个场景累计挂满 100 小时 | 称号 + 名帖记录 |

四条原则：

1. **成就只给展示物，不给战力**（[原则十一](原则.md)）。
   一旦成就给属性，它就变成了必做清单。
2. **「首个」在十来个人的服里是永久的。** 这是最便宜也最有力的设计——
   一句"全服第一个"能被人记好几年，成本只是一行记录。
   **不要在清档后重置这类记录**，把它们写进编年史。
3. **稀奇成就要真的怪。** 它们的作用不是激励，是**制造话题**——
   有人在频道里问"你那个称号怎么来的"，这个成就就值了。
4. **不做成就点数总分。** 一旦有总分，五条线又被折算成一个数了。

### 养成：面子也可以自己经营

除了系统发的，还要有**自己动手弄的**（这才叫养成）：

| 玩法 | 内容 | 展示在哪 |
|---|---|---|
| **雅号** | 自己取一个号（如"独钓客"），花银两，且公示不可撞名 | 名字旁 |
| **兵器铭刻** | 给自己的武器命名，战斗日志里会报出来 | 战斗广播 |
| **名帖装饰** | 用收藏品、鱼谱纪录、家园快照布置个人页 | 江湖名帖 |
| **一句留言** | 上线广播里跟着的一句话，自己写 | 登入广播 |

这些都**不给任何属性**，纯粹是"我想让别人看到我是这样的人"。
在一个十人聊天室里，这件事的驱动力可能比战力更持久。

### 回到最初的样子

这个项目一开始要做的是"**一个像论坛的页面，能进到不同的地方有人在，
中间有个大聊天室**"。单轴化恰恰背离了它——
一个只有战力的江湖，人少的时候就只剩排行榜前三名还在玩。

## 三、四个时间尺度

| 尺度 | 玩家在做什么 | 设计职责 |
|---|---|---|
| **秒级** | 泡点 tick、一回合出招 | 手感 |
| **分钟级** | 一场战斗、一次打造、一次钓鱼 | 单次行为的爽点 |
| **小时级** | 一次上线：看看谁在、聊两句、清日常、挂上 | **社交发生在这一层** |
| **天级** | 日常、家园收成、市场挂单 | 明天还来的理由 |
| **周级** | 禁地、秘境、械斗、任务链推进 | 值得期待的高光 |
| **月级** | 升级、毕业装、主线章节 | 长期目标 |

**小时级是最重要也最容易被忽略的一层。** 这是个聊天室起家的游戏，
"上线看看谁在"本身就是玩法。所有主动内容都不该把人从公共频道拽走太久——
这也是[禁地](禁地.md)定成"一局一刻钟"而不是"一局两小时"的原因。

## 四、玩家动词表

玩家能做的全部事情，以及它们各自的定位：

| 动作 | 一次多久 | 类型 | 主要产出 | 必做？ |
|---|---|---|---|---|
| 泡点 | 持续 | 挂机 | 经验、少量银两 | 底层 |
| 打坐疗伤 | 30 秒 | 挂机 | 恢复 | — |
| 聊天／看谁在 | 随意 | 社交 | 关系 | 底层 |
| 日常任务 | 1~2 分钟／次 | 主动 | 银两、材料、帮贡 | **必做** |
| 门派任务 | 8 分钟 | 主动 | 帮贡 | **必做** |
| 打怪 | 十几秒 | 主动 | 经验、掉落 | 可选 |
| 切磋 | 1~2 分钟 | 社交 | 名次、乐子 | 可选 |
| 帮派械斗 | 40 分钟 | 社交 | 帮贡、声望 | 可选 |
| 打造／洗词条 | 数秒 | 主动 | 战力 | 可选但强 |
| 市场摆摊采购 | 数分钟 | 经济 | 银两、装备流通 | 可选 |
| 禁地 | 15 分钟 | 主动 | 材料、称号、故事 | 可选 |
| 秘境 | 定时 | 主动 | 材料、装备 | 可选 |
| 家园种收 | 数分钟 | 挂机为主 | 材料 | 可选 |
| 钓鱼 | 10 分钟 | 主动 | 材料、纪录 | 可选 |
| 挖宝 | 数分钟 | 主动 | 材料、故事 | 可选 |
| 串门／偷菜 | 数分钟 | 社交 | 材料、乐子 | 可选 |
| 任务链／主线 | 不定 | 主动 | 故事、解锁 | 可选 |

**必做只有两行。** 这是这份文档最重要的一张表——
以后任何人想再加一行"必做"，都要先来这里改，并说明为什么值得。

## 五、三种人的一天

设计要同时对这三种人成立：

**上班族（每天 20 分钟）**
```
早上   开着泡点去上班
午休   清 5 次日常（8 分钟）
晚上   挂上，聊两句，看看市场，睡前收家园
周末   把攒的禁地次数一次打完
```

**学生／闲人（每天 3 小时）**
```
全程泡点，中间穿插打怪、切磋、打造
禁地当天就打完，钓鱼挖宝随手做
在公共频道待着，是聊天室的主力
```

**周末玩家（一周上两次）**
```
攒了 15 次日常、8 次禁地，一次性清完
主线推两章，跟人切磋几场
不会因为工作日没上线而永久落后
```

三种人**都不会掉队**，只是节奏不同——这是攒存制换来的。

## 六、系统咬合图

```
        泡点 ────────────► 经验、少量银两
          │
          ▼
        等级 ──► 属性点 ──┐
                        ├──► 战力 ◄── 装备 ◄── 打造 ◄── 银两 + 材料
        天赋 ────────────┘                              ▲      ▲
                                                        │      │
        日常／门派任务 ──► 银两、帮贡 ───────────────────┘      │
        禁地／秘境／家园／钓鱼／挖宝 ──► 材料 ──────────────────┘
                                        │
        市场 ◄──────────────────────────┘   （不玩的人可以买）
```

**关键闭环**：材料有多个来源，且**可交易**。
所以不玩家园的人可以买矿，不打禁地的人可以买高阶材料——
这正是"可选"能成立的经济基础。若某种材料只能自产不能买，
产它的那个玩法就自动变成必做。

> **注意这张图只画了战力那一条线。** 另外四条（名望、见闻、家业、人情）
> 见第二之一节——它们不接进这张图，正是它们独立的意义。
>
> 例外：[装备与打造](装备与打造.md)规定高档打造的稀有材料**买不到、只能自己打**。
> 这是有意为之的门槛，但也意味着**冲最高档打造的人必须玩禁地**。
> 这是唯一一处"可选变必做"，仅限终局追求，可以接受。

## 七、加新玩法前的三问

沿用[经济与成本](经济与成本.md)的三问，再加两条：

1. **它的产出是泡点的几倍？** 超过 5 倍就要警惕。
2. **它的银两出口在哪？** 只进不出的玩法一律不加。
3. **它有没有上限？** 无上限产出必然被刷爆。
4. **它是必做还是可选？** 若是必做，第四节那张表要改，并说明为什么。
4b. **它喂给哪条线？** 五条线（战力／名望／见闻／家业／人情）至少要喂一条，
   且**不能只喂战力**——只喂战力的玩法，本质上是打怪的换皮。
5. **它索取多少主动时间？** 加进第一节那张表重算，
   **每日必做总额不得超过 15 分钟**。

## 待拍板

1. **每日必做实测 20 分钟，超了 5 分钟。** 要么日常 5 次压到 8 分钟内完成，
   要么把门派任务并进日常那 5 次里（做门派日常也算日常次数）。倾向后者。
2. **禁地攒存 8 次会不会太多？** 一次性打 8 局是两小时，
   跟"一局一刻钟"的轻量定位冲突。或许攒存上限设 6。
3. **秘境是定时开放的，天然无法攒存**，这跟规则一冲突。
   要么接受它是唯一的例外（错过就错过），要么给"补办门票"。
4. **名望线已展开**（称号／变色／前缀、成就四类、雅号铭刻名帖）。
   **见闻、家业、人情三条还只有框架**，要分别设计。
5. **颜色到底给几种、分别对应什么？** 建议 6~8 种，
   但要先确认深浅两主题下都可读。
6. **雅号允许改吗？** 不许改则取错了很难受；允许改则"名号"失去分量。
   或许"一年一次"或"改一次要很贵"。
