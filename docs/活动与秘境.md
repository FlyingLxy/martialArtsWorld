# 活动与秘境

参考 MU（奇迹）的三样经典设计，但**必须为文字挂机改造**，因为这游戏有两个硬约束：

- **战斗是 1v1 回合制，没有走位和群战**
- **在线人数是个位数**（照搬公会攻城，四个人上去会很尴尬）

## 一、秘境：定时 + 门票（建议最先做）

```
血池秘境
开放    每晚 20:30 – 21:00（平时左下角不显示，到点自动出现）
门票    血玉令 ×1（打怪掉碎片，5 片合成；或日常任务保底给一张）
玩法    进去后限时 15 分钟，怪一波波刷，杀怪计积分
结算    按积分排名发奖：帮贡、稀有材料、只有这儿掉的装备
```

**为什么这个优先级最高**：它把三样东西串成一条线——

```
打怪掉碎片（给刷怪一个理由）
   → 合成门票（给收集一个理由）
      → 定时开放（给上线一个理由）
```

而且**单人就能玩**，人多只是排行榜好看。不依赖在线人数，这对你们现在的规模很关键。

## 二、攻防战：随机分阵营

MU 的攻城是公会打公会，你们人少，改成**报名后随机分配阵营**：

```
洛阳攻防     每周六 21:00，持续 45 分钟
报名         开场前十分钟，人齐后随机分成攻 / 守，保证两边人数差 ≤ 1
攻方目标     打破三道城门 —— 所有攻方玩家的伤害累加到同一条血条上
守方目标     守住 —— 击退攻方、或"修补城门"回血
胜负         时限内破门 = 攻胜；守住 = 守胜
奖励         胜方全员帮贡 + 银两；败方减半（不空手）
彩头         胜方贡献最高者，名字挂城头一周，全服可见
```

**关键改造：不做真正的群战。** 技术上不重写战斗系统，而是
**共享一条血条 + 个人贡献计分**——所有人各打各的，伤害汇总到同一目标，
进度全服实时广播（「城门已破两成！」）。

在文字游戏里这个表现力其实更强：公共频道刷战报，比看血条更有临场感。

**随机分阵营**顺带解决了两个问题：人少时的阵营平衡、固定帮派之间的积怨。

### 人数不足怎么办

三个方案，选一个写进设计：

1. **自动降级**：报名不足 4 人，改成「守城演练」，单人也能打，奖励减半
2. **押后再做**：先做秘境，等在线人数撑得起来再上攻防战 ← **推荐**
3. **机器人补位**：用[江湖散人](江湖散人.md)凑人数

## 三、场景的时间窗

上面两样的技术前提：场景不再常驻，而是有开放时段。

```js
血池秘境: {
  name:'血池秘境', zone:'秘境',
  schedule:{ open:'20:30', dur:30 },   // 到点才出现在左下角
  ticket:'xueyuling',                  // 进门扣一张
  instance:true,                       // 进去的人共处一个副本状态
  waves:[...],                         // 分波刷怪
  score:{ kill:10, boss:200 },         // 计分规则
}
```

需要一个**活动调度器**（定时开关场景 + 全服预告）。建议放 `server/events.js`（新模块），
依赖方向上排在 `combat` 之后、`commands` 之前。

## 待拍板

1. **秘境开几点？** 建议 20:30（晚饭后、睡前，在线率最高）；或一天两场（12:30 + 20:30）
2. **门票怎么给？** 纯掉落（硬核）／ 日常保底给一张（温和，把日常和秘境绑起来）← 倾向后者
3. **副本里死了怎么办？** 踢出去（狠）／ 原地复活扣分（温和）／ 不死只是打不动（最温和）
4. **攻防战什么时候上？** 建议等在线稳定 8 人以上再说
