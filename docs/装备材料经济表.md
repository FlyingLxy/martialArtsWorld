### 5.1 现行概率的精确期望方程：本轮确定性算术

为判断周3陨铁是否支撑上述投入，本轮按既有概率/怜悯求解有限线性方程；没有抽样、随机种子、游戏执行或模拟脚本调用。状态为`(l,s)`，l是当前打造等级0～14，s是连续无正进展次数。s≥6后所有转移概率相同，统一截为6；+15为吸收态，剩余成本0，因此共有15×7＝105个非吸收状态。

每个状态先按《装备与打造》4.2取基础`p2/p1/pf/pb`，从失败转向成功的百分点为`min(max(0,s−2)×8,32,当前失败百分点)`；l≥9且s≥5时再将全部3个百分点大失败转向成功。正进展后s归0；失败/大失败后s取min(6,s+1)。低段l<6失败不掉级，l≥6普通失败−1，大失败−2，等级最低0、大成功最高15。

对任意一种投入，令c(l)为从l尝试一次的成本，s′=min(6,s+1)，d(l)=l（l<6）否则l−1，则所有状态满足：

```text
E(l,s) = c(l)
       + p2 × E(min(15,l+2),0)
       + p1 × E(min(15,l+1),0)
       + pf × E(d(l),s′)
       + pb × E(max(0,l−2),s′)
E(15,s) = 0
```

概率在方程中用精确百分比有理数；整理成`(I−P)E=c`。陨铁的c(l)在l≥9时为1，其余为0；其余材料读取已登记15行，尝试次数取c=1，银两系数读取各行R倍数。105个状态同时求6个成本列，求得解代回原方程的全部残差严格为0。结果显示至9位小数，不用显示值再次推导：

## 6. 固定分解篮子与回收算术

每个非十声模板固定一个标准篮子，按模板等级/品质和第3节**基础篮子**计算；不含品质增材、核心、图纸或银两。十件L10入门白装虽无铸造配方，分解基础篮子取蓝色系数1并按实际武器族选篮子。其他196件铸造装备使用自身品质系数。掉落实例与铸造实例的同模板基础篮子相同，不看词条好坏、实际购价、赠送来源或市场价。

分解先按品阶20/25/30/35/40%逐materialId对基础篮子向下取整；再将enhanceLedger实际、可追踪、尚未回收的投入按M1/M2/M3/M4的20/15/10/5%分别向下取整。最后合并同ID结果；不先混算两种返还率。任何绑定来源存在时返还继承最严格归属，非整数余数丢弃，不能积攒成可提现返还券。

L1蓝木金武器篮子为木2、精铁1，25%后均为0；这是明确的向下取整结果，确认页须显示“本次无可返材料”。L60红木金武器基础篮子木32、精铁16，40%后返木12、精铁6，参考162两；不返玄晶8、钢4、陨铁2或核心。即使不计核心机会成本，162/5885≈2.75%，并且该核心来源的成品和返料均绑定，不能卖给玩家套利。

对任何已登记配方，基础返值≤基础投入×40%，铸造总投入还含非负品质增材与正工费，因此系统价下立即分解回报≤40%，且本批实际严格低于40%。打造后分解另按实际追加材料返≤20%，不返追加银两，不能提高到正收益。此为确定性上界，不是波动市场P95结论；市场P95<80%仍待获得模拟授权后验证。

世界资格初始化与保底重置读取[任务奖励与世界掉落经济表](任务奖励与世界掉落经济表.md)：蓝创角12；紫/橙角色20/40级分别给2/1，未达不攒，当期不双发；所有怪等级/差级/本门/D03条件同时校验。保底初始0、实发后归0、跨周保留。

## 7. 投入传承：保留份额，逐次抵扣

本轮对“传投入、不复制等级”提出明确解释：源/目标同槽，目标+0、等级不低于源；十声排除。原子操作把源真实未回收的打造投入转换成仅绑定该目标的内部可抵扣份额：银两70%，M1/M2/M3/M4为80/80/85/90%，每类先合并同ID同归属来源后向下取整，另付 `ceil(0.10R目标)` 手续费。源回+0、原账清零，目标仍+0；两者都不产出材料余额或新货币。

目标之后每一次正常打造仍完整支付该次同类成本并使用既有随机规则；先以其尚未用完的同ID份额抵扣，剩余银两/材料由玩家补齐。银两份额不抵材料，不跨材料ID抵扣，不抵铸造/图纸/重洗/手续费；跳过的强化级也不能预扣或退现。未用份额只保留在目标实例，不能出售、提现或转给第三件装备。

目标账本只记录本次实际新投入＋本次实际消耗的可追溯份额，不能把源原始总额再次记入。再次传承时只对目标已消耗且未回收的投入计算保留；其未用份额直接作废。分解时未用份额也作废，已消耗份额按实际留存材料规则返还。这样每次传承都会损失份额，源+0不能反复转出同一历史投入。

例：L10武器按+1～+6各一次成功，银两逐次为118/147/177/221/265/324，合1252两，精铁4、玄晶4。传入L20+0武器后保留876两、精铁3、玄晶3的专用份额，手续费381两；源+0清账。目标下一次+1正常成本153两＋精铁1，由份额抵扣后余723两/精铁2/玄晶3，仍正常进行该次成功率判定；没有白得+6。若此时分解目标，未用份额不发到背包。

此方案需要第5项落存档/事务字段与幂等验收，不能因文档给出算术就宣称已实现。

## 8. D04绑定、交易、税与耐久推荐

本节是交给用户审阅的统一推荐，不把候选变成已批准首发决策。市场是材料与未绑定普通装备的正式流通入口；首发推荐不做绕过托管的直接赠送/易货。已有十声保管、个人奖励绑定不受本次普通市场选择影响。

| 来源/操作 | 推荐状态 |
|---|---|
| 普通可交易原材/公共系统购材 | 可交易；绑定来源不因此解除 |
| 陨铁、碎片、30核心、古墓材料 | 角色绑定；世界阴晶若后续启用仍同ID同绑定，只按来源计产率/周帽 |
| 普通白蓝成品且未用绑定材料 | 可交易，穿戴本身不绑定；首次打造、重洗或接受传承即绑定 |
| 紫橙红成品 | 未触发其他绑定时首次穿戴绑定；本批30红装使用绑定核心，铸造即绑定 |
| 任何铸造/加工投入含绑定来源 | 输出继承最严格归属；不能混料洗白；预览明确将使用哪些来源 |
| 入门、主线、个人保底、启动保障成品 | 获得即角色绑定；分解返料同绑定 |
| 已绑定/十声 | 不可上架，不存在“交易时打造清零就解绑”路径 |

同materialId仍只有一个总余额，来源/归属分量之和必须等于总额；不能造两个同名物品。默认优先消耗绑定分量，用户明确选择仅可交易材料时库存不足应拒绝，不能静默补用绑定料。所有接受绑定的操作在最终提交前给出结果。

市场沿用7天挂单，建议每角色最多10单，整单成交，挂牌物/银两由托管锁定；到期/撤单只返原物，挂牌费不退，重复结算只返一次。定价P为整单正整数价；挂单费`ceil(0.005P)`，成交税`ceil(0.05P+0.50×max(0,P−3V))`，V为该整单固定官评。卖家收到P减成交税，挂单费已在上架时单独销毁；买家仅付P，不能再扣一份成交税。

可交易精品装备V取`ceil(0.08R)`，紫橙装备V取第3节材料系统价之和＋工费（不把已解锁资格重复加价）；普通材料V为本表单位价×数量。滚值不改变V，打造等级不改变V（已打造本就绑定）。未有官评的物品不得上架，不能用0开启溢价税。神兵/十声/核心没有可交易报价；家业展示估值不成为可兑现货币。

例：官评300两的一单以1000两成交，上架费5，普通税50，超900部分另税50，卖家到账900，扣既付挂牌费后净895，系统销毁105。正常官评交易按1000两计则挂牌5＋成交50，净945。溢价税只提高异常转账成本，不能声称消灭对倒或保证市场价。

**耐久推荐后置，待用户裁定：**本轮基本供需表按无耐久、无修理费核算；不创建一项0余额修理债务。若决定首发启用，保留《装备与打造》6.4及《装备系统》17的备选损耗/修理系数，并重新计入普通战、精英、死亡的净收入后才能发布。不能同时宣称“耐久后置”又用其10%～18%回收作为已存在通胀闸门。
