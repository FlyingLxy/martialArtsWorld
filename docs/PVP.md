# PVP：切磋 · 擂台 · 无法之地 · 械斗

「械斗」在文档里只被提过四次，一直没有规则。这一篇补齐全部玩家对抗玩法。

**总原则**：这是十来个朋友的服务器。
**PVP 的目的是制造话题，不是制造退坑。**
任何"被打了一次就不想上线"的设计一律不做。

## 一、四种形态

| 形态 | 双方同意？ | 损失 | 记仇？ | 喂哪条线 |
|---|---|---|---|---|
| **切磋** | 需要 | 无 | 否 | 人情（交情 +2） |
| **擂台** | 需要（攻擂方主动） | 无 | 否 | 名望 |
| **无法之地** | **不需要** | 有 | **是** | 战力 + 人情（负） |
| **械斗** | 报名 | 轻 | 否 | 名望 + 门派 |

## 二、切磋

最基础的一种，**不产生任何损失**。

| 项 | 规则 |
|---|---|
| 发起 | 同场景内向某人发起，对方可拒绝 |
| 回合上限 | 25 回合，超时按剩余气血比例判 |
| 结果 | 胜负记录，交情 **+2**（不论胜负） |
| 损失 | **无** ——不掉经验、不掉耐久、不掉钱 |
| 下注 | 可选，双方约定银两，**零和转移**（不抽税） |

**"打过一场就是交情"**（[社交与关系](社交与关系.md)）：
切磋不论胜负都加交情，因为它本身就是一种社交行为。

回合上限 25 对得上[战斗模拟](combat-balance-simulation.md)实测的 19.32 回合，
落在区间内。

## 三、擂台

设在[问道场](场景卡全集.md)，**守擂制**。

```
擂主      当前排名第一，挂在擂台上
攻擂      任何人可挑战擂主，或挑战榜上任意名次
胜        接替对方名次，对方下降一位
败        无损失，但当日对同一目标的挑战次数用掉一次
```

| 项 | 规则 |
|---|---|
| 挑战次数 | 每天 5 次，**可攒存至 15 次**（[规则一](玩法与核心循环.md)） |
| 冷却 | 对同一目标每天最多 1 次，防车轮战 |
| 奖励 | 名次本身 + 称号 + **赤色**（夺魁） |
| 银两 | 少量，且**不随名次膨胀**——擂台喂名望不喂家业 |

> **v1 的错误**：擂台自动匹配最强的对手，新人上去必输。
> v2 改成**可选择榜上任意名次**——你自己决定挑战谁，
> 打不过就先挑名次低的。这一条已在 v1 修过，v2 沿用。

### 离线守擂

擂主离线时用**当前配置的数值档案**应战（不需要本人在场）。
否则擂台变成"谁在线谁称王"，跟挂机本位冲突。

## 四、无法之地：唯一允许强制 PK 的地方

这是仇人簿的**唯一来源**（[社交与关系](社交与关系.md)）。

| 允许强制 PK 的场景 | 理由 |
|---|---|
| [乱葬岗](场景卡全集.md) | 高收益高风险，本来就是 `risk` 场景 |
| [北坊](场景卡全集.md) | 洛阳的黑市区，官差不进的巷子 |
| [幽潮之下](场景卡全集.md) | 满级终局，本就极危险 |

**其余 46 个场景一律禁止强制 PK。** 城区、新手区、门派驻地、
家园全部安全。

### 红名：参照传奇，但更温和

击杀非红名玩家 → 自己染红：

| 红名值 | 惩罚 |
|---|---|
| 1（杀 1 人） | 进不了城区商店，持续 30 分钟 |
| 2~3 | 进不了城区，持续 2 小时；被杀时掉落材料 |
| 4+ | 上述 + **全服可见红名列表**，任何人可在无法之地击杀你且不染红 |

红名值每 2 小时（一个时辰轮回）自然消 1 点。

**三条防退坑设计**：

1. **被杀的损失很轻**：掉一部分未落袋的材料，**不掉装备、不掉等级**。
   [经济与成本](经济与成本.md)的"重伤 1 分钟"照常生效，不额外加罚。
2. **红名是社会性惩罚，不是数值惩罚**——进不了城、被公示，
   靠的是"大家都看得到"，而不是砍你属性。
3. **新手保护**：20 级以下不可被强制 PK，也不能强制 PK 别人。

### 为什么还要留这三块地

完全没有强制 PK，仇人簿就是空的，江湖也就少了一半味道。
但把它**限定在三个场景**，意味着**不想碰的人可以永远不碰**——
这符合"主动全可选"（[玩法与核心循环](玩法与核心循环.md)）。

## 五、械斗：门派之间

接[活动与秘境](活动与秘境.md)的攻防战设计，做实规则。

| 项 | 规则 |
|---|---|
| 形式 | 门派 vs 门派，**报名制** |
| 开放 | 每周固定两场（配合[时辰](地图系统.md)） |
| 时长 | 40 分钟 |
| 人数 | 不足时**随机分阵营**——见下 |
| 奖励 | 帮贡 + 门派声望 + 称号；**不给装备** |
| 损失 | 阵亡即退场等待复活，**无任何掉落** |

### 随机分阵营解决两个问题

[活动与秘境](活动与秘境.md)已定：人数不足时随机分阵营。
这顺带解决了**人少时的阵营平衡**和**固定门派之间的积怨**——
今天你我同队，下周就是对手，仇结不起来。

十来个人的服务器上，这一条几乎是械斗能不能办起来的前提。

### 计分

```
击倒对方成员      +3
占据据点每分钟    +1
护送/夺旗完成     +10
```

**不按人头堆分**，否则强者屠杀弱者最划算。
据点与目标占大头，让弱者也有贡献方式（守点、护送）。

## 六、跟五条线的对应

| 玩法 | 喂哪条线 | 不喂什么 |
|---|---|---|
| 切磋 | 人情（交情） | 不喂战力、不喂家业 |
| 擂台 | 名望（名次、称号、赤色） | **银两不随名次膨胀** |
| 无法之地 | 战力 + 人情（仇人） | 不喂名望——杀人不给称号 |
| 械斗 | 名望 + 门派帮贡 | 不给装备 |

**"杀人不给称号"**是有意的：
不能让"杀了多少人"变成一种可炫耀的成就，
否则十人服会变成互相追杀的修罗场。

## 待拍板

1. **擂台离线守擂用"配置档案"，需要战斗模拟支持无人操作的自动出招。**
   这跟[战斗文档](turn-based-combat.md)的"选择一门当前可用的主动技能"
   需要一个默认策略。
2. **红名 4+ 的"任何人可击杀且不染红"会不会导致围殴？**
   十人服里可能变成群体霸凌。或许上限到 3。
3. **无法之地只有三处够不够？** 少了没人碰，多了破坏安全感。
4. **械斗每周两场，人数不够怎么办？** 是取消，还是允许
   [江湖散人](江湖散人.md)凑数？后者有"跟机器人打赢了攻城战"的空虚问题。
5. **切磋下注不抽税**，会不会成为洗钱通道？
   建议加单次上限，或按[市场](市场与家业.md)的溢价税逻辑处理。
