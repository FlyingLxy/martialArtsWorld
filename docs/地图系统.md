# 地图系统

> **与世界观的关系**：地名、门派驻地、区域归属以
> [万国江湖世界观设定](worldbuilding.md) 为准，本文只负责把它们落成**可玩的场景**
> ——门槛、收益、风险、独有产出这些。两边冲突时以世界观为准，本文跟着改。
> 历史年份以[编年史](编年史.md)为准，标准专名与首次对玩家展示的时机以[术语表](术语表.md)为准。
>
> 下面「门派山门」一节原本自拟了藏经阁、思过崖等地，现已并入世界观的
> **十处传承之所**（少林藏经坪、武当紫霄宫、峨眉金顶云台、丐帮君山总舵、
> 华山思过崖，以及海外五派的群星回廊、誓约厅、影庭、英灵长屋、神殿前庭）。

## 设计基线

**这是 v2 的地图设计，不继承 v1 的等级、地图和任务，上线时清档。**
唯一沿用的是 v1 的**泡点框架**：

```
每 2 秒结算一跳
每跳收益 = 场地基础值 × 等级衰减 × 悟性加成
等级衰减 = max(0.25, 1 − (等级 − 场地门槛) × 3.5%)
挂着就涨，关掉就停；不足一点的零头累积不丢
```

这套机制本身是好的——它天然制造了"该挪窝了"的节奏，也让挂机有意义。
保留它，别的从头来。

### v1 留下的三个教训

不是约束，是**用真实数据验证过的坑**，v2 照着避开：

| 教训 | v1 实测 | v2 怎么避 |
|---|---|---|
| **只有一个维度就没有决策** | 场景只有"等级门槛"一个区别，每段唯一最优解，玩家算一次就再不用想 | 六个机制字段（见下）组合出多维取舍 |
| **产出不压制会爆炸** | 打怪经验不随等级衰减，实测**刷怪比泡点快 858 倍**，核心玩法直接废掉 | 见[经济与成本](经济与成本.md)的等级压制 |
| **曲线追不上输出就失控** | `need` 用 `lv^1.75`，而输出是三项相乘，结果 10 级要打 25 只怪、80 级只要 4.7 只 | 上限 60 + `lv^2.2`（已定） |

## 写场景的方法：场景卡

每个场景按这张卡来写，**四栏缺一不可**：

```
名字与描述     地名以世界观为准；描述自己写，要有画面
玩法参数       泡点门槛与收益、能打什么怪、有什么功能（商店/任务/集市…）
机制           risk / night / crowd / solo / need / hidden / mat 怎么配
能长出什么任务  ← 最关键的一栏
```

**最后一栏是任务设计的种子**。写"乱葬岗"时自然会问：谁在这儿挖坟？
那些墓奴哪来的？夜里的磷火是什么？——三个任务就有了。
反过来先想任务再硬造一个地方来放，容易生硬。

全部场景卡写完，会同时得到**一张完整地图**和**一份任务素材清单**。

## 一、先加机制字段

场景从"布尔开关"升级成"有性格的地方"。新字段组合起来，
每个场景都应有自己的存在理由。

```js
乱葬岗:{
  name:'洛阳城外·乱葬岗',
  desc:'野狗刨开的坟头东一个西一个，夜里磷火乱窜。',
  zone:'洛阳',                                   // 归属区域
  exits:['guandao'],
  hunt:['yeguai','shigui'],
  paodian:{act:'枯坐养煞', exp:26, lv:50, tip:'阴气最能磨人心志'},

  risk : {hp:0.015, tip:'阴气侵体，每分钟蚀去一分五的气血'},
  night: {mult:1.8, tip:'子时阴气最盛，收益近乎翻倍'},
  mat  : {k:'yinjing', rate:0.04},
},
```

| 字段 | 效果 | 制造的取舍 |
|---|---|---|
| `risk` | 每分钟按比例掉血 | 收益换风险。**不能无脑挂一整夜**，得备药、得偶尔看一眼 |
| `night` | 特定时辰收益翻倍 | 制造"什么时候上线"的选择，夜猫子有专属去处 |
| `need` | 进入条件：等级／门派／物品／任务 | 有些地方是**奖励**，不是默认开放 |
| `crowd` | 在场人数越多，全场收益越高 | 把人往一起赶 —— 这是社交的抓手 |
| `solo` | 只准一个人待 | 逼人分散，制造"占坑"的博弈 |
| `hidden` | **在不在左下角列表里** | 跟 `need` 分开：`need` 管能不能进，`hidden` 管看不看得见。地图默认全可见，只有按设定该藏的才藏（胧月里、无名谷、幽潮） |
| `mat` | 独有产出 | 给"专门跑一趟"一个硬理由 |
| `zone` | 归属区域 | 用于折叠显示和赶路判定 |
| `schedule` | 限时开放（见[活动与秘境](活动与秘境.md)） | 到点才出现 |

**注意**：`risk` 和 `crowd` 的结算都挂在 `server/idle.js` 的每秒 tick 上，
那儿已经有现成的循环。

## 二、区域划分与场景规划

结构以[世界观第 4 节](worldbuilding.md)的地理树为准：四个中原出生地从不同方向汇入洛阳，
洛阳再连接中原山门与海外航路。

```text
杏花村 ─ 东南旧官道 ─┐
河阴渡 ─ 黄河南岸大堤 ─┤
函谷驿 ─ 崤山旧道 ───┤
龙门镇 ─ 伊水河湾 ───┘
                         洛阳城
                         ├─ 旧宫城／天街／问道场／北坊／东水门
                         ├─ 中原五派山门
                         └─ 万国行栈 ─ 东海·万国码头 ─ 五条航线 ─ 海外五派传承之所
```

**万国行栈是个很好的抽象**：它把"从洛阳走漕船车马到东海"这整段路收成一个节点，
地图上不必画沿途城镇。落成玩法时，它天然就是**赶路机制的挂载点**——
进出海外要在这儿付车马与船资，不做赶路读条。

> **现有的 13 个场景不作为约束**（已定）。塞北·风雪谷、西域·星宿海这些
> 不在地理树里的，重画时不必迁就——但**上线时要给现有玩家一条迁移路径**，
> 见本文末尾「迁移」一节。

下面按地理树展开。**地名与地域性格以[世界观](worldbuilding.md)为准，这里只定玩法形状。**

### 四个出生地（1～10）

玩家创建角色时自由选择故乡。每个出生地有自己的 1～10 级主线、熟人 NPC 和场景卡，
但不给属性、战力或门派选择差异。

| 出生地 | 代表场景 | 新手异常 | 长期返回理由 |
|---|---|---|---|
| **杏花村** | 悦来客栈、老槐树、铁匠铺、竹林小径 | 无字蓝布与海木匣 | 旧官道、乱葬岗、埋在树下的无字路碑 |
| **河阴渡** | 老渡口、缆绳行、河神祠、芦苇滩 | 逆流而来的无人货舟 | 逆流异象、失踪船簿、非本地船骸 |
| **函谷驿** | 官驿、旧关门、马市车行、烽燧坡 | 无车夫却盖有多派印记的货车 | 不存在的西行道路、古代“地脉隆起”记录 |
| **龙门镇** | 龙门石桥、石工巷、药王坡、旧陵道 | 没有致命伤却不知疼痛的尸体 | 石窟低鸣、反复出现的脉络纹样、山中旧墓 |

每个角色只亲历自己故乡的新手主线。其他三地之后可自由前往，可看事件遗址、后续对话和散落文案，
但不重做别人的 1～10 级主线。

### 四条赴洛路线（6～10）

| 路线 | 叙事距离 | 中途节点 | 地图处理 |
|---|---:|---|---|
| 杏花村 → 洛阳 | 六至七日 | 东南旧官道 | 保留一处长亭或荒庙 |
| 河阴渡 → 洛阳 | 五日 | 黄河南岸大堤 | 保留一处决口或护堤庙 |
| 函谷驿 → 洛阳 | 十五日 | 崤山旧道 | 保留一处旧驿或烽燧 |
| 龙门镇 → 洛阳 | 五日 | 伊水河湾 | 保留一处渡口或峡谷石径 |

只表现一个中途节点，不把五到十五日路程拆成十几个换皮场景，也不让玩家真实等待。

### 中原·洛阳城（10+）主枢纽

| 城区 | 主要玩法 | 场景定位 |
|---|---|---|
| **旧宫城** | 官署、档案、主线与后续隐藏区 | 外朝旧址开放，内苑、地下旧渠和封闭建筑按任务解锁 |
| **天街** | 集市、打造、告示、酒楼、请客 | 繁华旧都的交易和社交中心 |
| **问道场** | 10 级择承、比武、十派驻洛事务 | 十派各有接引人；只处理择承与门派事务，不公开授艺 |
| **北坊** | 城隍庙、衙门日常、牢狱、居民支线 | 官差、平民和江湖人的冲突面 |
| **东水门** | 漕运、仓栈、货运任务、万国行栈 | 洛阳连接东海的出入口；25 级主线引荐后开放出海 |

洛阳是一座仍然繁华的旧都，不是到处刷怪的废城。公共城区永久可用，历史深层与地下区域通过 `need/hidden` 逐步开放。

### 十派 10 级择承与中期路线

玩家在问道场从十派中选择一派。问道场只提供共同入口，受戒、拜师、入帮、入学、受封、受印等仪式仍分别遵守各派礼法。

- **中原五派**：择承后解锁对应山门与初级驻地。10～18 级先完成入门与本门短线，18 级左右回洛阳追查四案。
- **海外五派**：由本派驻洛使者正式接纳，10～25 级在问道场附近的驻洛使院修习。25 级后可赴万国码头，35 级左右进入海外传承之所。

中原五派驻地仍按世界观使用嵩山·藏经坪、武当·紫霄宫、峨眉·金顶云台、洞庭·君山总舵、华山·思过崖。
每派中后期继续有**驻地**（泡点 15／门派任务）→
**内室**（泡点 32，`need` 本门＋30 级，`solo`）→ **闭关处**（泡点 45，`solo`＋`risk`，期间不能说话）。

### 五条航线（25–40）海上，各具地貌

**航线本身就是场景**，不是一条读条——这是断潮未散的实感所在：

| 航线 | 场景 | 机制 |

| 金沙航线 | 金沙洲 | 白昼 `risk`（暴晒），夜里安全 —— 跟别处相反 |

### 配套：怪物跟着新区域重画

四个出生地、四条赴洛路线、海上和传承之所都要有自己的怪物与特色行为。
具体等级和属性从 v2 数值基准重新推导，不沿用 v1 的最强怪等级。
**必须遵守[经济与成本](经济与成本.md)里的等级压制**，别再出现刷低级怪滚雪球。

与海外线（`crowd` 热闹但要出海）并行，两条都能走到满级。

## 二之二、满级之后玩什么（上限 60 的关键）

**60 级不是终点，是分水岭**——之前是纵向成长（升级），之后全是横向。
这正是魔兽那套的精髓：上限低，但满级后的事情比升级路上多得多。

满级后的追求，现在已经有或规划中的：

| 方向 | 内容 | 归谁 |
|---|---|---|
| **装备** | 打造 +9（费用递增、失败降级，无底洞） | 已实现 |
| **构筑** | 天赋树、技能配置 | [天赋体系](talent-system.md) |
| **副本** | 禁地肉鸽，随进随出 | [禁地](禁地.md) |
| **经营** | 家园、种植、钓鱼、藏宝图 | [家园系统](家园系统.md) |
| **活动** | 定时秘境、攻防战 | [活动与秘境](活动与秘境.md) |
| **门派** | 帮贡换绝学、门派任务 | [任务系统](任务系统.md) |
| **社交** | 切磋排名、擂台留影、成亲、请客 | 已实现 |
| **主线** | 五条海外线索 → 幽潮 | [任务系统](任务系统.md) |

### 建议补一样：门派声望

魔兽满级后最耐玩的其实是**声望**。这游戏有现成的土壤——
[世界观](worldbuilding.md)第 8 节已定：十派都有外传之技，但不公开授艺，
获得方式必须由具体任务说清。门派声望可以提供**任务线索与引荐**，但不直接发招式：

```
十派各有独立声望，做该派任务／帮该派办事累积
声望到档   →  得到外传之技的任务线索／关键人引荐，或解锁专属装备、称号、传承之所深层区域
完成对应任务 →  才学会外传之技
```

好处：**它让玩家有理由接触自己没入的那九派**，而不是满级后只守着本门。
也顺理成章地把[世界观第 10 节](worldbuilding.md)那些门派张力变成可玩内容——
帮少林办事会不会得罪骑士团？这种取舍才是耐玩的东西。

## 三、跨区域：收车马费，不收时间

**不做"赶路要等 N 秒"**——那和"死后三分钟不能战斗"是同一类东西：
拿走的是游玩时间本身，没人有耐心等，而且它跟[设计原则](原则.md)
"惩罚不能拿走玩本身"直接冲突。

改成**花钱**。同样能制造"要不要跑这一趟"的取舍，还顺带补一个回收口。

```
同区域内            免费（随便跑，不折腾日常）
中原跨区域          等级 × 3 两      —— 意思意思，几乎无感
出海／返航（万国行栈） 等级 × 50 两     —— 有分量，跨断潮是件大事
海外区域之间        等级 × 30 两
```

**为什么按等级收**：固定价对低级玩家太痛、对高级玩家形同虚设。
按等级则人人痛感相当，而且**高等级付得更多**，正好回收他们的产出
（跟[经济与成本](经济与成本.md)里"请郎中"是同一个思路）。

### 两个要小心的

1. **别把人卡死。** 身上钱不够就跨不了区，这没问题；
   但**回自己故乡和洛阳的路必须永远走得起**（或者干脆免费），
   否则新手一穷就困在荒郊野岭，只能删号重来。
2. **别惩罚探索。** 中原境内定得极低（等级 × 3），就是让人有个"花了钱"的意识，
   不至于让人不敢逛。真正贵的只有出海那一次。

## 四、UI 影响

## 四之二、时辰（已定）

**用游戏内时间，2 小时一个完整轮回**（不用真实时间——那会把夜间内容锁给夜猫子，
而这游戏的用户多半是上班族挂机）。

```
一轮回 120 分钟，四段：

  卯·晨    0 ~  20 分钟   （20 分钟）
  午·昼   20 ~  60 分钟   （40 分钟）
  酉·暮   60 ~  80 分钟   （20 分钟）
  子·夜   80 ~ 120 分钟   （40 分钟）
```

**昼夜各 40 分钟，晨暮各 20 分钟做过渡。** 一天有 12 个轮回，
就算只在晚上玩两小时，也能完整经历一次昼夜——**没有人会因为作息错过内容**，
这正是选游戏内时间的理由。

实现要点：

- 用**固定纪元**换算（`Date.now()` 对 120 分钟取模），不要用服务器启动时间，
  否则重启后时辰会跳，玩家的节奏被打乱
- 时辰是**全服统一**的，公共频道可以播报（「天色向晚」「子时已至」），
  这本身就是把人聚起来的信号
- 晨暮两段留给**过渡型内容**：某些怪只在暮色出没、某些鱼只在破晓咬钩

依赖它的：本文的 `night` 场景（星辉学院／日轮圣城一夜一昼）、
[家园系统](家园系统.md)的钓鱼鱼种。

## 六、上线：清档

新设计与旧数据不兼容（等级上限、地图结构、数值曲线全变了），
**上线时清档**，不做迁移。

需要注意的只有三件：

1. **提前说一声。** 哪怕只有几个朋友在玩，也该在公共频道和客栈告示板上
   提前公告清档时间——不是技术问题，是基本的尊重。
2. **一次清干净。** 别反复清。设计定稿、实现完成、测试跑通之后再切，
   不要"先上一半再清一次"。
3. **存档兜底照样要做。** 即使清档，`server/core.js` 的 `load()` 里也该校验
   场景是否存在——`MAP[p.scene]` 为 undefined 会直接崩服。
   这个防御不管清不清档都得有，将来改地图还会用到。
