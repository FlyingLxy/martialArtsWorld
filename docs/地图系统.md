# 地图系统

> **与世界观的关系**：地名、门派驻地、区域归属以
> [万国江湖世界观设定](worldbuilding.md) 为准，本文只负责把它们落成**可玩的场景**
> ——门槛、收益、风险、独有产出这些。两边冲突时以世界观为准，本文跟着改。
>
> 下面「门派山门」一节原本自拟了藏经阁、思过崖等地，现已并入世界观的
> **十处传承之所**（少林藏经坪、武当紫霄宫、峨眉金顶云台、丐帮君山总舵、
> 华山思过崖，以及海外五派的群星回廊、誓约厅、影庭、英灵长屋、神殿前庭）。

## 现状与问题

13 个场景，其中只有 5 个能泡点。场景之间的唯一区别是"能不能打怪 / 能不能泡点"，
外加一个等级门槛。

```
  1 级  杏花村·村口        exp 0.7
  1 级  杏花村·悦来客栈     exp 1.2
  5 级  村外·竹林小径      exp 2.2
 15 级  后山·瀑布         exp 5
 30 级  本门·后山         exp 11
 45 级  塞北·风雪谷       exp 12
 60 级  西域·星宿海       exp 18
 60 级往上：空白 ← 已经有人 118 级了
```

**三个问题**：

1. **只有一个维度**（等级），每段只有唯一最优解，选地方不是决策
2. **60 级以上没内容**，最强的怪才 65 级
3. **移动没有成本**，从村口到西域一次点击，"江湖之大"没有实感

## 一、先加机制字段

场景从"布尔开关"升级成"有性格的地方"。四个新字段组合起来，
三十个场景能有三十种存在理由。

```js
乱葬岗:{
  name:'洛阳城外·乱葬岗',
  desc:'野狗刨开的坟头东一个西一个，夜里磷火乱窜。',
  zone:'洛阳',                                   // 归属区域
  exits:['guandao'],
  hunt:['yeguai','shigui'],
  paodian:{act:'枯坐养煞', exp:26, lv:50, tip:'阴气最能磨人心志'},

  risk : {hp:0.015, tip:'阴气侵体，每分钟蚀去一分五的气血'},
  night: {mult:1.8, tip:'子时阴气最盛，收益近乎翻倍'},
  mat  : {k:'yinjing', rate:0.04},
},
```

| 字段 | 效果 | 制造的取舍 |
|---|---|---|
| `risk` | 每分钟按比例掉血 | 收益换风险。**不能无脑挂一整夜**，得备药、得偶尔看一眼 |
| `night` | 特定时辰收益翻倍 | 制造"什么时候上线"的选择，夜猫子有专属去处 |
| `need` | 进入条件：等级／门派／物品／任务 | 有些地方是**奖励**，不是默认开放 |
| `crowd` | 在场人数越多，全场收益越高 | 把人往一起赶 —— 这是社交的抓手 |
| `solo` | 只准一个人待 | 逼人分散，制造"占坑"的博弈 |
| `mat` | 独有产出 | 给"专门跑一趟"一个硬理由 |
| `zone` | 归属区域 | 用于折叠显示和赶路判定 |
| `schedule` | 限时开放（见[活动与秘境](活动与秘境.md)） | 到点才出现 |

**注意**：`risk` 和 `crowd` 的结算都挂在 `server/idle.js` 的每秒 tick 上，
那儿已经有现成的循环。

## 二、区域划分与场景规划

结构以[世界观第 4 节](worldbuilding.md)的地理树为准 —— 洛阳是中原枢纽，
出海必经**万国行栈 → 万国码头 → 五条航线**：

```text
杏花村 ─ 村外与后山 ─ 洛阳官道 ─ 洛阳城
                                  ├─ 中原五派山门
                                  └─ 洛阳·万国行栈 ─ 东海·万国码头
                                                      ├ 雾海航线 → 星辉学院
                                                      ├ 西陆航线 → 白垒堡
                                                      ├ 扶桑航线 → 胧月里
                                                      ├ 北海航线 → 鲸骨湾
                                                      └ 金沙航线 → 日轮圣城
```

**万国行栈是个很好的抽象**：它把"从洛阳走漕船车马到东海"这整段路收成一个节点，
地图上不必画沿途城镇。落成玩法时，它天然就是**赶路机制的挂载点**——
进出海外要在这儿花时间，中原境内则不收。

> **⚠ 待同事确认**：现有的「塞北·风雪谷」「西域·星宿海」不在世界观的地理树里，
> 但游戏里已经有了（45／60 级泡点场地，有人在用）。建议挂在**洛阳官道**之下，
> 作为中原的边疆；或者由世界观补一条说明。**这条不定，海外地图没法接着画。**

## 三、赶路

跨区域移动加 20～40 秒赶路时间，期间不涨经验；区域内瞬移。

**为什么要**：现在从村口到星宿海是一次点击，"江湖之大"完全没有实感；
加了赶路，"要不要为那点收益跑一趟"才成为真决策。

**代价**：牺牲便利。如果觉得烦，可以只对**跨大区**收时间（杏花村↔西域），
同城内免费。
