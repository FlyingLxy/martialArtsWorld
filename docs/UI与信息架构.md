# UI 与信息架构

**文字游戏的 UI 就是玩法本体。** 别的游戏 UI 是通往内容的窗口，
这里 UI 就是内容——玩家全部时间都在看这几块文字。

这一篇定布局、信息密度和渲染规则。

## 一、三栏，各司其职

沿用 v1 已验证的论坛式三栏（这是[项目最初的诉求](../README.md)：
"像论坛一样的页面，能进到不同的地方有人在，中间有个大聊天室"）。

```
┌─────────────────────────────────────────────────────────┐
│ 泡點江湖   场景 行囊 名帖 见闻 市集 信箱 同道 玩法 · 离开 │
├──────────┬─────────────────────────────┬────────────────┤
│ 人物状态 │  当前场景（可行动项）        │ 此地人物       │
│          ├─────────────────────────────┤                │
│          │                             │                │
│ 江湖去处 │  江湖公共频道                │────────────────│
│ （按区域 │  （全服 · 打斗 · 公告）      │ 风云榜         │
│   折叠） ├─────────────────────────────┤ [战力|名望|见闻│
│          │  个人消息                    │  |家业|人情]   │
│          │  （只有你看得见）            │                │
│          ├─────────────────────────────┤                │
│          │  频道▾ [输入框]      发言    │                │
└──────────┴─────────────────────────────┴────────────────┘
```

| 栏 | 职责 | 为什么 |
|---|---|---|
| **左** | 我是谁、我能去哪 | 状态与导航，不需要频繁扫视 |
| **中** | 正在发生什么 | **视线焦点**，聊天与战斗都在这 |
| **右** | 还有谁、谁厉害 | 社交在场感——**这一栏是聊天室的灵魂** |

**右栏不能砍。** 「此地人物」让"有人在"这件事可见，
[原则第三条](原则.md)的社交本位就靠它。

## 二、上下分屏：公共 vs 个人

中栏的聊天区**必须上下分开**：

| 区 | 内容 | 特点 |
|---|---|---|
| **上：江湖公共频道** | 世界／本地／门派聊天、全服广播、他人的打斗播报 | 热闹，会刷屏 |
| **下：个人消息** | 你的战斗过程、泡点结算、任务提示、系统回执 | **不会被别人刷掉** |

**这是原版泡点江湖最重要的设计。** 如果混在一起，
你打了一场架的过程会被三条闲聊冲走。分开之后，
**热闹归热闹，自己的事一条不丢。**

## 三、名字的渲染：全游戏最贵的一块地

按[成就与称号](成就与称号.md)与[社交与关系](社交与关系.md)：

```
★ 竹林三友 某某某 一代宗师 ： 说的话
│    │       │      │        └ 正文，永远默认色
│    │       │      └ 称号，灰色小字，只挂 1 个
│    │       └ 名字本体，8 色自选其一
│    └ 结拜字号，灰色
└ 前缀符号，极稀有
```

**四条硬规则**：

1. **正文永远默认色。** 只有名字能变色。
2. **称号最多 1 个**，且是灰色小字——不跟正文抢注意力。
3. **不做闪烁、渐变、跑马灯。** 聊天室是用来读字的。
4. **八种颜色在浅／深两主题下都要实测可读**，读不清就换色不换语义。

### 此地人物列表的第二行

```
某某某 一代宗师
  知交 · 峨眉 · 泡点中
```

第二行灰色小字放三样：**与你的交情档位**、门派、当前状态。
交情档位放在这里，[人情线](社交与关系.md)才有日常露出。

## 四、新页面怎么进

v2 新增了名帖、见闻录、市场、成就四个页面。**不开新窗口，不跳转**——

| 页面 | 打开方式 | 占据 |
|---|---|---|
| **江湖名帖** | 点任何人的名字 | 覆盖中栏上半（公共频道位置） |
| **见闻录** | 顶栏「见闻」 | 覆盖中栏上半 |
| **市集** | 顶栏「市集」 | 覆盖中栏上半 |
| **成就** | 名帖内的标签页 | 名帖内切换 |
| 行囊、玩法 | 顶栏 | 覆盖中栏上半 |

**下半的「个人消息」永远不被覆盖。**
你在翻市集的时候，泡点结算和有人跟你说话仍然看得见——
这是挂机游戏的基本尊重。

## 五、信息密度原则

文字游戏最容易犯的错是**信息太多和信息太少**同时发生。

| 原则 | 做法 |
|---|---|
| **一屏能读完** | 任何面板首屏不超过 20 行，再多折叠 |
| **数字带含义** | 不写「攻击 112」，写「攻击 112（同级偏上）」 |
| **变化要显形** | 数值变动时短暂高亮该行，2 秒后恢复 |
| **常用的不藏** | 泡点收益、当前场景、气血内力永远可见 |
| **稀有的不占位** | 成就、图鉴、师承树都在名帖里，不占主界面 |

### 江湖去处按区域折叠

49 个场景不能平铺。按 `zone` 折叠：

```
▾ 当前：洛阳城
    天街 · 问道场 · 旧宫城 · 北坊 · 东水门
▸ 四出生地（16）
▸ 中原五派（15）
▸ 万国码头（5）
▸ 航线与海外（10）
▸ 特殊（4）
```

**当前所在区域默认展开，其余折叠。**
`hidden` 的场景在满足条件前根本不出现在列表里
（[地图系统](地图系统.md)已定 `need` 与 `hidden` 分开）。

## 六、移动端

朋友们会在手机上挂机，**必须能用**。

| 断点 | 布局 |
|---|---|
| ≥1100px | 三栏并排（上图） |
| 768~1100px | 两栏：左栏收进抽屉，中 + 右 |
| <768px | 单栏 + 底部四个标签：**场景 / 聊天 / 人物 / 我** |

移动端两条特殊处理：

1. **聊天永远是默认标签。** 打开就看到有人在说话。
2. **个人消息在手机上改成聊天区顶部的一条可展开条**，
   点开是最近 10 条——手机上上下分屏太挤。

## 七、明确不做的

| 不做 | 理由 |
|---|---|
| 3D、立绘、动画特效 | 这是文字游戏，[原则第五条](原则.md)保住零构建 |
| 自动弹窗广告位／活动横幅 | 会毁掉论坛式的安静感 |
| 战斗独立全屏页面 | 战斗过程走「个人消息」，**不把人从聊天室拽走** |
| 红点未读徽标满天飞 | 只给「信箱」和「名帖·新成就」两处 |
| 声音提醒默认开启 | 挂机游戏，默认静音，可手动开 |

**"战斗不开独立页面"是最重要的一条**：
[玩法与核心循环](玩法与核心循环.md)说小时级的"上线看看谁在"是最容易
被忽略的一层。任何把玩家拽出聊天视野的设计都在削弱这个游戏的本体。

## 待拍板

1. **风云榜五榜切换，右栏高度够放几行？** 五榜各只显示前 5 名，
   点标题看完整榜——还是右栏太挤，把完整榜放进名帖？
2. **名帖点开覆盖中栏上半，会不会打断聊天？** 或许改成右栏浮层。
3. **移动端单栏时「此地人物」放哪？** 现在是独立标签，
   但那样就看不到"有人在"了——或许在聊天顶部加一条在线人数横条。
4. **8 色在深色主题下的实际对比度还没测。** 上线前要过一遍 WCAG AA。
5. **要不要做主题切换（浅／深）？** 还是跟随系统。
