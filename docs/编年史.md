## 1. 开篇纪年只是开发坐标

以《姑存》主线开始的当年为 **K0（开篇年）**，`K-16` 即开篇前十六年。
`K` 纪年是开发侧用来对齐文案的坐标，不是世界内共用历法，**不得直接出现在玩家文案中**。

游戏内的中原官文、寺志、西陆旧卷和神殿记录可以使用各自历法。写作时必须先换算到下表，
不得根据“十余年”“多年前”再各自推算一套年份。

下表年份是开发侧上帝视角的固定坐标；“±2年”等误差指玩家和世界内学者根据残缺文献所能得到的结论，
不会反过来浮动开发坐标。“玩家如何知道”一列沿用[术语表的可见性标注](术语表.md#1-玩家侧可见性)。

## 2. 关键年份表

| 开发坐标 | 锁定事件 | 设定性质 | 玩家如何知道 |
|---:|---|---|---|
| **K-218** | 太阳神殿现存最早的“黑日”记录写成。原件历法换算存在±2年误差。 | 记录存在与年代早于当代断潮为已确认；它记的是什么未定。 | **仅碎片**：神殿旧拓、日影换算、多个抄本。 |
| **K-216** | 西来残卷所述“大雾闭海”发生。残卷记的是西方海域，不是少林亲历。 | 事件发生为已确认；是否与黑日或当代断潮同源未定。残卷原历法同样存在±2年误差。 | **仅碎片**：残卷、旁证、异地历法对读。 |
| **K-96** | 记载“大雾闭海”的西来残卷由行脚僧携至嵩山，次年编入藏经阁见闻类目。这是少林现有档案可证的最早接触。 | 入藏年代已确认；残卷如何流转到行脚僧手中未定。 | **仅碎片**：藏经阁入藏簿与残页纸张可相互印证。 |
| **K-82** | 后来被称为“旧堪舆图”的中原气机舆图定稿，标有当时的“气盛之地”。 | 图与大致成图年代已确认；测绘方法、缺页原因及变迁规律未定。 | **仅碎片**：函谷驿旧路簿、洛阳档案与门派抄图的异文。 |
| **K-16** | 东海远洋航线连续出现无日月、无方向、罗盘失效的海雾；海客开始共用“断潮”之名。 | **当代断潮的起点。**开篇时距今十六年，是“十余年”的唯一换算基准。 | **公开**：海客口述、旧港失船榜、当代航运档案。 |
| **K-15** | 大部分远洋航路中断；白垒堡远征队在此后的最后一次可靠通讯中求援，随后失踪。 | 航路中断与通讯存在已确认；远征队后来的经历、是否有人生还及其立场均未定。 | **公开 / 仅碎片**：断航史是公开事实；远征队档案属于后续海外内容，不在《姑存》中判定。 |
| **K-5** | 当代大祭司见到“黑日坠海”的神谕。 | 神谕发生已确认；它与 K-218 旧记、K-216 大雾及后来断潮消退的关系未定。 | **仅碎片**：五种相互矛盾的神谕解读。 |
| **K-4** | 断潮开始退去，且退潮与一次罕见星象发生在同年；三艘遍体鳞伤的商船抵达东海旧港，成为首批有档可查的返航商船。 | 退潮、星象与归船同年已确认；三者是否存在因果未定。 | **公开**：归船是重开航路的公共记忆；星象关联主要藏在武当观测簿。 |
| **K-3** | 朝廷命人扩建东海旧港；临时通译桌在仓库外形成。同年，归航者首次在可核对记录中共用“幽潮”称呼雾中的漆黑潮汐。 | 扩建与“幽潮”称呼的最早现存记录已确认；幽潮是否在更早年代出现过未定。 | **公开 / 随进度**：建港史可直说；“幽潮”到达码头后再正式解释。 |
| **K-2** | 旧港扩建一期完成，正式赐名“万国码头”；四海会馆成立并升起无名蓝旗。 | **“建港”的统一年份。**旧港在此前已存在，不得写成平地新建一座港城。 | **公开**：港史、港名与蓝旗皆可直说。 |
| **K-1** | 通译馆由临时翻译处正式成馆，定下“元息”“传承之所”“万国江湖”等跨文化译名。当代测绘也在此年发现元息盛区与 K-82 旧图明显不合。 | 译名年代与两版图的差异已确认；变迁原因未定。 | **公开 / 仅碎片**：新译名可公开使用；舆图比对在《姑存》中成为可核验证据。 |
| **K0** | 四个出生地的异常在同一两个月内先后跨过影响现实生活的临界点，“四案”与《姑存》开始。断潮未完全消失，普通船只仍无法稳定越过余雾。 | 四案是缓慢变化的局部后果，不是同一时辰的神秘爆发；当前世界状态已确认。 | **公开 / 随进度**：本地案件开场即可见；其他三案在洛阳汇总证言后公开。 |

## 3. 线索对齐结论

- **黑日早于断潮**：K-218 最早旧记明确早于 K-16 当代断潮；K-5 的是当代神谕，两者不得混成一份记录。
- **大雾不等于断潮**：K-216 只能确认出现过相似的闭海现象，不能因为年代与黑日旧记接近就确认周期或同源。
- **残卷年代与入藏年代分开**：文中事件是 K-216，少林最早有据可查的接触是 K-96，两者相差一百二十年。
- **元息盛区确在变**：K-82 旧图与 K-1 新图的差异是可证事实；变化是持续迁移、周期波动，还是人为影响，仍属未定猜想。
- **断潮只是退去，不是结束**：K-4 后远洋重开，K0 仍必须由万国码头的可靠船只和领航者穿越余雾。
