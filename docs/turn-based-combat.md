# 回合制战斗机制

> 状态：战斗时序基线 v0.1
>
> 适用范围：所有战斗场景使用同一套回合、行动、冷却和状态时序。
>
> 关联文档：[门派主动技能体系](active-skills.md)、[门派天赋体系](talent-system.md)、[战斗数值模拟与平衡结论](combat-balance-simulation.md)

## 1. 基本结论

战斗采用有行动顺序的回合制，不是实时战斗，也不是双方同时提交后统一结算。

一个完整回合中，每个仍可战斗的角色通常各获得一次主动行动机会。角色依照本回合行动顺序逐个行动；前一角色的技能及其全部反应结算完成后，下一角色才能开始行动。所有行动机会都完成、被消耗或失效后，才进入回合末结算。

```text
回合开始
→ 生成行动机会并确定顺序
→ 第一名角色行动，完成全部事件结算
→ 第二名角色行动，完成全部事件结算
→ 其余角色依次行动
→ 回合末持续、延迟、恢复和状态结算
→ 下一回合
```

当前数值以一对一战斗为校准基准，但规则允许以后扩展到多人战斗。

## 2. 核心对象

| 对象 | 定义 |
|---|---|
| 战斗 | 从参与者进入战斗到胜负、撤退或回合上限结算的完整过程。 |
| 回合 | 所有存活角色各获得至多一次主动行动机会，再进行一次统一回合末结算。 |
| 行动机会 | 角色本回合主动选择并施放一门技能的资格；控制可以消耗它。 |
| 主动行动 | 使用一门主动技能或系统保底普通拳脚；正常情况下消耗一次行动机会。 |
| 反应事件 | 反击、招架、打断、致命保护等由事件触发的行为，不额外消耗主动行动机会。 |
| 追加攻击 | 由主动技能或天赋产生的后续伤害段，不视作一次新的主动行动。 |
| 回合末效果 | 持续伤害、延迟伤害、持续恢复、自然回内、冷却和状态计数推进。 |

“行动机会”和“伤害次数”必须分开。一次主动行动可以没有伤害，也可以产生多段伤害、反击或追加攻击，但仍只消耗一次主动行动机会。

## 3. 回合流程

### 3.1 回合开始

回合开始时依次执行：

1. 回合编号加一。
2. 清空“每回合最多一次”等本回合计数器。
3. 为每个仍可战斗的角色生成一次主动行动机会。
4. 读取本回合开始时的身法、优先级和控制状态，确定行动顺序。
5. 处理明确写明“回合开始时”触发的天赋和状态。

回合开始后获得的新身法修正默认从下一回合起改变顺序；技能明确写明“立即抢先”时除外。

### 3.2 行动顺序

行动顺序依次比较：

1. 技能或状态声明的优先级，例如抢先、蓄力完成或强制后手。
2. 角色当前身法。
3. 身法相同时，使用可复现的随机判定决定先后。

同一优先级不能让角色在一个回合内获得第二次主动行动。抢先只改变现有行动机会的位置，不复制行动机会。

### 3.3 单次行动

轮到角色时：

1. 若行动机会已被控制消耗，则记录跳过并结束本次行动。
2. 选择一门当前可用的主动技能；内力不足且没有其他合法技能时，使用普通拳脚。
3. 完整执行技能宣告、支付、反制、命中、伤害、状态、反击、追加和致命结算。
4. 当前技能产生的事件队列清空后，本次行动才结束。
5. 消耗该角色本回合的主动行动机会，并记录需要在回合末推进的既有冷却；本次行动刚登记的冷却不推进。

一名角色在自己的顺序到来前已经死亡、撤退或失去战斗资格，其行动机会直接失效。

### 3.4 回合结束

所有行动机会处理完成后，统一执行：

1. 持续伤害和延迟到期效果。
2. 持续恢复及被重伤暂停的恢复。
3. 由回合末伤害触发的护盾、致命保护和死亡结算。
4. 自然内力恢复及其他明确写明的自然资源变化。
5. 持续状态、回合计数和冷却推进。
6. 检查胜负、平局和回合上限；战斗未结束则进入下一回合。

同一个回合末效果也必须进入统一事件流程，不能绕过护盾、净化或致命保护直接修改气血。

## 4. 主动行动与非主动行为

| 行为 | 是否消耗主动行动机会 | 是否视作主动施法 | 默认能否触发追加攻击 |
|---|---:|---:|---:|
| 五门主动技能 | 是 | 是 | 可以，按技能和天赋声明 |
| 普通拳脚 | 是 | 是 | 否 |
| 反击 | 否 | 否 | 否 |
| 追加攻击 | 否 | 否 | 否 |
| 持续伤害 | 否 | 否 | 否 |
| 延迟伤害 | 否 | 否 | 否 |
| 自动净化／致命保护 | 否 | 否 | 否 |
| 控制导致的跳过 | 消耗机会但不施法 | 否 | 否 |

追加攻击默认携带 `no_extra_chain`，不能再次生成追加攻击。反击不支付主动技能消耗、不刷新主动技能冷却，也不被视为角色主动使用了某类技能；天赋明确声明时才可例外。

## 5. 控制、打断与吟唱

### 5.1 控制

- 眩晕、封穴等“失去下一次行动”的控制，消耗目标下一次尚未处理的主动行动机会。
- 同一目标已经存在待消耗的行动控制时，新控制只能刷新该窗口，不能继续排队。
- 因此连续控制最多让目标连续损失一次主动行动，除非目标恢复行动后再次受到新的控制。
- 沉默、武器封锁等限制型状态不跳过行动，只限制可选择的技能标签；缠兵只降低符合技能威力，不属于技能封锁。
- 控制抵抗在状态写入前结算；抵抗成功后不得触发“控制成功”事件。

### 5.2 吟唱与蓄力

普通 `cast` 技能在同一次主动行动内完成“宣告 → 反制窗口 → 生效”，反制窗口不是额外回合。

需要跨回合蓄力的技能必须明确写出等待时长。宣告蓄力会消耗当前行动机会；蓄力完成后产生一个有优先级的结算事件，默认不再消耗新的主动行动机会。蓄力期间被打断时，按技能说明返还资源并移除结算事件。

## 6. 冷却规则

冷却以角色自己的主动行动机会为单位，不以现实秒数计算，也不因先后手变化缩短。

- 技能完成支付后立即登记冷却；随后未命中或被打断也不取消冷却，返还规则只影响内力。
- `CD 1` 表示接下来 1 次自己的主动行动机会不能再次使用，即本回合使用后，下一回合不可用，再下一回合恢复。
- `CD N` 表示必须经过 N 次自己的主动行动机会后才能再次使用。
- 角色因控制失去行动时，这次行动机会仍计入冷却推进。
- 本次行动新登记的冷却不被本次行动推进；只推进在该行动开始前已经存在的冷却。
- 反击、追加攻击和回合末效果不推进主动技能冷却。
- 每场一次的绝学不使用普通冷却；宣告并占用次数后，本场不能再次使用，即使随后被打断。

示例：角色在第 2 回合使用 `CD 1` 技能，第 3 回合该技能不可用，第 4 回合重新可用。

### 6.1 冷却缩减：额外推进率

装备与天赋提供的“冷却缩减”统一解释为**普通技能冷却额外推进率**，不直接把整数 CD 乘一个百分比：

1. 每次自己的主动行动机会结束，行动开始前已存在的普通技能冷却先正常 `-1`。
2. 正常推进后仍大于 0、且技能基础 CD 至少为 2 时，再按角色的额外推进率独立判定一次；成功则额外 `-1`。
3. 同一技能在同一次行动机会最多额外推进 1 次，判定使用服务端可复现随机源。
4. `CD 1` 永远至少空过一次自己的主动行动机会；绝学、每场次数限制、装备或套装的内部冷却均不参与额外推进。
5. 装备来源上限与全来源上限均为 15%；面板显示实际值，超过上限的部分不转化为其他属性。

15% 上限下，基础 CD 为 1／2／3／4 的技能，期望不可用行动机会分别约为 1.00／1.85／2.72／3.59。所有可用性变化仍只发生在整数行动边界。

## 7. 持续时间规则

“持续 1 回合”不能因为角色在回合中的先后位置不同而完全不生效。不同效果使用不同的到期锚点：

| 效果类型 | “持续 1 回合”的默认含义 |
|---|---|
| 自身进攻增益 | 覆盖自己的下一次主动行动，完成该行动后到期。 |
| 目标进攻减益 | 覆盖目标的下一次主动行动，完成该行动后到期。 |
| 护体、闪避、招架 | 至少覆盖下一次符合条件的受击；若未受击，则在自己的下一次主动行动开始前到期。 |
| 控制抵抗、免控 | 覆盖下一次控制判定；未发生控制时，在自己的下一次主动行动开始前到期。 |
| 持续伤害／恢复 | 在回合末结算 1 次；“持续 N 回合”即最多结算 N 次。 |
| 延迟效果 | 等待指定数量的回合末，再创建到期事件并重新进入完整结算流程。 |

同名状态默认刷新剩余时间，不叠加数值；明确写明可叠层时，层数和持续时间分别记录。

## 8. 资源与胜负

- 技能在命中前支付内力；被合法打断时默认返还 50% 已支付内力，技能另有说明时以技能为准。
- 门派资源只有在对应事件成功后生成。写明“命中获得”的技能未命中时不生成资源。
- 资源消耗发生在技能效果读取资源之后、生成新资源之前；技能明确要求预支付资源时除外。
- 角色受到致命伤害时，先进入致命结算阶段，再判断死亡；不坏法身等效果因此可以介入。
- 一方全部失去战斗资格时立即结束战斗，不再执行尚未开始的主动行动。
- 双方在同一个已开始的事件中同时死亡时记为平局；已经入队但尚未开始的后续事件不再执行。
- 达到回合上限仍未分胜负时，按具体玩法声明判定；没有额外规则时按剩余气血比例，高者获胜，相同则平局。

## 9. 与统一事件阶段的关系

回合制规则决定“谁在什么时候获得行动”，事件阶段决定“一次行动内部如何结算”。二者关系如下：

```text
战斗
└─ 回合
   ├─ 行动机会 A
   │  └─ 宣告 → 支付 → 反制 → 命中 → 伤害 → 状态 → 反应 → 致命
   ├─ 行动机会 B
   │  └─ 宣告 → 支付 → 反制 → 命中 → 伤害 → 状态 → 反应 → 致命
   └─ 回合末
      └─ 持续／延迟 → 恢复 → 状态与冷却推进 → 胜负检查
```

事件名称、载荷、同事件排序和防止无限触发的规则，统一以[战斗数值模拟与平衡结论](combat-balance-simulation.md)第 4、5 节为准。

## 10. 示例

### 10.1 控制消耗行动

甲先手使用《截脉封穴》并成功令乙失去下一次行动：

```text
甲行动并完成伤害、标记和控制
→ 轮到乙
→ 乙的行动机会被控制消耗，不施放技能
→ 进入回合末
```

甲在乙被控制期间再次附加同类控制，只刷新这一个待消耗窗口，不会让乙连续跳过两个回合。

### 10.2 反击不抢占下次行动

乙攻击武当，触发武当反击：

```text
乙的主动行动
→ 乙造成直接伤害
→ 武当生成反击事件并结算
→ 乙的行动结束
→ 武当原本的主动行动机会仍然存在
```

反击不是武当的主动行动，因此不会让武当失去本回合正常出招机会。

### 10.3 冷却与控制同时推进

甲在第 1 回合使用 `CD 1` 技能，第 2 回合被控制而跳过行动：

```text
第 1 回合：使用技能，进入 CD 1
第 2 回合：行动机会被控制消耗，冷却经过 1 次自己的行动机会
第 3 回合：技能重新可用
```

控制不会把技能冷却永久冻结，也不会额外缩短冷却。
