# 《姑存》主线任务设计

> 状态：任务链制作规格 v0.1
>
> 玩家流程：所选故乡 6 个任务 → 洛阳 13 个任务 → 万国码头 16 个任务，共 35 个；四条故乡分支合计需制作 53 个任务定义
>
> 等级覆盖：1～25；角色 10 级到达洛阳，18 级后前往万国码头，25 级完成《姑存》
>
> 剧情母本：[主线剧情《姑存》](首发主线剧情-姑存.md)
>
> 依赖：[任务系统](任务系统.md)、[地图系统](地图系统.md)、[术语表](术语表.md)、[设计原则](原则.md)

## 1. 文档边界

本文把已经定稿的《姑存》拆成玩家实际接取和完成的主线任务，规定：

- 任务顺序、等级节点、公开目标与完成判定。
- 调查、泡点、护送、战斗和文书交互分别承载什么剧情。
- 失败后如何恢复，以及单人、散人和低在线人数下如何完成。
- 一次性奖励的形状、地图解锁和见闻录写入时机。
- 四个出生地分支怎样汇入同一条洛阳主线。

本文不重新解释剧情真相，不改写核心人物动机，也不新增共同幕后黑手。逐字对白、怪物数值、经验和银两的绝对值仍在实现阶段按统一数值基准填写。

## 2. 任务体验目标

### 2.1 每个任务都要改变一件事

主线节点不能只是“和下一个 NPC 说话”。每个任务完成时至少发生一项可见变化：

- 一种解释被证据排除。
- 一个人的处罚、权限或处境改变。
- 一份证据进入案卷或见闻录。
- 一个地点、交互或后续任务被解锁。
- 玩家从“看见异常”推进到“知道该核验什么”。

纯对话只作为上述变化的结算，不单独占一个任务。

### 2.2 主线服务“待着”，不把游戏变成连续点击

全线交替使用三种节奏：

| 节奏 | 玩家行为 | 用途 |
|---|---|---|
| 主动短段 | 调查 3～5 个明确对象、整理文书或打一场战斗 | 推进证据链，通常 3～8 分钟完成 |
| 共处观察 | 在指定公共场景正常泡点，期间逐步出现人群对白和环境变化 | 让玩家认识地方与普通人的代价，八成在 2～4 分钟内完成 |
| 章节间歇 | 到达 10／12／15／18／21／23／25 级后继续 | 让主线与挂机成长、聊天和可选内容交错，不要求现实日期或倒计时 |

共处观察期间，玩家可以聊天、查看行囊、使用场景功能；离开后累计进度保留。主动检查现场可提前完成剩余观察，但不能用付费或消耗品跳过。

### 2.3 证据重于战斗

每个角色完整流程只有两场必打战斗：故乡案一场、白沙道重测一场。战斗只用于护住人、证物或连续测量，胜利本身不证明任何人的口供为真。

门派身份可以改变战斗技能和部分解释性对白，不能替代证据，也不能跳过任务。所有强制战斗按无门无派、同推荐等级、普通品质 `+0` 装备可完成来校准；失败后保留已取得证据，并从战斗前恢复。

## 3. 等级、门槛与章节节拍

| 章节 | 玩家等级 | 主线作用 | 硬门槛 |
|---|---:|---|---|
| 序章·乡人之过 | 1～8 | 认识故乡、熟人与第一条完整证据链 | 创建角色即可开始 |
| 赴洛 | 9～10 | 用一个途中节点概括五至十五日行程 | 9 级可启程，10 级进入洛阳 |
| 第一幕·一纸无据 | 10～12 | 核验故乡证物并真正洗清熟人嫌疑 | 10 级 |
| 第二幕·四方同异 | 12～15 | 读取另外三案，排除合谋并建立无题手簿 | 12 级 |
| 第三幕·旧图今日 | 15～18 | 叠图、救人、承担公开真相的现实代价 | 15 级 |
| 第四幕·不予出档 | 18 | 核验旧港图，决定以个人身份东行 | 18 级 |
| 第五幕·海图无罪（前段） | 18～21 | 恢复原始译文、计时与船体证据 | 18 级 |
| 第五幕·海图无罪（后段） | 21～24 | 候潮、重测、找回缺页并公开核验 | 重测 21 级，核验 23 级 |
| 尾声·姑存 | 24～25 | 写成附页、落实处分与补偿、收到回执 | 25 级领取最终回执 |

等级门槛只挡住章节，不逐条卡任务。未到下一门槛时，日志明确写“此案下一步尚需时日；可在当前地区修行、接支线或处理日常”，不伪装成 NPC 忘了下一句台词。

港口“四日候潮”和全篇“五至七周”是叙事时间。它们由任务阶段与过场表现，不对应四个现实日，也不要求玩家挂机等待指定时长。

## 4. 通用交互规则

### 4.1 调查不是猜谜考试

- 当前必须检查的对象始终显示在任务目标中；场景文案负责说明“为什么查它”。
- 玩家可以自由选择检查顺序。证据齐全后由玩家执行一次“复核／落笔／提交”完成结论。
- 排序、叠图和换算交互允许试错，并在错误时给出证据内的矛盾，不扣物品、不重置整段。
- 关键结论至少有两类独立证据支持。可错过的碎片只能增加人物理解和见闻录内容，不能改变主线能否完成。

### 4.2 对话选择表达性格，不改写道德底线

关键回应提供“直率／温和／讥讽／寡言”四类语气。选择只改变玩家当句表达和少量后续招呼，不改变证据、奖励、处分或结局；系统保存最近常用语气供下一次默认选中，玩家随时可换。

### 4.3 多人帮助是故事，不是门槛

- 任务现场的其他玩家可以协助战斗、搬运或护送，获得一次小额协助奖励和对应见闻，不分走主线持有者的奖励。
- 低在线时由明确标注的普通 NPC 补足搬运、抬人和见证位置。
- 主线不要求把物品交给指定真人，不要求组队，也不读取江湖散人作为真实玩家姓名。
- 公共场景可以同时容纳处于不同任务阶段的玩家；关键证物、伤者和测量船使用个人阶段表现，不能被别人提前拿走或杀死。

### 4.4 失败与中断

| 情况 | 恢复规则 |
|---|---|
| 战斗失败 | 返回战斗前安全点；已完成调查项不回退，任务证物不掉落 |
| 护送对象气血归零 | 目标撤回最近安全点，重新开始当前护送段，不重做前置交谈 |
| 玩家离开共处观察场景 | 累计观察时长和已出现的见闻保留 |
| 整理文书中途退出 | 保存已确认的配对与排序；再次进入继续 |
| 主动丢弃普通背包物品 | 主线证物不占普通背包格，只存在于案卷栏，不能出售、分解或销毁 |
| 等级不足 | 保留当前主线并显示下一章节开启等级，不清除或降级进度 |

## 6. 洛阳公共任务链

从本节起四条出生线汇流。任务正文按玩家出身替换故乡证物、熟人、案由和核验动作，不改变公共结论。

### 第一幕·一纸无据（10～12 级）

| ID | 任务名 | 主要场景 | 玩家目标与完成判定 | 结果／解锁 |
|---|---|---|---|---|
| `LY-01` | 许多急事之一 | 旧宫城外朝 | 观察等回文的三类普通人，提交地方保结、封记和抄本；向杜春生把请求限定为“证明熟人没有造假” | 获得待核凭条；认识杜春生的权限边界 |
| `LY-02` | 先验一件东西 | 档案院侧库 | 完成出身专属核验：拓片对里程簿／船簿对水位档／木牌对站号簿／纹图对修筑档 | 杜春生必须把“不是今日凭据”与“并非当代伪造”分开记录 |
| `LY-03` | 一封只管清白的回函 | 档案院外房 | 逐项复核姓名、案由和裁定范围后用印寄出；从故乡回信确认处罚撤销 | 故乡篇正式结案；当前玩家写入本出生点公共完成记录；解锁 12 级章节 |

`LY-03` 完成时才写公共完成记录，避免只开始任务的玩家被当作当地解决者。记录保存角色唯一 ID 与当时显示名；异乡玩家阅卷时读取显示名快照。

### 第二幕·四方同异（12～15 级）

| ID | 任务名 | 主要场景 | 玩家目标与完成判定 | 结果／解锁 |
|---|---|---|---|---|
| `LY-04` | 三份薄卷 | 旧宫城外房 | 在外房共处观察并于急雨时护住案箧；依次阅读另外三案的已完成案卷 | 首次阅卷时锁定三名异乡解决者显示名；玩家此时才可见“四案”合称 |
| `LY-05` | 先找不同 | 档案院侧库 | 把四案按材料、年代、经手关系和受益人分类，逐案补齐一项流转证明 | 排除同一组织布置四案；不生成幕后黑手线索 |
| `LY-06` | 留一处空白 | 档案院案桌 | 为四案分别抄下地点、年代、当时条件、今日对应与未解处；每条必须保留“未可据此”栏 | 建立未题名、无编号、无印记的普通手簿；不得在玩家 UI 中命名为神器或组织 |

## 8. 任务奖励与成长接口

### 8.1 奖励原则

主线是一次性、不可重复的有限产出。奖励帮助玩家跟上场景门槛，但不能让连续点任务取代泡点成长，也不能让没入门的玩家缺少关键战力。

| 奖励 | 规则 |
|---|---|
| 经验 | 普通节点按同等级最优公共场景约 5～12 分钟泡点产出折算；章节收束按 20～30 分钟折算。整条 1～25 主线提供的经验不超过该段累计升级需求的 25% |
| 银两 | 只覆盖任务明确发生的拓印、药费、路费、船资和修理支出，并附少量结余；不得成为可重复刷取的主要收入 |
| 装备 | 不发主线专属必需装备。到 10／20 级里程碑时可从该等级通用标准装备中自选一个当前较弱槽位，品质和预算遵守装备系统 |
| 物品 | 主线证物进入案卷栏，不占背包、不可交易；完成后转为见闻录条目，不留下可复制售卖的实物 |
| 权限 | 解锁洛阳、万国码头、案卷回顾和相应 NPC 后续对白；不授官职、门派身份、领航权、调档权或正式称号 |
| 公共记录 | 故乡回函后记录当地完成者；维拉号裁决书记录当前玩家。两者只提供叙事留名，不加属性 |

经验绝对值必须从最终 `need(lv)` 与场景 `paodian.exp` 反解，不能把上述分钟直接写死成经验常量。路费和补偿也应按对应等级段收入计算，并与地图车马费一起校验。

## 9. 案卷、动态姓名与任务状态

### 9.1 玩家案卷栏

主线证据使用结构化案卷，不塞普通背包：

```js
p.story = {
  mainline: {
    id: 'gucun',
    step: 'LY-04',
    origin: 'xinghua',
    tone: 'direct',
    evidence: ['xh_stele_rubbing', 'xh_deed_copy'],
    checks: { archive_box: true },
    snapshots: {
      otherOrigins: {
        heyin: { playerId: '...', displayName: '何四' },
        hangu: { playerId: null, displayName: '曹芸' },
        longmen: { playerId: '...', displayName: '冯安' },
      },
    },
  },
};
```

字段名是实现形状，不是最终接口。主线、日常和玩家悬赏必须分槽保存，接主线不能挤掉正在进行的日常或悬赏。

### 9.2 动态姓名规则

1. 当前玩家完成 `LY-03` 后，才把自己的角色 ID 和当时显示名写入对应出生地的公共完成记录。
2. 其他玩家第一次执行 `LY-04` 时，读取每个未亲历出生地最近一位合格完成者，并立刻写入个人快照。
3. 快照此后不随新的完成者或角色改名变化；没有真实玩家时使用“林小满／何四／曹芸／冯安”。
4. 公共记录只轮换“最近完成者”，不宣称此人是唯一解决者；被读取后形成的个人快照永久稳定。
5. 江湖散人、管理员测试角色和未完成 `LY-03` 的角色不得进入候选池。
6. `MT-14` 的维拉号裁决书固定写当前玩家显示名，并同时保存角色 ID，绝不套用上述公共历史姓名。

## 10. 制作验收清单

### 10.1 剧情验收

- 四个出生点都只解决本地熟人的清白，不提前出现“四案”合称。
- 另外三案通过案卷与真实玩家姓名进入主线，不要求玩家重跑。
- K-1 之前的碑、簿、图和旧人文字均未使用“元息”。
- 气机迁移被证实，但原因、周期、与白沙道是否同源仍未定。
- 艾莉娜先承认错译，老罗恩的缺页后来独立查明；两人的责任不合并。
- 水寇没有留下指向四案、维拉号、艾莉娜或老罗恩的线索。
- 老罗恩永久失去领航资格，艾莉娜半年后才能重考，杜春生仍在原职。
- 最后一条新信息就是“此件存疑，姑存”，之后没有更大危机钩子。

### 10.2 玩法验收

- 任一出生地、任一门派或散人都能单人完成全部 35 个任务。
- 主线与日常、悬赏分槽，不互相覆盖。
- 每场强制战斗都以同推荐等级普通品质 `+0` 散人角色通关过；门派只改变打法。
- 战斗失败、断线、换场景后不会丢失关键证据或重置整章。
- 共处观察可累计、可聊天、可离场续做，低在线时不要求真人。
- 所有关键调查目标可从任务日志直接找到，不依赖低概率掉落或冷门物品说明。
- 任务状态同时区分已排除、待证明和无权判断，不会把局部证据显示成全案定论。
- 经验、银两和装备奖励通过统一曲线校准，整条主线经验未超过 1～25 级累计需求的 25%。

### 10.3 持久化与并发验收

- 异乡解决者姓名在首次阅卷时锁定，之后角色改名或公共记录更新不影响旧案卷。
- 同场多名玩家处于不同阶段时，个人证物与任务 NPC 状态不串线。
- 重测战斗只结算主线持有者的证据进度，协助者不会获得重复主线奖励。
- 主线完成后仍可回看全部公开案卷，关键物品不会残留为可交易对象。
- 重复登录、服务重启和存档迁移后，任务节点、检查项、姓名快照与已领里程碑奖励均保持一致。
