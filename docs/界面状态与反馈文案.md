## 1. 使用边界与显示规则

本文的STATE、MSG编号是文档/验收索引，不是新的API字段或内容物品ID。界面不直接显示这些编号。花括号为必须由已授权的权威状态填入的占位，不能把空值显示成0、免费、已完成或“undefined”；缺必需条款时显示MSG-113，保留已输入内容并停止该操作。

- 主界面使用“行囊、待领取、正在确认结果、内容已更新、重新进入”等玩家语言。requestId、saveEpoch、controlRevision、stateRevision、commitId、eventSeq、errorId及错误码只放默认折叠的“问题详情”；不包含密码、令牌、他人余额或隐藏答案。
- 桌面反馈跟随中栏操作区，公共聊天和个人事件分区继续可读；手机沿“场景／聊天／人物／我”入口，聊天默认页用个人事件摘要条展开结果。只增加普通新消息的文字计数，不把所有变化变成红点。
- 正常读取、免费领取、穿卸不产生绑定时的换装、免费洗点、普通移动、开关和已展示条款内的单次操作，不再追加通用“确定吗”。消耗、绑定或不可逆结果在原操作页给一份完整预览，明确提交按钮就是确认；仅退出古墓、分解/丢弃等从快捷入口发起时补同一份确认页，不连弹两次。
- 2秒修行收入只更新面板及可展开的本段累计，不能每次写聊天、个人事件或播报。普通单次成功在原行显示一次；稀有/永久史由已提交事件显示一次，断线补读不重播庆祝。旧“闭关禁言”与F03冲突按本轮界面建议保留聊天/社交可达，仍待评审，不以本表宣告旧规则已被用户裁定。
- 金额显示到已有0.01两余额精度，整数费用显示整数两；数量带单位。正数HP/MP不足显示精度时用“少于0.01”，不能显示成0而据此判死或禁用合法招式。完整精度可在属性详情查看，界面显示值不参与扣付计算。
- 时间采用玩家所在地可理解的日期与时刻，并明确“北京时间”；日常/周常写“每日05:00／周一05:00”，不是手机本地零点。倒计时依据服务端时刻与截止时刻估算，切后台、换标签、重连均不自行续期。
- 同一操作只在关联位置保留一份结果。成功、拒绝、待确认依据可追溯的提交状态判定，不能只看HTTP状态、动画结束、余额碰巧变化或SSE消息先后来猜。较旧的结果可补操作历史，不能覆盖较新的面板。
- 自由文本、角色名、门派名和物品名按纯文本展示；不拼成HTML。只显示当前有权查看的内容，权限撤回后不从旧缓存/聊天补读恢复私密资料。

## 2. 有限通用状态

同页可同时存在“连接恢复中”和某条“已领取”。状态按组件和操作意图划分，不能用整页一个布尔值抹掉已经确认的结果。表内英文仅供实现与验收映射。

| 状态ID | 合同状态 | 进入依据与玩家显示 | 可操作边界 / 退出依据 |
|---|---|---|---|
| STATE-01 | loading | 首次读取该面板，尚无可信数据；MSG-01 | 原位置显示骨架或文字；不把加载中当空列表。返回快照后进入02/03/04；读取出错保留查询按钮 |
| STATE-02 | empty | 已成功读取，当前授权集合确实为空；MSG-02或801 | 提供已开放的下一步；没有合法去处则仅返回。隐藏内容不借空态泄露 |
| STATE-03 | locked | 公开可见但等级、地点、实例或发布阶段不满足；MSG-03及对应错误文案 | 按钮旁说明实际缺项；满足后由新状态解锁。D待定只说暂未开放，不报虚构日期 |
| STATE-04 | ready | 当前状态允许操作，必要报价已取得且可展示 | 主按钮含动作与成本；点击后进入05。任务“目标已完成”在本状态显示“可领取”，不显示“已获得” |
| STATE-05 | submitting | 已发出一次明确意图，尚未得知结果；MSG-05 | 原按钮“提交中…”且禁止重复该意图；读面板、聊天和无冲突操作可继续。确定提交→07，耐久拒绝→08，失联/未知→06 |
| STATE-06 | pending-unknown | 请求超时、提交待查或异常后不能确认；MSG-06 | 保留原意图，提供“查询结果”；不换一次新购买/打造补发，不允许改原参数。未知范围内相关资产写入口暂不可操作，聊天/只读可继续；查明后转07/08/09 |
| STATE-07 | committed | 匹配的持久成功回执或可确认该意图结果的已提交事件；MSG-07 | 安装新状态并允许下一次明确操作。业务可能只是“报名已登记／等待归还”，只显示相应已完成步骤，不把整个流程判完 |
| STATE-08 | rejected | 已取得该意图的耐久业务拒绝；MSG-08及具体原因 | 这次没有资源扣发；保留输入。修正条件后可发起新的明确操作，原意图重查仍返回原拒绝；不退以前已付的费用 |
| STATE-09 | stale | 页面/对象/报价已变、角色绑定不符或需全量同步；MSG-09 | 停止依赖旧内容的提交；刷新本人合法状态并重新展示变化。新意图需要重新点击，不静默接受涨价/换目标 |
| STATE-10 | offline | 当前连接已断开或会话无法继续；MSG-10 | 保留最后确认状态及其时间，停用依赖在线确认的写入；不播放离线收益。战斗/古墓真实状态分别见§6；重连进入11 |
| STATE-11 | recovering | 重登、快照/事件/历史补读及未决操作核对中；MSG-11 | 可以看缓存但标旧记录；受影响写入口等所需数据完成核对后开放。恢复完整→04/07，仍未知的单项保持06，不用“联网了”替代“账已确认” |

格式、鉴权、限流、版本等未受理拒绝不伪装成STATE-08的耐久业务拒绝：按具体原因进入01/03/09/10，或保留输入回04。对已可能送达的旧意图仍按06核查。空态、锁定态、网络态均不得擅自把钱包、技能、存档或背包清空。

## 4. 报价、绑定与必要确认

有代价的操作页在一个位置完整展示：**对象与数量 → 实付银两/材料及来源绑定 → 已托管/已预约与可用余额 → 成功或随机结果范围 → 失败/取消/退出后果 → 容量去向 → 到期时刻 → 明确提交按钮**。没有发生某类代价就省去该项，不堆一屏无关风险声明。引用的概率只能来自发布规则，不把“期望成本”“EP预算”说成保底或实际胜率。

材料默认优先使用本人绑定分量。勾选“仅使用可交易材料”后显示对应可用量；不够就停用提交，不静默补绑定料。新的绑定结果在确认前明确到物品/输出，随机结果预览只列概率/候选范围，不先抽出实际词条供反复刷新。

一次性任务里程碑的自选装备只显示已发布且当前合法的模板。没有合法模板时保留待领取权，显示MSG-801及可公开原因，不能塞一件不兼容武器、改发银两或再发主任务XP。正常清空筛选与因D03/等级无合法模板须区分。

## 9. 关系同意、权限与超时

邀请在个人事件/关系页的一张卡中呈现：谁邀请、做什么、双方真实代价、有效至何时、接受/婉拒。对方在线、聊天回复或发起人点击都不代表同意。邀请等待不锁死其他游戏操作；接受前重新核对条款。师徒、指点、请客、带游、参观、昵称邀请10分钟，结拜24小时；参观接受后的单次入场许可另10分钟，已合法入宅不因此每10分钟被强制赶出。切磋邀请只展示已发布条款中的实际截止，不由界面套用其他邀请的期限。

| 文案ID | 玩家文案 | 触发与按钮 |
|---|---|---|
| MSG-601 | {角色名}邀请你{具体事项}，有效至{北京时间}。{双方代价与结果} | “接受”／“婉拒”；条款完整，不自动代付/代签。发起后显示“等待对方答复” |
| MSG-602 | 已发送邀请，等待对方答复。尚未收取本次费用。 | 只用于合同确认尚无托管/收费的一般邀请；不用于已同意并托管的结拜成员 |
| MSG-603 | 本次指点将消耗师父20精力，你获得{锁定等级实际E/12}经验。 | 徒弟接受页；仍须小时经验余量足够整包，等级/条款变则重取预览。尚未接受不先展示经验到账 |
| MSG-604 | 由{付款者}支付20两，双方交情增加1。 | 同场请客接受页；付款者从100到80、交情+1只在共同结果确认后展示。八个无资源表情动作不引用此收费文案 |
| MSG-605 | 本次结拜共{人数}人，每人100两，合计{100×人数}两。请核对成员、字号与截止时间。 | “同意并托管本人100两”／“婉拒”；每人包括发起人亲自确认，不能一人代签全部 |
| MSG-606 | 你已托管100两，等待其他成员确认。当前已同意{n}/{总人数}。 | 该成员托管提交后；不写已结拜。三人例前两位各150→50，第三位仍150 |
| MSG-607 | 本次结拜未成立，你托管的100两已退回。 | 该人原托管退款已提交后；未托管者显示“本次结拜未成立”。退款尚未知时用MSG-06，不先补钱包 |
| MSG-608 | 已结为{字号}，{人数}位成员各支付100两。 | 最后一人接受及全体成立同次提交后；三人例实付共300，不重复扣前两人 |
| MSG-609 | 你已出师，师承记录已留存。当前交情为{实际值}。 | 徒弟40级出师成功；交情至少200是结果，不显示“交情200才可出师”，解除不抹终身记录 |
| MSG-610 | 已获准参观，可在{北京时间截止}前进入一次。 | 单次许可生成后；“进入宅院”，入场仍验当前设置，查询/重连不延长许可 |
| MSG-611 | 宅主目前谢绝参观。 | 宅主全关或当前无权进入；“返回”。交厚≥80也不能绕过全关/黑名单；不显示私有拒收原因 |
| MSG-612 | 参观权限已结束，已返回{合法安全地点}。 | 撤权/导师离场/最后在线连接失效后的安全返回已提交；已有另一在线连接不误踢，真实处理前用“正在返回” |
| MSG-613 | 此次由师父带你参观，可查看此地风貌；不会开启这里的修行、任务或学艺权限。 | 带游开始说明；“结束参观”。不能误记发现收藏或把看见当已解锁 |
| MSG-614 | {角色名}想称呼你为“{六字内称呼}”。仅你们彼此可见。 | “接受称呼”／“婉拒”；也可到设置关闭接收。改称呼内容后旧接受不生效 |

宅院默认策略按原社交：交情≥80免逐次同意，其余需本次许可；宅主可切到“谢绝参观”或恢复默认。开关附近直接说明“恢复后交厚好友可直接串门，其他人仍需你同意”，不把恢复默认说成所有陌生人可进。解除师徒/结拜的确认页展示原合同历史后果，不虚构解除费用或清除终身关系资格。

## 10. 十声、空态与可访问性

十声是一条公开可见、资格明确的长线入口，不包装成普通新手必做事项。未最终启用时用MSG-111，不能假报名、假收料或展示“已有候选”占位；散人保留公开见证，无未登记的第十一种器型领取按钮。

| 文案ID | 玩家文案 | 触发与按钮 |
|---|---|---|
| MSG-701 | 意向已登记。正式报名将于{北京时间}开放，当前未收取材料。 | 免费意向提交后；“查看本轮安排”，不显示为正式候选 |
| MSG-702 | 已报名，贡献材料正在保管中。截止前可撤回，截止后按本轮结果结算。 | 正式报名提交后；“查看报名”／期限内“撤回报名”，公开范围按报名条款 |
| MSG-703 | 已撤回报名，精铁12、玄晶2已按原归属返还{至行囊／至待领取}。 | 实际返还已确认后；到期后不提供按开奖结果撤回 |
| MSG-704 | 本轮已结束，你未获得保管权；本轮有效贡献已结算。 | 实际未获选结果；不虚构安慰奖励，不反复弹庆祝或“再投料加权” |
| MSG-705 | 你已获得本代十声的保管权，正本{已入行囊／在待领取中}。 | 唯一归属提交后；“查看正本”，待领取只转移原件，不重新选人 |
| MSG-706 | 归还申请已登记。正本暂不能用于新的战斗，当前战斗结束后完成归还。 | 已进入耐久归还中间态；“查看进度”。不是网络未知，也不是已完成归还 |
| MSG-707 | 已完成归还。打造投入已记为专用抵扣：{实际清单}。 | 回收完成后；无真实份额时改为“已完成归还。本次没有可抵扣的打造投入。”。有份额才提供“查看抵扣”／合法L60普通武器“选择承接武器”，说明目标仍+0、需实际手续费，不把抵扣显示为银两或材料到账 |
| MSG-801 | 当前没有可选的{装备／条目}。{公开原因或筛选说明} | 真空池：保留合法待领位，给“查看条件”或配置恢复后“更新列表”；仅筛选空给“清除筛选”。不展示内部占位ID |
| MSG-802 | 暂无新的个人事件。已确认的记录可在这里查看。 | 手机摘要展开/个人事件空态；普通新消息用“新消息{n}条”，不抢正在阅读位置 |
| MSG-803 | {完整物品／动作／状态名称}：{必要数量与效果说明}。 | 图标或素材未制作时直接使用完整文字；不能只露资源编号、空方块或“素材待补”，信息不可省略 |
| MSG-804 | 当前{状态说明}。可用操作：{当前合法操作名称}。 | 屏幕阅读器/键盘反馈模板；名称与可见按钮一致，不能只有颜色、动效或悬浮提示能表达锁因 |

可访问性展示建议：所有输入有持久可见标签；原按钮提交后保留焦点，错误定位到对应字段且有文字原因；面板关闭后回到发起按钮。键盘可打开面板、切到合法目标、确认/取消，单独显示焦点，不把快捷键设成不可撤的消费。聊天新消息不抢焦点；战斗每次行动机会开始提供一次清晰提示，倒计时不逐秒朗读，仍服从同一10秒规则，不以无障碍名义暗改战斗窗口。动效可减弱或关闭，资源结果必须仍有静态文字；颜色前缀/稀有度有名称，不能只看颜色。
