# 市场与家业（家业线）

「交易」在文档里被提了七十多次，却一直没有规则。
这一篇补上，同时把[五条追求线](玩法与核心循环.md)里的**家业**线做实。

**市场不只是便利设施，它是整个"可选玩法"能成立的经济基础**——
[玩法与核心循环](玩法与核心循环.md)规定主动玩法产出材料而非战力，
前提就是**材料可以买到**。不玩家园的人能买矿，不打禁地的人能买材料。
市场一旦不通，每个产材料的玩法都会变成必做。

## 一、形态：挂单制，不是摆摊

梦幻是摆摊（人要在线），我们是挂机 + 聊天室，**挂单更合适**：

```
挂单     选物品 → 定价 → 交押金 → 离线也能卖
购买     在市场页搜/筛 → 一键买下
撤单     随时可撤，押金不退
时限     7 天，到期自动退回背包
```

**离线可成交**是关键——这个游戏一半时间玩家在挂机，
要求人在场才能交易等于砍掉一半流动性。

## 二、三笔钱：市场是第一大回收口

| 名目 | 收多少 | 谁付 | 去向 |
|---|---|---|---|
| **挂单押金** | 标价的 0.5% | 卖家，挂单时付 | **销毁**（撤单也不退） |
| **成交税** | 成交价的 5% | 卖家，成交时扣 | **销毁** |
| **溢价惩罚税** | 见下 | 卖家 | **销毁** |

押金不退是为了**防垃圾挂单**：随手挂个天价占位没有成本的话，
市场页会被垃圾淹没。0.5% 很低，但足以让人认真定价。

### 溢价惩罚税：防对倒洗钱

系统按 [EP 预算](装备与打造.md)给每件装备一个**官评价**。

```
成交价 ≤ 官评价 × 3        正常抽 5%
成交价 > 官评价 × 3        超出部分额外抽 50%
```

**这是防小号洗钱的核心机制**：想把银两转给别人，
最简单的办法是高价买他一件垃圾装备。溢价税让这条路变贵。

十来个朋友的服务器上恶意洗钱动机不强，
但**这条机制顺带做了价格锚定**——新玩家看官评价就知道行情，
不会被宰。

## 三、什么能卖，什么不能

| 类别 | 能否交易 | 理由 |
|---|---|---|
| 材料 | ✅ | **这是可选玩法成立的基础** |
| 装备（未打造） | ✅ | 流通让废品有去处 |
| 装备（已打造） | ⚠️ 见下 | |
| 药品、消耗品 | ✅ | |
| **高档打造的稀有材料** | ❌ | [装备与打造](装备与打造.md)的有意门槛 |
| **残页、图鉴条目** | ❌ | [见闻线的护城河](见闻与收藏.md) |
| 称号、成就、交情 | ❌ | 名望与人情不可买 |

### 已打造装备能不能交易

**建议：能，但打造等级清零。**

- 能交易 → 废品有去处，市场活跃
- 打造等级清零 → 有钱人不能直接买一件满打造的装备跳过整条曲线

这样买来的是"底子"，打造还得自己来。
既保住了流动性，又保住了[原则第九条](原则.md)的投入曲线。

## 四、跑商：家业线的主动玩法

家业线不能只有"攒钱"，得有**主动经营**的部分。

```
每个时辰轮回（2 小时）刷新一次各地物价
从低价地收货 → 运到高价地卖出 → 赚差价
```

| 项 | 规则 |
|---|---|
| 价差来源 | 系统按「距离 + 当地稀缺」生成，随机浮动 |
| 载货上限 | 按等级，防止一次通吃 |
| 风险 | 路上有概率遇劫（[人形怪](怪物与掉落.md)），打输损失部分货 |
| 频次 | 不限次，但价差每 2 小时才刷新一次——**这本身就是节流** |

**跑商是唯一"靠脑子而不是靠战力"赚钱的路子**。
不会打架的人也能富，这正是五条线独立的意义。

> 跑商喂的是家业线，**不喂战力**——赚的是银两，
> 银两买得到材料和服务，买不到名望、见闻和人情。

## 五、家业值：家业榜怎么算

```
家业值 = 现银
       + 挂单市值（按官评价，不按标价，防刷榜）
       + 家园估值（设施等级 × 系数）
       + 装备估值（按 EP 折算）
```

**挂单按官评价而不是自己的标价** ——
否则挂个一亿两的破铜烂铁就能刷榜首。

| 展示面 | 放什么 |
|---|---|
| 名字颜色 | **绿**（家业榜进过前三） |
| 风云榜·家业 | 家业值排名 |
| **家园** | 串门看到的宅子规模就是家业的可见形态 |
| 市场挂单署名 | 挂单上带称号 |
| 江湖名帖 | 家业值、成交笔数、跑商次数 |

**家园是家业线最好的展示位**——数字排名很抽象，
但"上他家串门发现宅子气派"是具体的。
这也给[家园系统](家园系统.md)的装饰投入一个社交理由。

## 六、防通胀的三道闸

[经济与成本](经济与成本.md)已经立了产出闸门，市场这边补三道：

1. **税收全部销毁**，不进任何池子。成交越活跃，回收越多。
2. **官评价锚定**，成交价不会脱缰。
3. **系统不做回购**。商店只卖不高价收——
   [经济与成本](经济与成本.md)已定"装备回收价按材料算，不按属性算"。

## 待拍板

1. **成交税 5% 够不够？** 太低回收不了，太高没人交易。
   建议先 5%，看实际成交量再调。
2. **已打造装备交易时打造等级清零，会不会太狠？** 折中方案：
   清零但退还部分材料。
3. **跑商的载货上限按等级，会不会让低级玩家没法赚钱？**
   或许改成按「家业值」——穷的人反而载得多，是个温和的均贫富。
4. **要不要做「求购」挂单**（我出价收某物）？做了市场更完整，
   但也多一套 UI。
5. **官评价怎么给非装备物品定？** 材料好办（按产出速率），
   但鱼、菜、藏品这类不好估。
