# 市场与家业（家业线）

> 状态：第4项D04统一推荐（2026-09-08），仅文档，待用户审阅。以[装备材料经济表](装备材料经济表.md)消除旧税率/交易清零冲突，没有修改市场代码或运行供需模拟。材料流通是首版保留范围，普通装备交易绑定和耐久仍待用户裁定。

市场提供材料与未绑定装备的玩家间交换。普通成长同时有公共系统材料渠道：没人挂牌、不经营家园、不打古墓时仍可付费取得普通材料，不能把“市场有人卖”当唯一生产源。

## 一、挂单与托管

推荐首发7天卖单，每角色最多10个有效挂单，离线可成交，整单购买。普通材料每单最多999个；装备每单一个真实uid，不以背包位置代替实例。挂牌前展示物品快照、总价、官评、上架费、预计税和绑定状态，确认后将原物锁入托管。

购买先校验价格版本、可交易状态、买家余额及背包，再原子转物与结算银两。已售/已撤/已过期不可再买；重复请求返回同一结果。撤单/到期返原物，上架费不退；背包不足保留同一托管待领记录，不丢物、不重复寄送。

挂单与结算必须持久化。旧v1曾因挂单只存内存而在重启后丢物；第5项须完成恢复、幂等和并发购买验证，本轮文档不代表已修复。求购、直送与易货不作为本轮已完成的交易通路。

## 二、统一税率与官评

P为整单正整数价，V为整单固定官评价：

| 收费 | 推荐公式 | 收取时机 |
|---|---|---|
| 上架费 | `ceil(0.005P)` | 上架时卖家付，销毁，撤单不退 |
| 成交税 | `ceil(0.05P+0.50×max(0,P−3V))` | 成交时从卖家应收款扣除并销毁 |

卖家成交入账P减成交税，上架费不再扣第二遍；买家仅付P。两费分别最终向上取整至1两，不先舍入中间因子。本轮替代旧《装备系统》2%＋8%案，不叠加两份税。

V读取装备材料经济表：可交易精品取ceil(0.08R)，紫橙取固定材料价＋铸造工费，材料取单位价×数量；R=12H×槽位权重，H=576+24L。成交价、滚值和上次挂牌价不反向改变V。未有官评的物品不得上架，不能以V=0补空值；食品本批按家园经济表绑定，不用装备EP给食物开放报价。

例如V=300、P=1000，上架5，普通税50，超过900的100两另税50，卖家入账900、扣原上架费后净895，系统销毁105。正常P=1000且不溢价时销毁55。溢价税提高异常转账成本，不能保证没有对倒或市场价永远接近官评。

## 三、绑定与可售集合

| 类别或操作 | 本轮推荐 |
|---|---|
| 精铁/玄晶/原矿/木炭/硝石/皮布木/百炼钢等普通材料 | 普通来源可交易；绑定来源保持归属，系统购买不解除已有绑定 |
| 陨铁、神兵碎片、30核心、古墓三材料 | 角色绑定，不上架；阴晶仍同ID逐源计产出，不拆同名物品 |
| 普通白蓝成品且未用绑定材料 | 可交易，穿戴本身不绑定 |
| 紫橙红成品 | 无更严格来源时首次穿戴绑定；本批红装使用个人核心，铸造即绑定 |
| 任何品阶首次打造、重洗、接受传承 | 立即绑定，提交前预览 |
| 铸造/加工混入绑定材料 | 输出继承最严格归属，不能把绑定核心洗成可交易红装 |
| 启动保障、入门、主线、个人保底 | 获得即绑定，分解返料同绑定 |
| 十声成器 | 不上架/赠送/分解，只按同一uid保管、归还及再问兵 |
| 四作物种/食、残页、图鉴、称号、交情、永久图纸/展示资格 | 不可交易，不作为普通材料上架 |

旧“已打造装备交易时清零”不再作为本轮推荐，绑定物不能清零后解绑。投入传承只转目标专用的未来打造抵扣份额，不转可提现货币；未用份额不可上市。本轮推荐玩家间交换只通过市场托管，不以直送、易货或清零返料绕税。

同材料ID只有一个总余额，来源/归属分量之和等于余额。默认优先消耗绑定分量，指定仅用可交易材料时不足应拒绝，不静默补料后绑定成品。市场卖出只消费可交易分量，加工与分解不增加可交易分量。

## 四、供给与回收

普通材料全额按固定价购买，不限每日总量，单单≤999；玄晶10级、百炼钢20级开放，系统不售陨铁/碎片/核心。精品按实际PUB/可购GEN及本派合法目标销售，整套普通六槽约0.96H。系统不回购装备或材料换银两；分解只返固定材料并向下取整。

买材→铸造→立即分解按系统价返值≤40%，实际铸造费使本批严格低于40%；加工投入价＋费等于输出价。税不会让系统循环变正收益；不同玩家的历史买价与价格波动仍可能产生交易利润，不能据此宣称市场P95<80%已验证。篮子、取整、例子见装备材料经济表。

第4项推荐耐久后置且不收修理费，待用户裁定；本轮收入表不把修理当作现有回收口。若选择首发启用，应沿备选损耗/修理系数重算净收入。税、铸造、打造和重洗虽已有参数，其长期消耗总量仍须实际分布验证。

## 五、家业展示与跑商边界

家业可展示现银、合法托管资产、家园和装备，每项只计一次；挂单物从背包移到托管不增加价值，使用固定官评而非自定标价。不可交易核心、称号/交情和未启用设施不捏造银两价值，榜单展示分也不可兑换。累计系统赚入推荐按[日常与经济方案](日常与经济方案.md)§5.2，只计系统净发银两、不计退款/垫付/市场周转。完整排行榜权重与快照由对应社交/榜单合同定义。

跑商原案仍是活动候选：两小时地区价差、运货容量、遇劫损失及求购挂单未在本轮登记成可执行奖励，不计入H、普通材料或神兵周供给。是否首发按范围表D09裁定，本段不替用户延期。无论跑商是否启用，公共购材和材料市场须独立可用。

## 六、依赖与验收

本轮推荐引用装备材料经济表、日常周常表及家园禁地经济表。第5项须保证托管、绑定来源、回收账本、重复结算与断线恢复；第6项保证提交前清楚显示成本/预计税/绑定结果。D04用户裁定、市场分位数和长期回收仍待后续验证，本轮不是已运行系统。
