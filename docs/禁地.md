# 禁地：肉鸽副本

> 状态：玩法草案。先把一局怎么走写清楚，数值后补。
>
> 参考：[杀戮尖塔](https://store.steampowered.com/app/646570/Slay_the_Spire/) 的分层节点地图
> （进门选物、每层入口商店、打完一个点再选下一条路、一路汇到层主）。
> 战斗仍用本游戏现成的 **1v1 回合制**，不做卡组。

这不是 [活动与秘境](活动与秘境.md) 里那种「到点开门、一屋子人刷分」的秘境。
两件事都叫「进去打」，但一个是**定时集体刷**，一个是**随进随出的单人试炼**。
入口、奖励、失败规则都不一样，别做成同一套。

| | 秘境（已有草案） | 禁地（本文） |
|---|---|---|
| 什么时候进 | 每天固定时段 | 有次数就随时进 |
| 几个人 | 同场计分，人多只是榜好看 | **一人一局**，别人进不去你的图 |
| 地图 | 一个场景，怪一波波刷 | **三层节点图**，自己选路 |
| 核心决策 | 打多久、打哪只 | 带什么奇物、走哪条岔路、钱花在哪 |
| 产出 | 积分排名发奖 | 本局搜刮，出来才结算 |

## 为什么要做

泡点是这游戏的日常，打怪是顺手。缺的是一截**主动玩 15 分钟也值得**的内容：
有选择、有风险、有「这局构筑」的感觉，打完能带回大世界用不上的材料。

它必须过[设计原则](原则.md)这几关：

- **不盯着也能活**：禁地是主动玩的，不做日常打卡。不进不亏，只是少一份材料。
- **不把人从聊天室拽走**：人还在频道里，只是地点写成「乱葬岗古墓」。
- **产出有上限**：每周次数 + 材料周帽，见第七节。
- **单机克制**：第一版单人。全服频道会报层主、绝境通关、极品材料，让屋子里的人有的聊。

## 一、一局怎么走

以第一张禁地「乱葬岗古墓」为例。玩家从乱葬岗（或城隍庙告示）点「探禁地」。

```
① 选难度     浅探 / 深入 / 绝境
② 整备       确认自己的兵器护体，再从 5 件奇物里选 2 件带进本局
③ 第一层     入口商店 → 走节点 → 墓奴头领
④ 第二层     入口商店 → 走节点 → 镇墓兽
⑤ 第三层     入口商店 → 走节点 → 古墓主人（终点，只有一个）
⑥ 结算       奇物消失；材料、银两、本局丹药带出（丹药出禁地作废）
```

中途关掉页面：**局存着**，下次登录还在这个节点上。
挂机泡点在禁地里**停掉**——你在走路，不是在打坐。

### 文字里长什么样

左下角去处列表换成「本层地图」，中间还是叙事 + 选项。打完一个点，才出现下一列可走的路。

```
┌ 泡點江湖  令狐冲 32级 · 乱葬岗古墓 · 深入 · 第一层 ──────────┐
│ 人物状态     │【供品密室】石桌上三只碗，中间那只还热着。    │
│ 气血 820/900 │                                            │
│ 冥钱 46      │ 前方可去：                                 │
│ 奇物 摸金符  │  · 游荡尸傀（普通）                        │
│     盗泉壶  │  · 盗墓贼摊（商店）                        │
│              │  · 磷火小径（未知）                        │
│ 本层地图     │                                            │
│  店          │ 本层终点：墓奴头领                         │
│  ├尸傀 ←你   ├────────────────────────────────────────────┤
│  ├未知       │ 江湖频道照常。有人通关绝境会刷一条。         │
│  └贼摊       │                                            │
│    ╲  ╱      └────────────────────────────────────────────┘
│     层主
```

玩家永远只看见**当前点连出去的下一列**，不会一次把三层全摊开。
本层已经走过的路用灰字留在左下，方便回想「我是从商店绕过来的」。

## 二、难度：浅探 / 深入 / 绝境

三层结构不变，改的是怪有多硬、路上有多少好点、失败能带出多少。

| | 浅探（简单） | 深入（中级） | 绝境（地狱） |
|---|---|---|---|
| 谁能进 | 20 级 | 40 级 | 60 级 |
| 怪的血/伤 | ×1.0 | ×1.35 | ×1.8，精英再加一层词缀 |
| 每层节点列 | 5 | 5 | 5 |
| 商店 / 休整 | 偏多 | 常规 | 偏少，精英偏多 |
| 入口商店货 | 药、信息、便宜奇物 | 常规 | 贵、带副作用的凶物更多 |
| 珍贵材料 | 几乎没有，教规则 | 有 | 绝境独有的那种才在这儿 |
| 失败带出 | 已搜刮的 50% | 30%，且不含珍贵 | **只留保底一份**，其余丢在墓里 |
| 每周次数 | 与另两档**共用**次数池，见第七节 | 同左 | 同左 |

浅探是教地图怎么走的，不是肝点。绝境是给已经嫌大世界怪不够咬的人。

进入门槛跟等级挂钩，**不跟门票绑死**。浅探可以纯银两（或免费，待拍板）；
深入、绝境再收「摸金令」一类门票，令可以从日常、打怪碎片、浅探结算里来。
这和秘境的门票是两路东西，别做成同一张票进两个门。

## 三、地图：三层，每层多点，最终一条道

杀戮尖塔那张图搬过来，压成文字游戏吃得下的尺寸。

### 一层长这样

每层 **5 列**：

```
列 0        列 1        列 2        列 3        列 4
入口商店 ── 2～3 个点 ── 2～3 个点 ── 2～3 个点 ── 层主（唯一）
```

- 列 0 **永远是商店**。刚下到这一层，先买药、卖多余丹药、看情报。
- 列 1～3 是分叉。每个点只连向**下一列的 1～2 个点**，不能回头，不能斜着跳列。
- 列 4 **永远只有一个层主**。所有活路都汇到他这儿——这就是「最终直通向一个重点」。
- 列 2 或列 3 **至少保证有一个商店**（不一定你走得到，但图上存在）。浅探保证你的路上至少碰到一个；绝境不保证。

生成时先铺层主，再往回长枝，最后保证从入口到层主至少有两条不完全重合的路。
这样「选路」是真的：左边多休整、右边多精英和宝库。

```
第一层示例（深入）

  [入口商店]
    ├────────┐
  普通战    未知
    │      ╱  ╲
  商店   精锐   普通战
    ╲     │    ╱
      休整 / 宝库     ← 你只能走到与当前点相连的那些
           ╲  ╱
          墓奴头领
```

第三层的层主换成禁地主，打赢 = 本局通关，进入结算。
第一、二层打赢层主 = 下到下一层，气血**不回满**（只按难度给一截回复，见下），冥钱和奇物带着走。

| 过层回复 | 浅探 | 深入 | 绝境 |
|---|---|---|---|
| 气血 | 回 50% 已损 | 回 30% 已损 | 回 15% 已损 |
| 内力 | 回满 | 回满 | 回 50% |

逼你在「这层打得残，要不要在入口商店把钱砸在药上」里做决定。

## 四、节点类型

战斗全部走现有 `combat.js` 的 1v1。禁地里的怪是另一套表，不跟竹林毛贼混用。

| 记号 | 类型 | 进去发生什么 | 打完／完成后 |
|---|---|---|---|
| 战 | 普通战 | 一只与本层、本难度匹配的墓怪 | 掉冥钱；小概率普通材料 |
| 锐 | 精锐 | 更硬，带一条词缀（反伤、吸血、先手晕……） | 必给「3 选 1 奇物」+ 更多冥钱；有机会掉珍贵材料 |
| 主 | 层主 / 禁地主 | 本层唯一终点，有阶段描述 | 层主：过层。禁地主：通关结算。必给强奇物或一份珍贵材料 |
| 店 | 商店 | 见第五节 | — |
| 息 | 休整 | 打坐一炷香：回 30% 气血，**不耗大世界打坐** | 也可花冥钱「磨刀」：本局攻击小幅提升（每局限一次） |
| 宝 | 宝库 | 开石匣，无战斗 | 材料；绝境有几率出本禁地独有材料 |
| ？ | 未知 / 奇遇 | 一段江湖文本 + 2～3 个选项 | 可能变成战斗、商店、白给、掉血、得奇物。选项写后果倾向，**不暗改概率**（原则六：诚实） |

未知揭开之后，这个点在地图上改成它真正的类型，方便回顾。

**不去做的节点**：多人同屏、走位、陷阱格子、需要盯 CD 的持续作战。
文字游戏里一次点击一个点，打完再选，节奏才跟得上「挂着也能聊」。

### 选路规则

你站在点 A。只有 A 连出去的点能点。点下去就开战／进店／读奇遇，**不能反悔**。
打输 = 本局失败（见第六节），不是退回上一个点。

## 五、进门选物，和本局里的「装备」

大世界的兵器、护体、武功**原样带进禁地**，不在进门时卸光重选。
否则玩家会觉得「我打造了半天，进去作废」，跟现有养成打架。

进门多的是一层 **本局才有效的奇物**——对应杀戮尖塔的遗物，不是换一把刀。

### 整备：5 选 2

进门时从本禁地的奇物池里随机抽出 5 件，**选 2 件**带入。没选上的本局再见不到。

奇物是被动，不占行囊格。效果写短、写明白。例（数值后补，这里定**种类**）：

| 奇物 | 干什么 | 适合谁 |
|---|---|---|
| 摸金符 | 宝库、精锐、层主的材料多一份 | 冲材料 |
| 盗泉壶 | 商店伤药半价 | 残血贪路线 |
| 纸人替身 | 本局第一次本应战死时，气血回到 30%，替身烧掉 | 学绝境、保底 |
| 血玉扳指 | 击杀回 8% 气血 | 连战、少休整 |
| 阴风步 | 每场普通战开始你先白打一记（必中、伤害低） | 磨普通怪 |
| 腐尸胆 | 精锐战攻击 +15%，休整回血减半 | 走精英线 |
| 哑巴铃 | 下一列节点类型对你隐藏，掉落 +25% | 赌 |
| 重铸锤 | 可在任意商店花冥钱给本局兵器临时 +1（出禁地消失） | 养成不够、本局硬刚 |

绝境整备多一步：5 选 2 之后，再从 3 件**凶物**里必须拿 1 件。
凶物强，但带刺（例如「冥钱获取 +40%，商店不再出售伤药」）。
这是地狱难度的「再上一层锁」，不是把怪的数值再乘一次就完事。

### 本局里还会再拿到东西

| 来源 | 给什么 |
|---|---|
| 普通战 | 冥钱；偶尔普通材料。**不强制弹 3 选 1**，少一层必点 |
| 精锐 | 3 选 1 奇物 |
| 层主 | 3 选 1 强奇物，或直接给材料 |
| 商店 | 伤药、情报（揭开下一列类型）、奇物、把普通材料换成珍贵的配方 |
| 宝库 / 奇遇 | 材料或奇物 |

**伤药是本局丹药**，不进大世界行囊，出禁地作废。
大世界金疮药带不进来——禁地补给只走冥钱，避免「把客栈库存倒进去无限刷」。

本局获得的奇物同样出禁地消失。玩家带出来的只有：**材料、少量银两、以及「通关过」这类记录。**

## 六、死了、跑了、掉线

禁地里的死 ≠ 大世界死。不要套「丢 5% 经验、抬回客栈」那套（那是大世界主动打架的惩罚，见[经济与成本](经济与成本.md)）。

| 情况 | 结果 |
|---|---|
| 战斗气血归零 | 本局失败。按难度带出一部分已搜刮材料（第二节那张表）。不掉大世界装备、不掉经验 |
| 自己点「撤出禁地」 | 与失败相同。已经打过的层主**不算通关**，没有通关奖励 |
| 掉线 / 关页 | 局冻结在当前节点。再上线还在这儿，怪的血重开（避免卡在半场） |
| 冻结超过 24 小时 | 按失败结算，避免存档里挂一堆僵尸局 |

纸人替身之类的奇物在「气血归零」时先触发，不直接判负。

## 七、经济：进什么、出什么、怎么卡住

先答[经济与成本](经济与成本.md)的三问，再谈奖励。

### 1. 产出是泡点的几倍？

禁地**不给经验**，或只给「通关一次相当于同等级泡点 10～15 分钟」的量，且有周帽。
主食是**材料**，不是升级。升级还是泡点的事，别再开一条无上限的经验管。

银两：每局结算给一截，按难度和层数，量级对准「同等级打 8～12 场野怪」，
不要对准打 100 场。

### 2. 上限在哪？

```
每周次数池    4 次（浅探 / 深入 / 绝境共用）
攒存上限      8 次（两周量，出差回来能补）
刷新          凌晨 5 点，与日常任务同一套钟
材料周帽      每种禁地独有材料每周带出有上限（例：阴晶 20、古金丝 4）
```

次数可攒、不做不罚，和[任务系统](任务系统.md)同一哲学。
绝境也吃这 4 次——你要肝地狱，就少走浅探，这是选择不是第二套体力。

### 3. 回收在哪？

禁地独有材料的去处要在做禁地之前写死，否则又是只发不收：

| 材料 | 哪来 | 去哪（回收） |
|---|---|---|
| 阴晶 | 乱葬岗古墓普通／精锐 | 乱葬岗相关打造、夜栖类消耗，或兑换摸金令 |
| 古金丝 | 宝库、层主，深入以上 | **现有打造 +9 之上的新档**，或一件「禁地限定」护体图纸 |
| 镇墓泥 | 绝境禁地主 | 更稀的图纸／称号，每周帽极低 |

大世界已经在掉的精铁、玄晶，禁地里**只当边角**，不要让禁地变成玄晶工厂。
珍贵的定义是：大世界场景打不到，只能从禁地带出来。

**冥钱**只在本局流通，出禁地带不走，避免多一种要通胀的货币。

门票（摸金令）：打怪碎片合成 + 日常保底，走秘境门票同一思路，但是**另一种道具**。

## 八、第一张禁地：乱葬岗古墓

世界观上就是洛阳城外那片坟地往下挖。夜里磷火、摸金、镇墓，跟[地图系统](地图系统.md)里乱葬岗的 `risk / night / mat` 对得上。
幽潮、海外传承先别塞进第一张，留给后面第二张「断潮沉船」之类。

### 三层叙事

| 层 | 名字 | 层主 | 气味 |
|---|---|---|---|
| 一 | 盗洞 | 墓奴头领 | 新挖的洞、贼人、散乱殉葬 |
| 二 | 墓道 | 镇墓兽 | 机关、石俑、越走越安静 |
| 三 | 主室 | 古墓主人 | 棺、铭文、真正的陪葬 |

普通怪、精锐、奇遇文本都围着「盗墓 / 镇墓 / 不该惊动的东西」，
不要写成通用地下城刷怪房。

### 入口放哪

第一版：乱葬岗场景里一个常驻出口「墓道向下」。
乱葬岗本身还没做的话，临时挂在洛阳官道或城隍庙告示上，地图扩到乱葬岗再挪回去。

## 九、和现有系统怎么接

```
gamedata/dungeons.js     禁地配置：层、节点权重、怪、奇物、奇遇、商店货
gamedata/dungeon_mobs.js 禁地专用怪（或并进 mobs.js 但打标 dungeon:true）
server/dungeon.js        生成图、走点、结算、次数；站在 combat 之后、commands 之前
```

- 战斗：调现有 `combat.js`，对手换成禁地怪；掉落不要走大世界 `DROP`，走禁地自己的表。
- 泡点：进禁地 `stopIdle`，出来再 `autoIdle`。
- 行囊：本局材料先记在 `p.dungeon.run` 上，结算时再进 `p.mats`，受周帽裁剪。
- 频道：人还在世界／本地频道。地点显示禁地名单层。
- 切磋／悬赏／赶路：局里禁用。
- 存档：整局写进玩家对象，关服再上线能续。

前端：中栏用现有房间文案位；左下角去处改成本层 ASCII／文字树。
**不加新框架**，继续零构建。

## 十、第一版做什么，以后再做什么

### 第一版就这些

- 一张禁地（乱葬岗古墓），三层，三档难度
- 节点：战、锐、主、店、息、宝、未知
- 整备 5 选 2；绝境加一件凶物
- 次数池 + 材料周帽 + 失败分档带出
- 局内存档、掉线可续

### 明确不做（第一版）

- 组队进同一张图（战斗是 1v1，硬做会变成两套战斗）
- 卡组、牌、能量
- 禁地里换大世界兵器（用奇物表达本局构筑）
- 第二张、第三张禁地
- 赛季、外层永久天赋树（那是另一套养成，跟[门派天赋](talent-system.md)重叠）
- 把秘境和禁地合成一个入口

### 以后可以长的

- 第二张：断潮沉船（接[世界观](worldbuilding.md)幽潮），节点表换皮、奇物换池
- 通关记录、绝境层数、全服「谁先开棺」
- 禁地限定图纸进打造
- 两人前后进入同一层、不能同场，但能在频道里报点（极轻的社交）

## 十一、长期闭环补充：让每一局都留下东西

禁地的材料和银两是短期收益，但还需要一条**不直接堆战力的永久推进线**。
否则玩家第一次通关后，剩下的就只是每周把四次次数用完。

### 11.1 失败也要有进度

无论通关还是失败，都记录一份「禁地见闻」：

- 首次遇到某种怪、奇遇、机关、层主时，解锁禁地图录
- 发现某条特殊路线后，永久显示一条模糊提示（不直接告诉最优解）
- 带出或见过某件奇物后，加入奇物图鉴；部分奇物进入后续抽取池
- 触发关键奇遇后，推进墓主人、盗墓贼或镇墓人的支线文本
- 首次通关、绝境通关、无伤过层等，奖励称号、家园陈列品或频道标记

这些奖励只扩大内容、收藏和表达，不另做一棵永久属性树，避免和[门派天赋](talent-system.md)重叠。

### 11.2 层主必须有自己的规则

「血量更高 + 一条词缀」只能作为基础差异。每个层主至少有一条会改变决策的专属规则：

- 墓奴头领：战斗中会召来一名残兵，优先处理谁会影响后续伤害
- 镇墓兽：受到某类招式后进入不同状态，逼玩家调整出招顺序
- 古墓主人：每隔若干回合封存一种补给或改变场上效果

每个层主建议两阶段，第二阶段只增加一个新规则，不做单纯的数值翻倍。
这样玩家记住的是「这位 Boss 怎么打」，而不是「它的血有多少」。

### 11.3 挑战诏令：同一张图的第二种玩法

在进入禁地前，可以从若干条本周诏令中选择一条，主动接受限制来换取额外奖励：

- 不允许使用休整节点
- 精锐节点增加，但精锐掉落提高
- 所有未知节点改为两选一，并显示后果倾向
- 每层只允许购买一次补给

诏令使用现有次数池，不额外增加次数，也不产出永久战斗属性。奖励优先给禁地材料、图鉴进度、称号和家园纪念品。
诏令的目标是让熟悉地图的人继续有选择，不是把它变成每周必做的最优答案。

### 11.4 轻量异步社交

禁地仍然保持单人战斗，但可以共享少量信息：

- 每周一张「共鸣地图」：所有人使用同一张节点种子，比较路线和层数
- 频道公布首通、最快通关、最高诏令和极品奇遇
- 通关后可以留下本局路线摘要，其他玩家只能看到选择过的节点和最终结果
- 极少数稀有战利品转化为家园可展示的墓碑、壁画、灯具或标本

不做实时组队、不做同屏抢怪；社交重点是讨论路线、炫耀结果和交换经验。

### 11.5 和家园互相导流

禁地和家园的关系不只停留在「禁地产材料，家园炼材料」：

- 禁地掉落的残片可以解锁家园主题装饰或特殊陈列柜
- 家园炼制的少量消耗品可以改变禁地路线选择，但不能直接提高面板战力
- 某些藏宝图、稀有种子和家园访客事件由禁地见闻解锁
- 家园中的访客可以评论玩家展示的禁地战利品，形成可见的经历记录

这样，禁地提供故事和稀有收藏，家园负责展示和延续关系。

## 待拍板

1. **浅探收不收门票？** 免费教规则更稳；收很少银两也能当回收口。
2. **禁地给不给经验？** 倾向「通关给一截、有周帽、绝不按怪给」。否决「每场都给大世界经验」。
3. **每周 4 次够不够？** 一局约 12～15 场战斗，主动玩大约一刻钟。4 次是一周的高光，不是日常。
4. **失败带出比例** 第二节那组 50% / 30% / 保底，会不会让绝境没人敢点？若太狠，绝境失败改为「已过层的材料全留，本层的丢」。
5. **入口挂在哪** 等乱葬岗场景有没有跟期 2 一起做。没有就先挂官道。
6. **金疮药到底隔不隔得住？** 本文按「大世界药带不进」写。若觉得狠，可改成「带得进但效力减半，且禁地里买不到大世界药」。
7. **要不要本局临时兵器？** 现在用奇物代替「选几个装备」。若你更想进门从三把墓中兵刃里选一把替换本局武器，整备段改成「1 兵器 + 2 奇物」。
8. **失败见闻是否永久保存？** 建议保存；失败也应推进图鉴、剧情和收藏，不只按比例带出材料。
9. **第一张禁地的三位层主各自规则是什么？** 每位至少确定一条改变决策的规则，再开始填数值。
10. **挑战诏令按周轮换还是玩家自选？** 建议每周轮换 3 条，进入前任选 1 条，不增加次数池。
11. **是否做每周共鸣地图？** 建议做，作为单人禁地的异步社交入口，不共享战斗现场。
