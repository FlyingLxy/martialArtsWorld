# 待确认清单（数值基准 → 战斗/天赋）

数值基准这边定完了骨架，有 5 处碰到你的地盘。前 3 条点个头就行，后 2 条要动手。

## 1. 四维属性叫什么？

天赋文档引用过"角色四维属性"，但只出现过「身法」「悟性」两个，另外两维没列全。
提案：**力道 / 身法 / 根骨 / 元息**

- 「元息」来自你写的世界观第三节（四海会馆对内力、魔力、圣息、忍气的统称），
  比我原来编的「元气」好——我们有五个海外门派，奥术学院顶着「元气」条会别扭。
- 「悟性」换成「元息」后，天赋里那条「每 20 点悟性使剑法伤害 +1%」照搬，效果不变。

**要你确认**：这四个名字行不行。

## 2. 身法决定出手顺序

你战斗文档 3.1／3.2 已经是这么写的（优先级 > 身法 > 可复现随机），我只是对齐。
另外**暴击率也挂在身法上**——回合制里先手就是一切，这一维因此永远不会变成废维。

**要你确认**：暴击挂身法有没有问题。

## 3. 「气贯长剑」的属性归属

现在写的是「每 20 点悟性使**剑法**直接伤害 +1%」。改名后成了"元息提升外功剑伤"，
和"元息主管内功"看着有点冲突——但这招名字就叫**气贯长剑**，气灌进剑里，反而更贴。

**建议保留**，并在元息定义里写明"允许天赋做转化"，华山剑气流正好占这个设计位。

## 4. 战斗里有没有「冷却缩减」？

元息的产出之一是冷却缩减，但你文档第 6 节只写了冷却的登记与推进，没有缩减机制。

**要你回答**：支不支持？不支持的话元息少三分之一产出，我换一项（比如内功穿防）。

## 5. 平衡模拟需要加一档「满装」

这条工作量最大，但不急，**在装备数值填完之后**再跑。

模拟基线 6.1 是 `1200／112／42／100`、暴击 8%——**这只代表裸装**。
而我们定了满级装备占战力 65%、暴击主要来自装备，**满装玩家暴击可能 30%+**。

意味着现有全部结论（含切磋 19.32 回合）只在裸装下成立。而天赋里
「心如磐石」（减暴伤）、「剑到人亡」（+15 百分点暴击）、「借势翻身」（受暴击触发）
三个节点直接吃暴击，强度会随装备大幅漂移——**裸装平衡不等于满装平衡**。

**要你做**：模拟增加至少两档（裸装 / 满装）全量复验。已写成装备上线的硬关卡。

## 附：一个可能被误读的数

推出来的满级战力构成里，**天赋占 18%**，装备占 56.4%。

**这个 18% 只算数值。** 天赋里大量内容是机制——触发、控制、资源转化、
暴击伤害转换，「借势翻身」这类节点根本没法折成百分数。
别拿这个数论证天赋不重要，文档里也特意写了这句。

顺带：非装备那 43.6% 内部怎么切（等级 15% / 属性点 10.6% / 天赋 18%）动到你的地盘，
这个比例你也看一下。
