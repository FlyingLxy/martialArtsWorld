# 见闻与收藏（见闻线）

[五条追求线](玩法与核心循环.md)里的**见闻**线，回答的问题是「你知道什么」。

它同时是[原则第十条](原则.md)"明线公开、真相散落"的**承载装置**——
碎片化叙事要成立，必须有个地方让玩家**回看已经见过的碎片**，
否则"散落"就只是"丢失"。

## 一、核心机制：见闻自动记录

**玩家不需要主动收集。** 见过就记下：

| 行为 | 自动记入 |
|---|---|
| 进入一个场景 | 场景志 + 该场景的描述文本 |
| 击杀一种怪 | 五族图鉴对应条目 |
| 拿到／看到一件装备 | 器物志（包括别人展示的） |
| 触发一段重要对话 | 见闻录·对话 |
| 见到一门招式被使用 | 见闻录·招式（包括别人对你用的） |
| 钓上一种鱼 / 采到一种草药 | 鱼谱 / 草药谱 |
| 拾得一页残卷 | 案卷·残页 |

**这是挂机本位的必然设计**（[玩法与核心循环](玩法与核心循环.md)）：
如果见闻要专门去"采集"，它就变成了第三件必做的事。
自动记录之后，**主动的部分只剩"补全缺口"**——
而缺口本身就是探索的动力。

### 它顺带是这个游戏的说明书

见闻录里的条目**要写得值得读**——怪物的习性、装备的来历、
场景的旧事。于是玩家不用去翻外部攻略站，
**游戏里就有一本自己写的百科**，而且是自己走出来的。

### 五族图鉴的额外作用

图鉴条目里**记录该族的行为库**（呼唤同伴、复起、幻影……）。
所以图鉴不只是收集，**它就是攻略**：
打过一次亡灵，你才知道它会「复起」，下次就不会白高兴。

这让[怪物与掉落](怪物与掉落.md)的族系设计多了一层价值：
族系是玩法差异，也是收集单位，还是知识本身。

## 三、案卷与残页：碎片化叙事的实现

按[原则第十条](原则.md)的三层信息：

| 层 | 放在哪 | 玩家怎么拿到 |
|---|---|---|
| **公开事实** | 主线任务、必经 NPC | 做主线就知道 |
| **可证真相** | **案卷·残页**、装备描述、场景描述 | 至少两条不同来源相互印证 |
| **未定猜想** | 单方记载、矛盾口供 | 收集了也不会有官方答案 |

### 三条防线（原则第十条的硬要求）

1. **任务目标、地图入口、关键操作不藏在残页里。** 残页只承载"为什么"，
   不承载"怎么做"。
2. **会改变主要结论的真相，不得只有一条可错过的证据。**
   每条关键真相至少铺两处，且至少一处是不可错过的。
3. **残页奖励是新对话、案卷、称号，不是战力。**

### 「相互印证」怎么做

同一件事，两处记载不完全一致：

```
函谷驿的通关文书记载    某年某月，一支商队西行，未归。
崤山旧道的石刻          同年，山道塌方，封路半年。

两条对上 → 玩家自己推出：那支商队根本没走成，
           那"未归"的记录是谁写的？
```

**这比直接告诉玩家答案有意思得多**，而且它不需要额外系统——
只需要写文案时有意留下可对照的细节。

## 四、完成度与展示

见闻线的展示位（[名望线地价规则](成就与称号.md)）：

| 展示面 | 放什么 |
|---|---|
| 名字颜色 | **青**（集齐任一整本） |
| 称号 | 各册的集齐称号 |
| **江湖名帖** | 七本册子的完成度进度条 |
| 风云榜·见闻 | 总完成度排名 |
| [四海会馆](场景卡全集.md) | 案卷交付与查阅点；学者会对你的发现有反应 |

**四海会馆是见闻线的"家"**——世界观里它就是研究元息的地方。
玩家把残页交上去，学者给出解读（有时是错的解读，这也符合原则第十条）。

## 五、跟别的线的边界

| 边界 | 说明 |
|---|---|
| 见闻 ≠ 战力 | 集齐图鉴不给属性，一点都不给 |
| 见闻 ≠ 名望 | 见闻是"你知道什么"，名望是"别人知道你" |
| 见闻可以喂任务 | [任务系统](任务系统.md)可用图鉴完成度做门槛 |
| 见闻**不能被交易** | 你不能买一本填好的图鉴——这是它跟家业线的根本区别 |

**"不能买"是见闻线唯一的护城河。** 银两能买材料、买装备、买服务，
但买不到"你去过哪、见过什么"。这条一旦破了，见闻线就变成家业线的附属品。

## 待拍板

1. **器物志约 200 条，文案量是最大的一块。** 建议首发只做兵器和佩饰，
   护甲类先用统一模板。
2. **别人展示的装备算不算"见过"？** 算的话，市场逛一圈就能刷图鉴；
   不算的话，收集会很慢。倾向**算，但只算实际交易或穿戴出现在你面前的**。
3. **残页要不要能交易？** 不能交易则收集纯靠自己（护城河牢固），
   能交易则市场更活跃。倾向**不能**，理由见第五节。
4. **见闻录条目要不要限制字数？** 太长没人读，太短没味道。建议 60~120 字。
5. **四海会馆学者给的解读会有错的**，要不要明确标出哪些是"学者的看法"？
   标了就少了迷惑性，不标可能被当成官方答案。
