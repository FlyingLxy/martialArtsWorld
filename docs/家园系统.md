# 家园系统

> 状态：玩法草案。先把「挂着能干嘛、产出怎么进战斗」写清楚，数值后补。
>
> 关联：[设计原则](原则.md)、[经济与成本](经济与成本.md)、[地图系统](地图系统.md)、[任务系统](任务系统.md)

## 为什么要做

现在材料几乎只靠**打怪掉**（精铁 35%、玄晶看怪等级），打造是唯一的无底洞回收口，
但**主动刷怪几乎没成本**——药白掉、打坐无限回、死亡不痛（见[经济与成本](经济与成本.md)）。
结果是：要么刷爆，要么懒得刷、打造卡材料。

缺一条**不抢泡点、不逼人盯屏、但能让后勤有存在感**的路：

- 挂着也能推进（种菜要时间、鱼塘能挂、熔炉能排队）
- 产出**直接服务战斗**（回血丹、短时增益、炼制用的矿料），不是第二套经验
- 跟大世界打通：各地打坐能摸到低档矿石，家园负责**收拢、炼化、变成能用的东西**
- **别人能来你的院子**——偷菜、偷矿、雇短工（见第八节）；**钓鱼本身**则是主动小玩法（见第四节）

它必须过[设计原则](原则.md)这几关：

- **不盯着也能活**：生长、垂钓、熔炼都是时间活，上线收一收就行
- **不上线不亏**：作物会枯、鱼塘有上限，但**没有「今天不浇就永久损失」的打卡惩罚**
- **产出有上限**：地块数、熔炉队列、每日收获帽，见第七节
- **先想回收再想产出**：种子、燃料、维护费都是银子出去的路

## 一、家园是什么

每个玩家有一座**私宅**，逻辑上是一个独立场景（「某某的宅院」），
从悦来客栈或本门后山点「回宅」进入。在宅子里：

- **不能泡点**（没有 `paodian`）——避免「家园 = 更舒服的泡点场」
- **不能打怪**
- **江湖频道照收**，人还在聊天室里，只是地点显示成「张无忌的宅院」
- 打架、械斗、禁地等**自动收功**，跟离开泡点场景一样

### 解锁

| 条件 | 说明 |
|---|---|
| 等级 ≥ 15 | 跟「后山瀑布」泡点档衔接，新手期先熟悉大世界 |
| 完成引导任务「安家」 | 悦来客栈掌柜给地契，教第一次播种 |
| 花 500 两修葺 | 一次性开销，也是早期回收 |

**待拍板**：15 级会不会太早？要不要绑「拜入门派后」？

### 宅院分区

```
┌─────────────────────────────────────────┐
│  【张无忌的宅院】                        │
│                                         │
│  ┌──────┐ ┌──────┐   ┌─────────────┐   │
│  │ 菜园 │ │ 药圃 │   │    鱼塘     │   │
│  │ 4 格 │ │ 3 格 │   │  竿钓 / 挂网 │   │
│  └──────┘ └──────┘   └─────────────┘   │
│                                         │
│  ┌──────────────┐  ┌────────────────┐  │
│  │  熔炉 · 砧台  │  │  库房（材料）   │  │
│  │  炼矿 · 炼丹  │  │  不占行囊格     │  │
│  └──────────────┘  └────────────────┘  │
│                                         │
│  晒矿场（可被偷）  ·  门房告示（发雇工）  │
└─────────────────────────────────────────┘
```

## 二、菜园：菜

**定位**：短周期、给**气血／内力恢复**和**轻量战斗增益**，不是经验来源。

### 流程

```
买种 → 占一格 → 等待生长（真实时间）→ 收获 → 入库房或行囊
```

| 作物 | 生长时间 | Combat 用途 | 种子价 |
|---|---|---|---|
| 白菜 | 2 小时 | 食用回 15% 气血 | 10 两 |
| 辣椒 | 4 小时 | 下一场战斗攻击 +3%（1 次） | 25 两 |
| 莲藕 | 6 小时 | 食用回 20% 内力 | 30 两 |
| 老姜 | 8 小时 | 解毒一次（消一层毒／灼烧） | 40 两 |

- 默认 **4 块菜地**，升级宅院可扩到 6 块（花银子 + 帮贡，见第七节）
- 生长**离线照样走**；超过成熟时间 24 小时未收，**枯萎**（产物没了，地空出来）
  - 这是「鼓励偶尔上线」，不是「每天必须打卡」——24 小时很宽，且只损失这一格
- 不浇水、不施肥也能长（**别加 micromanagement**）；可选「施粪」花 5 两缩 20% 时间

### 跟战斗的接口

- 菜进**库房**，战斗外从宅院吃，或在大世界「行囊 → 食袋」里用（占 1 个食袋位，上限 5）
- **比金疮药便宜但弱**：金疮药 30 两回 35% 气血且现在会掉；菜是后勤替代，不抢药店的回收意义
- 辣椒、老姜提供**打怪缺的东西**（微增益、解状态），让「先回宅收菜再出门」有理由

## 三、药圃：草药

**定位**：中周期、产**炼丹原料**，跟泡点奇遇里的「石缝赤草」一条线。

### 跟现有内容的衔接

`gamedata/flavor.js` 里已有泡点奇遇 `{t:'herb'}`：「石缝里一株赤红草药，采下服了」——
那是**即时小收益**。药圃是**可规划的草药来源**，两者不冲突：

| 来源 | 特点 |
|---|---|
| 泡点奇遇 | 随机、即时、量小 |
| 药圃 | 选定品种、定时收、量稳定 |
| 地图 `mat` | 稀有品种、要跑特定场景 |

### 药圃格与品种

默认 **3 格**，品种示例：

| 草药 | 生长 | 炼制去向 | 解锁 |
|---|---|---|---|
| 赤参 | 6 小时 | **回气丹**（回 25% 内力，战斗可用） | 默认 |
| 当归 | 8 小时 | **止血散**（回 20% 气血） | 默认 |
| 银翘 | 12 小时 | **解毒丸** | 药圃 2 级 |
| 雪莲 | 24 小时 | **破境丹**（+5% 经验，仅泡点生效 1 小时） | 任务链 |
| 朱砂草 | 12 小时 | 熔炉：**朱砂粉**（打造 +6～+7 成功率 +2%） | 乱葬岗 mat 换种 |

- 雪莲的泡点 buff **刻意做弱**，避免家园抢泡点主场
- 稀有种子的获取绑地图 `mat`、任务、禁地，给「跑大世界」留理由

## 四、钓鱼（参考星露谷）

**定位**：这游戏里**少数值得主动点几下**的玩法——星露谷钓鱼的精髓是「遛鱼条」，
不是挂机收网。钓上来的不只是食材，还有**宝箱、藏宝图**，把玩家拽进大世界挖宝。

### 4.1 两种钓法（主被动分开）

| 方式 | 操作 | 适合谁 | 产出档次 |
|---|---|---|---|
| **挂网** | 点一次「下网」，离开也行 | 懒人、睡前 | 杂鱼、虾壳，**不出藏宝图** |
| **持竿** | 人在水边，进「遛鱼」小游戏 | 愿意玩的人 | 全鱼种 + 宝箱 + 图 |

挂网保留，但** deliberately 无聊**——好货都在持竿里。跟泡点不冲突：持竿时**不算泡点**（人在动），挂网时若在家园则也不泡点。

**可钓鱼的水边**（不止宅院）：

| 地点 | 特色鱼 | 备注 |
|---|---|---|
| 自家鱼塘 | 入门鱼种 | 解锁后默认有 |
| 洛阳·码头 | 海鱼、河海杂类 | 任务链常来 |
| 黑水沼 | 毒鳝、墨鱼 | 夜钓加成 |
| 塞北·风雪谷 | 冰鲈 | 需耐寒药或高等级 |
| 西域·星宿海 | 怪鱼 | 稀有图碎片 |

### 4.2 持竿流程（星露谷式遛鱼）

```
抛竿 → 等咬钩（3～15 秒，文字倒计时）→ 咬钩！进入遛鱼条 → 成功入篓 / 脱钩
```

#### 遛鱼条（前端小 UI，中间面板）

星露谷是**竖条**：鱼 icon 上下窜，绿色「受力区」跟着玩家按键移动。
这里改成**横条**，更适合本游戏宽布局：

```
  ┌─ 遛鱼 ─────────────────────────────────────┐
  │  [═══════绿色受力区═══════]                 │
  │            ◆ 鱼                            │
  │  张力 ████████░░░░░░  （超出则线断）          │
  │  [收线] 按住向上拉区  [放线] 按住向下让区跟鱼 │
  └────────────────────────────────────────────┘
```

| 要素 | 说明 |
|---|---|
| 绿色区 | 玩家用 **收线／放线**（鼠标按住或键盘 A/D）让区跟着鱼游 |
| 鱼 | 每 0.3～0.8 秒换向、加速，难度高的鱼窜得更凶 |
| 张力 | 区与鱼重叠时张力涨、脱钩倒计时缩短；离开太久张力也涨 → **线断** |
| 进度 | 区与鱼重叠累计「遛顺」进度，满 100% 起鱼 |
| 时长 | 简单鱼 8～15 秒，传奇鱼 40～60 秒 |

**文字版 fallback**（无 JS 时）：每 2 秒出一道「鱼往左／往右」题，点对 +15 进度，连错 3 次脱钩。

#### 钓功等级

| 等级 | 经验来源 | 效果 |
|---|---|---|
| 1～10 | 每条鱼按难度 +1～+5 | 绿色区 **+宽**、张力 **-涨速** |
| 满级额外 | — | 宝箱出现率 +5% |

钓功**只服务钓鱼**，不加战斗属性——避免又一挂数值。

### 4.3 鱼种表（示例）

难度 = 遛鱼条参数；跟 **时辰**（见[地图系统](地图系统.md)待拍板的昼夜）、**天气**（后续）可再叠。

| 鱼 | 难度 | 常见水域 | 用途 |
|---|---|---|---|
| 鲫鱼 | ★ | 鱼塘、码头 | 做菜 +2% 气血上限 |
| 泥鳅 | ★ | 鱼塘 | 炼丹「滑骨散」 |
| 黄鳝 | ★★ | 码头 | 软筋索（必中 +1） |
| 河蚌 | ★★ | 挂网／竿 | 开蚌 → 珍珠 |
| 铁骨鱼 | ★★★ | 码头夜 | 铁骨粉 → 精铁 |
| 乌鳢 | ★★★ | 黑水沼 | 毒性材料 |
| 冰鲈 | ★★★★ | 风雪谷 | 寒石伴生 |
| 星纹鳗 | ★★★★★ | 星宿海 | 卖店 500 两或炼玄晶辅材 |
| **古鉴鱼** | ★★★★ | 任意 | 剖肚 **必出残页**（藏宝图碎片） |

### 4.4 宝箱与藏宝图

咬钩后，除普通鱼外有 **独立判定**（与鱼种并行，不互斥）：

```
P(宝箱) = 3% + 钓功等级×0.3% + 使用鱼饵×2%
```

钩上来的是**宝箱**时，遛鱼条换成「沉箱」——区更窄、张力涨更快，但**不失败也能重钓**。

起箱后二选一（星露谷经典）：

| 选项 | 结果 |
|---|---|
| **开箱** | 银两、材料、**藏宝图**、旧装备、垃圾（湿鞋） |
| **扔回** | 无事；传说鱼爱好者会扔，这里一般人都开 |

**藏宝图**种类：

| 图 | 线索示例 | 挖点场景 | 典型宝藏 |
|---|---|---|---|
| 杏花村图 | 「三棵老槐，面向瀑布方向七步」 | 老槐树下 | 50～200 两 + 精铁 |
| 洛阳图 | 「城隍庙后墙，第三块松砖」 | 城隍庙 | 药种、丹方 |
| 乱葬岗图 | 「磷火最亮处往下三尺」 | 乱葬岗 | 阴晶矿、奇物残片 |
| 塞北图 | 「烽火台西北角，雪最厚处」 | 烽火台 | 寒石、装备 |
| 无名谷图 | 「剑冢断碑之下」 | 剑冢 | 高阶材料（需解锁场景） |

图进 **行囊「图囊」**（上限 5，可叠同类未挖的）。

### 4.5 挖宝

到图所指 **场景** 后，多一个指令 **「挖掘」**（或 `dig`）。

```
读图 → 场景匹配？ → 是 → 挖（消耗 1 图，30 秒读条，可被打断）
                  → 否 → 「此地不对，图上的标记对不上。」
```

| 规则 | 说明 |
|---|---|
| 场景必须对 | 精确到 `map.js` 里的 scene id，不是整个区域 |
| 读条 | 30 秒；打架、换场景取消；**挂着读条不算泡点** |
| 同图同点 | 全服无限副本——每人挖自己的图，不抢坑 |
| 失败感 | 5% 空箱：「只挖出一双臭鞋。」 |
| 广播 | 挖出 **玄晶以上** 或 **>3000 两** 等价物 → 江湖频道一条 |

**跟大世界的衔接**：藏宝图是「让人从宅子／码头 **站起来走一趟**」的钩子，
跟任务链解锁隐藏场景不冲突——图可以是隐藏场景的**另一条入口**。

### 4.6 鱼饵与竿（轻量养成）

| 物品 | 来源 | 效果 |
|---|---|---|
| 竹钓竿 | 安家任务送 | 基础 |
| 精钢钓竿 | 铁匠铺 800 两 | 张力上限 +20% |
| 蚯蚓饵 | 菜园 compost / 5 两 | 宝箱率 +2% |
| 面饵 | 悦来客栈 | 简单鱼难度 −1 档 |
| 毒虫饵 | 黑水沼 mat | 毒鳝、乌鳢专用 |

不做得像 RPG 一整页装备——**一竿一饵**足够。

### 4.7 上限与防刷

| 项目 | 上限 |
|---|---|
| 挂网 | 1 网，8 小时产量封顶 |
| 持竿 | **每天成功起鱼 30 条**（脱钩不算）；好鱼不另 cap |
| 宝箱 | 每天 **3 个**（超出仍可钓，但箱变空） |
| 挖宝 | 每天 **5 次** |
| 藏宝图交易 | 可挂集市，跟装备一样抽一成 |

期望：专注钓鱼 **1 小时** ≈ 材料价值 **主动打怪 1～1.5 小时**，但 **零经验**；
藏宝图是大奖方差，平均下来不超过 [经济与成本](经济与成本.md) 的 5 倍泡点材料比。

### 4.8 社交挂钩

| 事件 | 社交效果 |
|---|---|
| 钓到星纹鳗 | 本场景日志：「XXX 钓上来一条星纹鳗，满塘人侧目。」 |
| 挖出大宝 | 江湖频道公告（见上） |
| 雇工 **帮下网** | 仍只做挂网，**不能代遛鱼**——小游戏必须本人 |
| 串门 | 在别人鱼塘边**不能偷鱼**（只偷菜／矿），可围观日志 |

## 五、熔炉与砧台：炼矿炼药

**定位**：把零散原料**合成**成战斗／打造能用的东西。家园是**加工厂**，不是矿场。

### 两条生产线

```
矿线：  原矿 / 矿粉 / 杂材  ──熔炼──→  精铁、玄晶、朱砂粉 …
药线：  草药  ──炼丹──→  回气丹、止血散、解毒丸 …
```

| 配方 | 原料 | 时间 | 产出 | 备注 |
|---|---|---|---|---|
| 炼精铁 | 原矿 ×3 + 木炭 ×1 | 30 分钟 | 精铁 ×1 | 见下节矿石来源 |
| 炼玄晶 | 原矿 ×12 + 硝石 ×2 | 2 小时 | 玄晶 ×1 | 比打怪慢，给非刷怪玩家出路 |
| 回气丹 | 赤参 ×2 | 20 分钟 | 回气丹 ×1 | 战斗可用 |
| 止血散 | 当归 ×2 | 20 分钟 | 止血散 ×1 | |
| 铁骨粉 | 铁骨鱼 ×1 | 15 分钟 | 等价精铁 ×1 | 鱼塘接熔炉 |

- 熔炉 **1 个队列**，宅院升级可开第 2 队列
- 炼丹／炼矿**离线进行**，跟种菜一样
- 每次炼制消耗 **木炭**（商店买或任务给），形成持续小额回收

### 跟打造的衔接

现有 `gamedata/items.js` 里打造只吃 `jing`（精铁）和 `xuan`（玄晶）。
家园**不新增打造等级**，只提供**额外的材料来源**，且：

```
炼 1 精铁 的成本（原矿+木炭+时间） > 打怪掉 1 精铁 的期望时间
```

**主动刷怪的人仍然更快**；挂家的人慢，但不至于永远 +4 卡住。

## 六、矿石从哪来：大世界打坐 + 家园

用户要求：**其他场景打坐也能获取基本矿石**。这是刻意设计，用来跟 [地图系统](地图系统.md) 的 `mat` 字段联动。

### ① 通用打坐产矿（任何泡点场景）

只要 `p.idle` 在跑（任意有 `paodian` 的场景），除了经验以外，
**额外**以很低概率摸矿：

```
每 2 分钟 tick 一次判定：
  P(原矿) = 0.02 × 场景系数

场景系数：
  安全区（客栈、竹林）     0.5
  普通泡点（瀑布、后山）     1.0
  高危泡点（乱葬岗 risk）    1.5
  带 mat 的场景              1.0，且 mat 种类影响副产物（见下）
```

- 原矿**不占行囊**，默认进「矿袋」（上限 50，满则不再获得）
- **回到家后**可把矿袋里的矿倒在「晒矿场」晾晒 → 才能被熔炼；晒矿场里的矿**可被来客偷走**（见第八节）
- 锁在库房里的 refined 材料（精铁、丹药等）**不可偷**
- 期望：挂 **8 小时**泡点 ≈ 摸 **4～6 原矿**——够炼 1～2 精铁，是点缀不是主业

### ② 场景 `mat` 独有矿产

地图文档里已有 `mat: {k:'yinjing', rate:0.04}` 一类字段。
在家园上线后，`mat` 表示**该场景打坐额外产哪种原矿／伴生矿**：

| 场景 | mat | 打坐副产 |
|---|---|---|
| 乱葬岗 | yinjing | 阴晶矿（炼丹 + 特殊打造） |
| 黑水沼 | shuiyin | 水银砂（解毒丸加成） |
| 火焰山 | huoshi | 火硝（熔炼加速 10%） |
| 塞北烽火台 | hanshi | 寒石（护甲打造 +1 成功率） |

**要去对的地方挂**，才炼得出对的东西——跟「凭什么待在这儿」一致。

### ③ 家园初矿（可选）

宅院自带 **1 口枯矿坑**，每天可「采一次」给 1～2 原矿，纯引导用。
要不要保留待拍板；太慷慨会变成第二泡点。

## 七、经济：上限与回收

### 产出上限（防刷）

| 项目 | 上限 |
|---|---|
| 菜地／药圃 | 格数固定，枯了要重种 |
| 鱼塘 | 单网 8 小时封顶 |
| 矿袋 | 50 原矿 |
| 库房 | 200 格（只存家园产物） |
| 战斗消耗品携带 | 食袋 5、药袋 5 |
| 每日「吃菜／吃药」战斗 buff | 各 3 次（防无限叠） |

### 回收口

| 消耗 | 说明 |
|---|---|
| 种子、木炭、粪肥 | 持续小额 |
| 宅院升级 | 500 → 2000 → 8000 两 + 材料 |
| 熔炼失败 | 5% 概率炸炉，损失原料（高级配方） |
| 雇工预付 | 工钱托管在契约里，完成才结算；平台抽一成 |
| 防盗设施 | 篱笆、看门犬、矿窖——一次性或维护费 |

### 偷与雇的外溢（不造新币）

偷菜、偷矿都是**转移已有产出**，不是系统新发材料。
雇工是**银子从主户流向短工**，一成抽头凭空消失——跟集市抽头一样。

### 跟泡点的比值（必算）

| 来源 | 8 小时大致等价 |
|---|---|
| 泡点经验 | 基准 1 |
| 家园全套（4 菜 + 3 药 + 1 网 + 熔炉） | **经验 0**；材料 ≈ 主动打怪 **2～4 小时** |
| 打坐摸矿 | 材料 ≈ 打怪 **0.5～1 小时** |

整体 **不超过主动刷怪 5 倍**（见[经济与成本](经济与成本.md)），且**零经验**。

## 八、社交：串门、偷菜、偷矿、雇短工

[设计原则](原则.md) 说社交是目的。家园后勤如果只自己玩，很快又变单机。
所以**社交跟 MVP 一起走**，不是第二版补丁。

核心思路：

- **能串门** —— 制造「我去张三那儿看看」的由头
- **能偷** —— 有风险、有上限、会广播，成为频道里的乐子；不是无成本抢劫
- **能雇** —— 懒得收菜的人花钱，爱折腾的人赚工钱；银子流动，且要人在场或挂名托管

### 8.1 串门

```
悦来客栈 / 同道列表 / 聊天里点人名  →  「拜访宅院」  →  进入对方私宅场景
```

| 规则 | 说明 |
|---|---|
| 谁都能进 | 默认**不上锁**；江湖儿女的宅子，本来就没围墙（可以后升级加锁，见防盗） |
| 主人感知 | 有人进门，主人**个人频道**一条：「令狐冲 摸进了你的宅院。」全服频道不广播 |
| 能做什么 | 看布局、偷（见下）、接雇工、跟主人聊天——**仍在一个聊天室里** |
| 不能做什么 | 动库房锁着的货、拆熔炉、帮主人 **自动** 把东西转进自己包 |

### 8.2 偷菜

只对**已成熟、主人还没收**的菜地／药圃下手。

```
来客点某格「顺手牵羊」
  → 成功率判定（见下）
  → 成功：偷走该格产出的一部分，格子上标记「已被顺过」
  → 失败：空手而归，宅院日志 + 可选「抓个正着」
```

| 参数 | 建议值 | 说明 |
|---|---|---|
| 单次偷取量 | 该格产量的 **40%**（向上取整，至少 1） | 主人回来收，还能剩 **60%** |
| 每格被偷次数 | **1 次** | 偷过就不能再偷同一格 |
| 偷家上限 | 每人每天成功 **5 次**（跨所有宅院） | 防职业小偷 |
| 防偷上限 | 每个宅院每天最多被成功偷 **4 次** | 防把一个人偷秃 |
| 基础成功率 | **55%** | 看脸，不是必成 |
| 主人守家 | 主人在本宅且在线 → 成功率 **−25%** | 鼓励「回家看看」 |
| 看门犬 | 宅院升级 → 再 **−15%** | 花银子买的防盗 |

**抓贼（可选小互动）**：

- 主人守家且偷失败时，50% 概率触发「抓个正着」
- 小偷损失 **20 两**「赔礼」（进主人腰包），并在**本场景日志**刷一条：
  「张无忌 想顺走令狐冲 的辣椒，被当场按住，赔了二十两。」
- **不触发战斗**——这是社交乐子，不是 PVP 副本

**频道怎么说**：

- 成功：**仅宅院场景内**可见——「韦小宝 从 陈近南 的药圃顺走了一株当归。」
- 全服公告只有「恶名」攒够时（见 8.5），避免刷屏

### 8.3 偷矿

偷的是**晒矿场**里堆着的原矿，不是矿袋（在身上）、不是库房里的精铁。

| 参数 | 建议值 |
|---|---|
| 晒矿场上限 | 默认 **15 块**原矿；超出必须收进库房或熔掉 |
| 单次偷取 | **1～2** 块原矿 |
| 成功率 | **45%**（比偷菜低——矿更值钱） |
| 次数 | 跟偷菜**共用**每日 5 次成功上限 |
| 被偷次数 | 跟偷菜**共用**每宅每天 4 次上限 |

**矿窖**（宅院 2 级可建）：

- 花 300 两 + 精铁 ×2
- 矿袋里的原矿可「入窖」→ **不可偷**，但窖容量 **30**，且入窖的矿**不能立刻熔炼**（要先取出晒）
- 取舍：方便偷 vs 安全但麻烦

### 8.4 雇短工

主人懒得种、收、下网、点熔炉时，在**门房告示**发契约；来客**接活**，干完领钱。

#### 契约类型

| 活计 | 主人要什么 | 短工怎么做 | 典型工钱 |
|---|---|---|---|
| **帮种** | 指定空格子种某作物 | 人在宅内点「代种」 | 15～30 两／格 |
| **帮收** | 成熟作物全部入库 | 人在宅内点「代收」 | 10 两／格 + 产出 5% 小费（可选） |
| **帮下网** | 鱼塘下网一次（仅挂网） | 人在宅内操作 | 25 两 |
| **帮炼** | 指定配方进熔炉队列 | 人在宅内点「代炼」（原料从主人库房扣） | 40 两＋木炭费实报 |
| **看家** | 2 小时内防盗 | 短工**在本宅在线**即可，不用一直点 | 80 两／2h |

#### 流程

```
① 主人发契：活计类型、数量、工钱（预付进 escrow）
② 短工拜访 → 「接活」→ 契约绑定在该短工名下（同时只能接 1 单外家活）
③ 短工在宅内完成指定操作 → 系统校验 → 工钱从 escrow 转给短工（抽头 10% 消失）
④ 超时 24h 无人接 / 接后 12h 未完成 → 原路退还给主人（扣 5% 手续费）
```

**关键约束**（防代练刷钱）：

- 短工**必须身处该宅院场景**才能完成操作——不能远程一键
- 同一对主雇，**每天最多成交 3 单**——防小号互刷
- 工钱上限：系统按活计类型给 cap（帮收最多 200 两／单），发太高会被截断
- 短工**可以边干活边偷**——但偷失败被抓，当前契约**作废且不退工钱**（风险自担）

#### 离线主人

主人不在线也能发契、也能被偷。
雇工完成的「帮收」直接进主人库房；被偷的按偷菜规则走——**离线不能抓贼**，只能认栽，这也是社交话题。

### 8.5 善名 / 恶名（轻量声望）

不单独做复杂系统，只记两个整数，显示在名号旁可选：

| | 怎么涨 | 效果 |
|---|---|---|
| **善名** | 完成雇工 +1；被主人「谢过」（花 10 两）+1 | 接活时主人更愿意雇；成功率无关 |
| **恶名** | 偷成功 +1；被抓 +2 | 恶名 ≥10 时，进任何宅院**场景日志**会多一行「此人恶名在外，大家留神」 |

不做「恶名高了不能偷」——让人可以继续当贼，但要承担社交压力。

### 8.6 家宴（可选，跟雇工并行）

花 **200 两**买菜，请**当前在宅内**的好友吃 → 每人本场战斗 +2% 攻。
跟「请客」(`economy.js` 的 `treat`) 同哲学，只是地点改在私宅。
**待拍板**：第一版要不要跟偷菜一起做。

## 补充：家园的长期目标

家园不能只有「种什么、炼什么、卖什么」。如果所有玩家最后都把同样的格子填满，
家园就会退化成一张生产表。家园需要同时承担三种作用：**后勤基地、个人名片、社交据点**。

### 8.7 收藏与展示

家园至少要有一小块不参与生产的展示区域，专门放置玩家经历过的东西：

- 禁地掉落的墓碑、壁画、镇墓兽牙、特殊灯具
- 鱼类标本、藏宝图残页、稀有种子和门派信物
- 打造过的旧兵器、首次通关纪念、绝境纪录
- 主人自己写的宅院名、门联和一句话介绍

展示物不直接提供战斗属性。它们的价值是收藏、表达和让访客有话可聊。
稀有战利品要能被放出来看，而不是只在玩家状态里增加一个数字。

### 8.8 访问权限和访客反馈

现有「默认开放 + 可以偷」的设计要补一层明确的访问模式：

- **公开参观**：可以看布局、展示区、生产状态和留言簿，不能拿东西
- **好友来访**：可以帮忙、家宴、聊天和领取主人公开的待办
- **江湖风险**：主人主动开启后，才允许偷菜、偷矿和触发抓贼
- **闭门谢客**：暂时不接受访问，但不影响离线生产

偷盗可以保留为有趣的江湖行为，但不应该成为所有人的默认损失。主人应该能选择自己想经营的是「安全宅院」还是「江湖险宅」。

访客行为要留下记录：谁来过、帮了什么、偷过什么、主人是否感谢过。
留言簿和「最常来访」「最受欢迎宅院」等轻榜单，比单纯显示一个家园等级更有生命力。

### 8.9 NPC 和门派人物入住

家园需要少量固定角色，负责把生产系统变成故事：

- 掌柜、铁匠、药师或门派师兄可以阶段性入住
- 入住后提供一条小剧情、一个委托和一件主题装饰
- 帮他们完成委托，解锁新的家具、配方、鱼饵或藏宝图线索
- 不把入住角色做成必须收集的战斗伙伴，也不直接增加面板属性

家园是角色关系的延长线：玩家在外面闯荡，回家后有人记得他上次从禁地带回了什么。

### 8.10 经营方向与互补交易

不建议让每座宅院默认同时拥有所有生产能力的最高效率。可以保留基础全能，
再让玩家选择一个轻度经营方向：

- 丹房：药材种植和恢复类配方更丰富
- 炉坊：矿石加工和打造辅材更有优势
- 渔猎：鱼种、鱼饵和藏宝图线索更丰富
- 酒食：家宴、宴席和社交消耗品更有优势

方向可以更换，但需要时间或银两成本。差异的重点是配方和交易需求，
不是把某一方向做成唯一正确的战斗流派。

### 8.11 公共家园与共同目标

个人宅院负责「我的经历」，公共家园负责「我们的江湖」：

- 门派院：同门共同建设藏经阁、练武场、药圃或议事厅
- 好友庄：几名玩家共同维护一块鱼塘或宴席场
- 江湖工程：全服或门派共同修复古桥、驿站、码头
- 共同目标完成后，解锁公共装饰、商人、地图捷径或新的故事节点

贡献应以材料、时间和任务为主，不用强迫所有人同时在线。完成进度在频道里播报，
让挂机聊天的人也能感知江湖正在发生变化。

### 8.12 和禁地形成双向循环

建议把两套系统连成下面这条链：

```
大世界／禁地取得稀有材料与见闻
        ↓
家园加工、收藏、接待访客、推进 NPC 故事
        ↓
获得消耗品、藏宝图线索、主题装饰和公共工程贡献
        ↓
回到大世界探索新的场景与禁地
```

家园不应该成为更高效的泡点场，禁地也不应该只是家园的材料矿。两边分别提供「经历」和「延续」，才会互相带动。

## 十一、落地分期

| 阶段 | 内容 | 依赖 |
|---|---|---|
| **MVP** | 私宅、菜园、挂网、熔炉、原矿→精铁 | 无 |
| **MVP+** | **持竿遛鱼 + 宝箱 + 藏宝图 + 挖宝**、码头钓点 | MVP |
| **1.0** | 串门、偷菜、偷矿、雇短工 | MVP |
| **1.1** | 药圃、打坐摸矿、多水域鱼种、`mat` 联动 | [地图系统](地图系统.md) 期 1 |
| **1.2** | 钓功、精钢竿、矿窖、看门犬、善名恶名 | MVP+ |
| **1.3** | 昼夜／天气影响鱼种、家宴 | 地图时辰拍板后 |

建议排在 **期 0.5（经济堵漏）之后、期 3（日常任务）前后**：
材料若仍可无成本刷怪爆仓，家园只会多一条管子。

补充一条 MVP 约束：第一版除了生产线，至少要有一个**非产出功能**，建议是「展示架 + 留言簿 + 公开参观」。
否则玩家第一次收完菜、炼完矿后，没有理由停留在宅院，也没有理由去别人的宅院。
