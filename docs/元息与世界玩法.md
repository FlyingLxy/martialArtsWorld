前十份文档补的是通用层——怪物、掉落、市场、PVP、UI。
**这一份补的是"只有这个世界才会有的玩法"。**

起点是[世界观](worldbuilding.md)与[编年史](编年史.md)里四条已经写死的事实：

| 不变量 | 原文 | 它其实是一条玩法规格 |
|---|---|---|
| **10** | 元息**不能被采集、封存或运走**；其变化规律仍是待探索的中原秘密 | 修行收益只能由人留在当地取得；受影响的物产可以带走，但不携带元息本身 |
| **4** | 各门派的解释和修行道路**不可互相替代** | 不同传承的挂机过程不能只换资源名称 |
| 编年史 **K-82／K-1** | 两版图的元息盛区明显不合，变迁原因未定 | 证明气盛之地会在跨年尺度缓慢迁移 |
| 世界观 **§13** | 五处中原传承之所在同一时辰偶有强弱呼应 | 允许在长期迁移之上存在短期强弱波动 |

后两条必须分开：**气机迁移**是远慢于人的长期变化，足以改变水路、聚居和物产；
**元息潮汐**是叠在当前格局上的短期强弱波动，只改变当前周期内可结算的修行效率与材料丰歉。
K-82 与 K-1 两版图的差异不能用来证明“两小时一次重分布”，潮汐的直接设定依据是
“同一时辰强弱相呼应”这条开放线索。潮汐不得改变道路、水源、聚落或《姑存》已经确认的
缓慢迁移结论。

在这个边界内，**世界观说元息的分布并非静止不变，
而我们把泡点做成了每个场景一个固定系数**——
把这个世界最动态的东西做成了最静态的。

## 一、元息潮汐：让核心循环活起来

### 候选规则（D07 未裁定）

```
当前候选：每个 120 分钟的完整昼夜轮回结束时，全图元息强度刷新一次
每个区域得到一个元息档：  枯 0.7 ·  平 1.0 ·  盛 1.3 ·  极盛 1.6
短期档位叠加在长期气机格局之上，不改写场景的地理与叙事状态
```

下文把两次元息刷新之间称为一个“元息周期”。当前候选让它等于一个完整昼夜轮回，
最终频率仍在文末待拍板；“卯、午、酉、子”只是同一昼夜轮回内的四个时段，不能把整个轮回称作一个时辰。

这版候选使用“[场景卡](场景卡全集.md)固定系数 **×** 当前元息档”的相对修正。它还不是可投放公式：
`0.7` 直接乘全部泡点会低于基准，与下文“不追潮汐仍有基准收益”的承诺冲突；保底、
区域分布和总量约束必须一起收口。六类修行先在潮汐关闭、世界修正为 `1` 的条件下比较。

于是同一个场景，**今晚和明早值不一样**；
同一时刻，**这里和那里也不一样**。

### 为什么这比固定系数好

| 固定系数 | 元息潮汐 |
|---|---|
| 算一次就知道最优点，之后再不用想 | 每天都要重新判断去哪 |
| 所有人挤在同一个最优场景 | 人被分散到不同区域 |
| 地图上大部分场景永远没人去 | 每个场景都会轮到"它旺"的时候 |
| 没有信息价值 | **"哪里旺"成了值得说出口的话** |

最后一行是关键。[原则第三条](原则.md)说社交是目的——
**元息潮汐凭空造出了一种值得在频道里交换的信息**。

### 玩家怎么知道哪里旺

**绝不做"打开地图直接看到全图元息"。** 那样它就退化成一张自动寻优表。

| 途径 | 精度 | 代价 |
|---|---|---|
| **身在其中** | 当前场景的档位，精确 | 免费——你在那儿就感觉得到 |
| **同区域他人告知** | 精确 | 靠[聊天](UI与信息架构.md) |
| **四海会馆公示图** | 全图，但**滞后一个元息周期** | 免费查阅 |
| **通译馆测绘** | 全图，当前 | 花银两，或做测绘任务 |
| **门派堪舆**（武当／奥术学院） | 预测**下一个元息周期** | 门派任务解锁 |

**信息不对称是有意的。** 会馆的图滞后一个元息周期，所以"现在正旺"这条消息
只能从人嘴里得到。这让"有人在线"变得有实际价值——
不是情怀，是真的有用。

> 武当能预测下一个元息周期，接的是世界观里
> "武当道人发现断潮消散的年份与某次罕见星象完全重合"这条线索。

### 三条护栏

1. **极盛（1.6）每个元息周期全图只有一处**，且不会连续两次落在同一区域。
2. **枯（0.7）不是惩罚**，它只是让别处更值得去；
   潮汐不修改任务次数、战斗属性、装备掉率或市场规则。不追潮汐的人仍能获得基准泡点收益，
   地区材料的短期波动只改变产地选择，并受总量上限与交易替代路径约束。
3. **潮汐不改变产出总量的上限**，只改变分布。
   [经济与成本](经济与成本.md)的闸门照常生效。

## 二、六类修行的产出基准（本轮提案，未验证）

### 2.1 既定边界与本轮负责的内容

第一版保留六类修行：中原五派共享连续吐纳；奥术、骑士、忍宗、战团、神殿各有不同的
准备、同伴、独处、交替与时辰机制。中原五派之间还由技能、场景、任务与文化责任形成差异，
不宣称十派各有一套挂机公式。首发成礼后[不能直接改派](门派加入任务.md)，修行也不能通过菜单换派套利。

本轮补统一比较单位、行为曲线形状和结算边界。以下公共基线、候选加成及中断规则是
**待共同评审的设计方案**，不表示已经跑过模拟或已经证明六派等收益。
旧稿的“显著提高”“收益翻倍”“昼夜收益差最大”只保留为玩法方向，不再作为数值承诺。

六类机制只修正**在线泡点经验**。它们不自动放大银两、场景 `mat`、打坐摸矿、装备掉落、
战斗奖励、任务奖励、精力恢复或家园产出。材料与世界潮汐的联动仍属第五节的独立候选。

### 2.2 同一单位、同一输入再比较

定义 `U(lv)`：同等级、符合进入与修行条件、场景系数为1的标准公共场景，每秒可以结算的基础泡点经验。
第4项推荐已明确 `U(L)=E(L)/3600`，E读取[日常与经济方案](日常与经济方案.md)逐级公式；不另造经验常数，不用战斗EP充当经验，也不把U显示成可持有物品或货币。
普通场景基础系数加合格crowd/night后在0.8～1.5封顶，再乘本节M≤1.10；安全收功位置C固定0.8，墓外高阶档覆盖父scene参数见场景表。四维不另加经验，60级XP0不折现；公共修行银两独立0.25H/小时，不受本节倍率影响。

| 符号 | 含义 | 比较时的边界 |
|---|---|---|
| `Δt` | 服务端确认的有效在线修行秒数 | 离线、主动停止修行和战斗时间为 `0`；同角色多连接不重复累计 |
| `B` | 不含传承与候选世界加成的当段基准产出 | `U(lv) × Δt × 场景系数 × 等级衰减`；已定的其他公共修正若启用，须在六类对照中保持相同 |
| `A_k` | 第 `k` 类当段的行为满足度 | 范围 `[0,1]`，由 2.4 的真实状态计算，不能由客户端声明 |
| `avgA_k` | 同一参照样本中 `A_k` 的基准产出加权均值 | 用于校准与验收；不是玩家状态，不在运行时跟着玩家行为自动调整倍率 |
| `M_k` | 传承对当段泡点经验的倍率 | 候选采用 `1 + 0.10 × A_k`；不满足偏好条件也不扣基础产出 |
| `E_k` | 本段实际结算的泡点经验 | 世界修正关闭时为 `B × M_k`；分数余额与其他泡点一起累积，不每跳丢零头 |

10 级前所有角色统一使用 `M = 1`。10 级起尚未入门或保持永久散人的角色，建议使用公开的
**平稳修行**：`A_none = 0.5`，即 `M_none = 1.05`；不借用任何一派的核心机制，不另造第七套门派。
这是本轮的散人等值路径提案，需与六类一起评审，不能默认让散人长期少拿同一份 `5%` 目标增益。
已经入门却没有材料、没有同伴或很久没打怪时，仍保有 `M ≥ 1` 的完整基础泡点；
不关闭经验、不强制退出、不要求真人补位。成礼切换只影响后续有效区间，不追补过去收益。

若某段发生升级、移动、开战、同伴进出、符文耗尽或游戏时段切换，先结算变化前的有效区间，
再按变化后的等级和状态算下一段。不能拿结算时的高档状态回算整段在线时间。

### 2.3 “长期等收益”具体指什么

**目标：公共基础始终为 `1 U`；在相同在线机会、公共场景条件与预先声明的参照样本下，
六类修行的平均行为满足度均为 `0.5`，目标经验为 `1.05 U`，与平稳修行的散人相同。**
它不要求同一时刻每一跳相等，也不声称“任意游玩方式在所有门派都一样快”；若任何行为都完全同值，
这六种机制就失去选择意义。

候选计算与验收方式：

```text
M_k = 1 + 0.10 × A_k
avgA_k = Σ(样本权重 × B × A_k) / Σ(样本权重 × B)
归一化经验 R_k = Σ(样本权重 × B × M_k) / Σ(样本权重 × B)
目标 avgA_k = 0.5，目标 R_k = 1.05
```

本轮建议先用 **最多 `+10%`、参照期望 `+5%`** 作为初验预算。`A_k ∈ [0,1]` 只能推出
`1 ≤ M_k ≤ 1.10`，**不能推出实际玩家的平均 `A_k` 已经等于 `0.5`**。参照样本必须先冻结，
再调整行为曲线与参数；不能为了凑均值给每派换一套有利样本，也不能把 `avgA_k` 当作自动补倍率的除数。
某类不能在共同样本下达到目标，就重新设计其可达行为与准备成本；不扩大加成上限、不压低基础泡点来凑数。
`+10%/+5%` 仍是待评审提案，不能作为已经通过的平衡结果投放；旧“翻倍”不再另外叠加。

上述公式只限定了收益形状，是否达到共同的毛经验目标仍待验证。还必须同时检查：

- **同一参照样本**：先冻结在线区间、起始时辰、移动/战斗/主动停止的时间线、同伴人数与资格；
  六类读取同一组外部事件，不为骑士只挑多人在线、为神殿只挑白昼、为战团只挑刚打完怪的记录。
- **同一时间账**：筹备符文、战斗和移动所用的时间不从报告里消失。主报告用相同在线窗口下的
  总泡点经验比较；另报有效修行秒数与单位修行秒收益，不能只挑战团的战后高档几分钟。
- **同一成本账**：符文材料、个人内力消耗、补给与主动操作数分别列账。毛经验相等不能证明净成本公平；
  若奥术必须额外付费才能追平无成本模式，需要调整其基础准备/资源来源或收益参数，不能只报 `R_k=1.05`。
  本节不擅自把银两、材料或内力按某个汇率折成经验。
- **均值之外的下限**：独处、无材料、不追加战斗、经常离场、短时上线均须单列。
  不得用少数理想玩家的高收益掩盖某一传承在常见环境下长期落后。

行为曲线与 `τ/N` 等参数属于未来配置版本：离线校准后固定发布，不按全服当天人数、
某人的付费/物品投入或实时收益自动上调下调。`avgA_k` 是报告里的结果，不能一律填 `0.5`
冒充已经达标。服务端定价、升级需求和样本具体权重仍由对应准备项收口；低在线样本中骑士
若因缺同伴而持续低于其他传承，须补可达的责任型修行或调整机制，不能以“无人所以少拿”结束验收。

### 2.4 六类行为曲线与状态边界

以下参数给出可以手算和继续验证的**第一组候选值**。时间参数先统一参照已有的 120 分钟游戏昼夜，
便于比较不同曲线；这不是由玩家数据拟合出的结果，不表示已经决定玩家必须连续挂两小时或每两小时打一次怪。
所有机制都保留公共基础，参数经行为与经济联验后才能成为正式发布值。

| 初验参数 | 本轮候选值 | 单位与含义 |
|---|---|---|
| `τ吐纳` | `7200` 秒 | 同场景累计 7200 秒连续有效修行后到达 `A=1`；达到后维持，直到发生规定的重置事件 |
| `τ满备` | `7200` 秒 | 一次满备最多支持 7200 秒有效修行；每有效修行 1 秒扣 1 秒支持时长，不能超量储备或叠成多份 |
| `N誓约` | `2` 人 | 计算本人以外的合格同伴；0/1/2 人分别为 `A=0/0.5/1`，超过 2 人不再增加 |
| `τ战意` | `7200` 秒 | 自最近一场合格战斗结算起，按服务器实际时间在 7200 秒内从 `A=1` 下降到 `0` |
| 日月轮回 | `7200` 秒 | 沿用地图合同：卯/午/酉/子分别 20/40/20/40 分钟；本轮不另造个人昼夜 |

满备表确定状态容量与消耗速度；第4项推荐 `recipe.cultivation.rune` 在安全位置即时布设，消耗木炭1＋最大MP10%，附加银费0，支持7200有效修行秒。资源/位置不足则不扣，已有剩余不能叠多份或退款搬场；木炭只用既有ID与系统价3两，不新增充能材料。四次满备支持8小时共木炭4/12两及四次MP10%，主动操作和恢复时间仍须入主报告，不把即时按钮视为实际操作零耗时。
以下曲线里的时间均使用秒，人数按真实角色计数；配置不能保留“较久”“显著”等模糊运行值。

| 类别 | 行为满足度 `A_k` 的候选形状 | 正常结算与中断 |
|---|---|---|
| **中原五派·吐纳** | `min(本场景连续有效修行秒数 / τ吐纳, 1)`，随连续修行逐渐进入高档 | 主动换场景、进入战斗或主动停止修行时连续计时归零；聊天、查看案卷/行囊不打断。断线仅暂停；同场景重连恢复已确认进度，离线秒数不加入连续计时 |
| **奥术学院·符文** | `min(本地符文剩余可支持修行秒数 / τ满备, 1)`，准备充分时高，随实际使用降到低档 | 布设先校验并原子扣除所需资源；资源不足仍可低档修行。仅有效修行消耗符文时长，聊天时照常消耗，战斗、主动停止与断线期间暂停消耗；主动离开场景即解除布设，不退重复使用的资源，不能把本地布设带到另一个场景 |
| **王冠骑士团·誓约** | `min(合格同伴数 / N誓约, 1)`；同伴为同场在线的同门或已成立的结拜成员 | 同伴进出或关系资格变化后，对下一有效区间重新计数；同一角色只计一次。同门与结拜身份重叠也只计一次；无人时 `A=0`，仍有正常低档泡点 |
| **影之忍宗·收束** | `1 / (1 + 同场其他在线真实角色数)`；独处为 `1`，人多时逐渐降低 | 不要求取得 `solo` 场景才能修行；公共场景无人时也可进入高档。同角色多窗口不增加人数；他人进入只影响之后的结算，不扣回既有经验 |
| **北海战团·战意** | `max(0, 1 − 距最近合格战斗结算的服务器实际秒数 / τ战意)`；没有记录时为 `0` | 按下述第4项合格公共PvE胜利才刷新，不能累加多份或储存次数；败逃、零奖教学/试演/对练不触发。开战停泡点，结束按正常修行开关继续；离线也消耗战后时间窗，不能退出保存高档 |
| **太阳神殿·日月** | 默认卯/午/酉/子分别为 `0.5/1/0.5/0`；反向取向用 `1−A` | 只读全服 120 分钟游戏昼夜，不读玩家现实作息。取向选择在下一完整轮回起点生效，每轮回最多生效一次，不能昼夜边界反复切成高档；重登不重置当前取向或已排定的变更 |

关于这张表，还需一起守住四点：

1. **准备状态不是可搬运的元息。** 奥术布设表达普通材料、书写步骤与个人修行准备；
   不生产“封存元息”、可交易充能物品或可提取经验的容器。连续计时、战后时间戳和符文状态只用于判定，
   不是未来可领取的一笔经验。符文成本按本节第4项推荐；安全免费打坐每次回复最大HP/MP各35%、30秒个人冷却，风险区不可调用。不能用存档重放或新建布设重复领资源。
2. **人数口径不能依赖假玩家。** 初次比较只计真实在线角色，普通 NPC 不计；
   机器人是否计入任何人数收益须经 D08 单独裁定，不能因为进入房间列表就自动生效。多角色/多账号如何识别与防自我补位，
   由身份与社交合同定义；此处至少禁止同角色多连接与同一同伴身份重复计数。
3. **战意不能另开刷怪经济。** 第4项推荐“合格战斗”为49公开世界遭遇中的正常胜利，且符合合法非空奖励资格与世界有效级差：开战时角色等级不能比怪物高超过10级。
   “非空奖励资格”指该遭遇有正式可结算奖励资格，不以本次随机材料/成品是否命中判断；不另收一次精力或新增最短交战秒数。精力与小时/周奖励额度仍按世界经济合同记账。
   败逃、取消、零奖、调试、剧情重试、试演、教学、对练/切磋不合格；古墓不属于公共世界遭遇。同一胜利只刷新一次，战意不另发经验/材料或恢复精力。
   此项取代第2项旧“胜负都算、怪≥L−5”的候选，仍须实际验证速战和奖励资格判定，不能称已经通过。
   没有战斗仍可低档泡点，不设置战团每日必打次数；原有战斗成本仍按统一合同执行。
4. **参照场景不能给某派偷加一层优势。** 场景 `crowd/solo/night` 与传承同伴/独处/日月可能相关，
   基础比较先用相同公共场景；联验再同时打开两层，检查是否重复放大。太阳的完整轮回均值不是任意短会话的均值，
   必须另验不同上线时刻与 20/40 分钟等短窗口。

#### 120 分钟手算样例：只检验曲线，不宣称全玩家等收益

这是固定初始状态的数学夹具。设同等级 `lv ≥ 10`、场景系数与等级衰减均为 `1`，不升级，
其他公共修正与候选世界修正关闭；从卯时起连续有效修行 `T=7200` 秒，测量期间不移动、
不开战、不主动停止、不断线。所有对照使用同一外部人数条件：同场始终只有 1 个其他真实在线角色，
且该角色对骑士满足同门或结拜资格。不同角色的初始修行状态按下表固定。

| 类别 | 窗口开始时的状态与窗口内曲线 | `avgA` 的手算结果 |
|---|---|---|
| 吐纳 | 连续计时从 `0` 开始，`A(t)=t/T` | 上升三角形面积除以时长：`(T×1÷2)/T=0.5` |
| 符文 | 窗口前已完成一次满备，剩余 `T` 秒；窗口内不补备，`A(t)=1−t/T` | 下降三角形：`0.5` |
| 誓约 | 始终 1 个合格同伴，`A=1/2` | 常数均值：`0.5` |
| 收束 | 始终 1 个同场其他在线真实角色，`A=1/(1+1)` | 常数均值：`0.5` |
| 战意 | 窗口前刚完成一场合格战斗并结算，`A(t)=1−t/T` | 下降三角形：`0.5` |
| 日月 | 覆盖完整卯/午/酉/子；保持同一取向 | `(0.5×20+1×40+0.5×20+0×40)/120=0.5`；反向也为 `0.5` |
| 散人平稳修行 | 固定 `A=0.5` | 常数均值：`0.5` |

于是本夹具内共同基准经验为 `7200 × U(lv)`，额外经验为 `360 × U(lv)`，
合计 `7560 × U(lv)`，归一化倍率 `R=1.05`。这里是连续时间曲线与时段面积的手算，
**没有运行挂机模拟，也不是每跳结算实现的通过证据**；未来离散结算需保留切段与分数精度，解释与手算的差值。

这张表有意固定了符文满备和战后起点，说明候选曲线有一个可复核的共同测量点；
它不是 2.3 所要求的同一完整在线时间账，不能用这张表替代长期验收。主报告必须从共同的在线起点计时，
把窗口前的符文准备、战斗、移动和材料/内力消耗纳入，报告因此少掉的有效修行时间与完整窗口总经验。
准备时间与战斗成本尚未确定时，只能列为未知成本，不能填零后宣布经济公平。

下面三组反例也必须进入后续输入，均**尚未运行验证**，不能只保留上面的理想测量点：

| 待验对照 | 固定输入与必须观察的差异 |
|---|---|
| 20 分钟碎片 | 比较一次 120 分钟与 6 次 20 分钟；分别记录主动停止/离场和仅断线的轨迹，间隔与昼夜起点必须明确。吐纳重置、符文解除、战意实际过期与日月短窗口不能混成同一种中断 |
| 无人同场 | 其他角色数为 `0`，骑士 `A=0`、忍宗 `A=1`；同时看无材料、不追加战斗与散人。若真实参照样本里长期存在系统差距，需调机制或可达路径，不能用“仍有基础”作为公平通过理由 |
| 长达 12 小时 | 固定在线主窗口 43200 秒；先验全程修行、不补备、不追加战斗，再验允许补备/追加战斗且相应扣除有效修行时间，完整记成本。吐纳满档保持、符文/战意耗尽、日月经过 6 轮的结果会不同，不能每 120 分钟凭空重置成手算初始状态 |

### 2.5 在线、断线、重启与时间边界

| 事件 | 共同规则 |
|---|---|
| 最后一个有效连接断开 | 只结算服务端已确认的有效在线区间，随后停止泡点；不按下次登录时间补发离线经验 |
| 同角色仍有另一个有效连接 | 角色保持在线，仍只有一条修行时间线；新增/关闭窗口不启动额外结算 |
| 主动开关修行、移动、开战 | 按事件时间切段，先结旧状态，再按 2.4 更新该类状态；战斗中不同时结算泡点 |
| 断线后重连 | 读取已保存的状态与分数余额；吐纳/符文按表中规则暂停恢复，战意按服务器时间过期，日月按当前世界时段重算 |
| 服务端重启 | 恢复最后可靠存档，不把停服时长当在线修行；不得每次启动重置世界昼夜或发新的一轮收益；进度丢失范围由保存合同约束 |
| 场景因权限、占位或风险变化而不能继续修行 | 停止该场景产出，并走地图合同的安全处理；实际迁出后按“换场景”规则处理本地状态，不让隐藏收益继续跳 |
| 升级或达到 60 级 | 先结算升级前后区间；60级XP截0、不转银两/材料/门望，合法公共修行本来独立的0.25H银两/小时照常 |
| 午夜、日常刷新与元息候选周期变化 | 不刷新个人六修行的状态或赠送额外倍率；只有依赖世界时段的日月规则读取新的时段 |

聊天、公共观察以及不改变位置/战斗状态的 UI 操作不打断修行。护送、试演、战斗教学等主动任务
是否暂停泡点，按统一任务事件合同声明，不能每个任务自行写例外；如果按战斗进入，就与普通开战一致。
主动移动导致的吐纳重置和符文解除是本轮提案中的准备取舍，需要与“鼓励探索、不增加日常负担”一起验证。

### 2.6 潮汐、共鸣与材料暂不并入六修行的基准

- 未选入 D07 的玩法在运行方案中视为关闭，世界修正为 `1`；不用候选潮汐或共鸣替某派补平基准。
- 第4项推荐若后续选入，必须在场景共同C≤1.5内重新分配潮汐/共鸣加值，再乘M；旧独立 `B×M×W` 乘区停止作为首批候选预算。最终组合仍须全派共同验证，不能在C封顶外再翻倍。
- 必须报告六修行与地区/时辰/人数相关性。单独两张表都达到各自目标均值，不代表相关连乘后仍达到组合预算。
- “不追热点有基本成长”必须用固定地点、不追潮汐的真实行为样本验。枯档 `0.7` 与基准保底怎么共存、
  共鸣缺派时有无补偿仍是 D07 决定项，本轮不靠文字宣布已经解决。
- 地区材料、家园产出、符文成本和精力分别记账；不把同一产物同时乘修行、昼夜、潮汐和共鸣。

## 三、共鸣：需要跨门派协作的挂机事件

> 以下仍是 D07 的玩法候选，含五人条件、持续时间与 `+25%`；未确定发布批次，也未计入第二节的六修行基准。

世界观线索里有一条一直没人用：

> 五处中原传承之所相隔甚远，元息却偶尔在同一时辰出现强弱相呼应的波动。

**做成玩法**：

```
当五处中原传承之所同时各有至少一名本派玩家在挂机
→ 触发「五脉共鸣」，持续一个元息周期（当前候选为 120 分钟）
→ 全服泡点收益 +25%，并在编年史留下一条记录
```

海外同理，需要五处海外传承之所同时有人——
但那要求所有人分散出海，更难，所以给更高的加成与一个专属称号。

### 为什么这个设计好

- **它是唯一需要"组织"的挂机内容**。有人得在频道里喊
  "少林缺人，谁去嵩山挂一会儿"——[社交是目的](原则.md)的最直接实现。
- **它奖励的是分散，不是集中**。别的多人玩法都把人聚到一起，
  共鸣把人推开，反而让整张地图活起来。
- **它对人少的服务器友好**：五个人就能凑齐一次共鸣，
  这在十来人的服里是可达成的目标，而不是遥不可及的团本。
- **它是纯挂机的**，符合[挂机本位](玩法与核心循环.md)——
  不需要操作，只需要"人在那儿"。

## 四、悬案：把十三条世界线索做成可推进的内容

世界观第 13 节列了十三条"可继续生长的线索"，
现在它们只是设定，不是玩法。

### 悬案系统

```
每条线索 = 一桩悬案
玩家在世界各处拾得「证据」（残页、物件、对话、观察记录）
证据积累到一定程度 → 可在四海会馆「立论」
立论会被记入编年史，署你的名字
```

| 项 | 规则 |
|---|---|
| 证据来源 | [见闻线](见闻与收藏.md)的残页、场景描述、装备来历、NPC 对话 |
| 立论 | 从系统给的几种解释里选一种，或选「存疑」 |
| **可以立错** | 后续证据可能推翻你的结论——**推翻本身也进编年史** |
| 奖励 | 称号 · 青色 · 编年史署名；**不给战力** |
| 协作 | 证据可以互相**告知**（不可交易，见闻线护城河），多人可共同立论 |

### 「可以立错」是这套系统的灵魂

按[原则第十条](原则.md)，未定猜想那一层"可以互相冲突，不急着给官方正解"。

所以悬案不是答题，**是修史**：

```
某某立论：黑帆船员的无痛是幽潮所致
七日后，某某某提出反证，前论被推翻
又两日后，两人共同立论：无痛与断潮余雾中的星象有关
```

这里不用 `K` 纪年。`K-3` 等负数表示开篇以前的历史坐标，玩家在 K0 开篇后的行为
应保存真实时间戳，再由界面按世界内历法或相对日期展示。

**这三行会永久留在编年史里。** 十来个朋友玩上一年，
编年史就是他们共同写出来的一部江湖史——
这比任何称号都更"名望"。

### 十三条悬案的初始难度分档

| 档 | 悬案 | 为什么 |
|---|---|---|
| **易**（10~25 级可推进） | 白垒堡盾徽出现在旧货市场 · 丐帮童谣各地歌词不同 | 证据在中原就能找到 |
| **中**（25~45 级） | 无船员的破船 · 冒用忍宗名义的刺客 · 黑帆船员无痛 · 华山思过崖的异种刻痕 | 需要到万国码头、航线或门派深处 |
| **难**（45~60 级） | 断潮消散与星象重合 · 太阳神殿"黑日"记录更早 · 少林西来残卷"大雾闭海" · 奥术学院只在断潮海雾中可见的星 | 需要海外传承之所或跨文化历法对读 |
| **终局**（60 级） | 五脉同时辰呼应 · 气盛之地与今图不合 · 洛阳为何是枢纽 | **三条指向同一个答案，但不在早期给解**（不变量 8） |

最后三条**故意不给答案**——不变量 8 说幽潮是共同谜团，
不在早期确定唯一解释。它们是留给续作或长期运营的钩子。

## 五、元息与物产：给地图一层经济纹理

不变量 10 说元息"对当地物产的影响仍是待探索的秘密"。

**做成**：元息档影响该区域的**材料掉落率**，不影响装备掉落。

```
枯 0.7   材料掉落 −20%
平 1.0   基准
盛 1.3   材料掉落 +20%
极盛 1.6 材料掉落 +40%，且有低概率出现该区域的稀有材料
```

于是[跑商](市场与家业.md)有了真正的价格波动来源——
元息枯的地方材料短缺、价格高，盛的地方过剩、价格低。
**商人开始关心元息，而不只是关心价差**。

这也让[家园](家园系统.md)的选址有了意义（若家园可迁）。

## 七、这一份补的是什么

前十份文档搭的是**任何 MMO 都需要的层**。
这一份里的五个系统，**换一个世界观就不成立**：

- **元息潮汐**——因为元息不能被采集运走，所以只能人去那里（不变量 10）
- **六种修行**——因为修行道路不可互相替代（不变量 4）
- **五脉共鸣**——因为传承之所相隔甚远却会呼应（世界线索）
- **悬案修史**——因为幽潮是不给早期答案的共同谜团（不变量 8）
- **元息与物产**——因为元息不能带走，却会改变当地物产（不变量 10）

**世界观越具体，能长出来的玩法就越独特。**
反过来，如果一套玩法搬到别的游戏里也照样成立，
那它多半没有用到这个世界。

## 待拍板

1. **元息四档（0.7/1.0/1.3/1.6）的叙事标签如何重映射？** D07尚未选入；第4项要求计入共同C≤1.5，不再允许旧1.6×场景1.5的独立2.4倍乘区。若采用潮汐，需重新分配档位效果并复核。
2. **潮汐每个 120 分钟昼夜轮回刷新一次会不会太频繁？** 变化太快可能来不及形成有效的信息交换；
   或许改成每三个完整轮回刷新一次（6 小时）。无论取哪档，都不能再把“轮回”写成“时辰”。
3. **六修行归一化提案是否采用？** 第二节已给公共基线、最高 `+10%` / 参照期望 `+5%`、
   三项 `7200` 秒时间参数、誓约 `2` 人及 120 分钟手算。加成预算、散人平稳修行、真实样本权重和参数校准仍须评审。
   第4项已给符文木炭1/MP10%成本和公共合格胜利战意条件；移动准备损失与低投入差距仍须评审/实测，既有手算不证明六修行平衡。
4. **共鸣要五派各有人在线，十人服能凑齐吗？** 若五派人数不均会永远差一派。
   或许允许[江湖散人](江湖散人.md)顶替——但那又有"跟机器人共鸣"的空虚问题。
5. **悬案立论错了会不会让人不敢立？** 或许"存疑"也算一种立论并给少量奖励。
6. **十三条悬案要不要一次全开？** 建议按等级分档逐步开放，
   终局那三条留到 60 级。
