# 元息与世界玩法

前十份文档补的是通用层——怪物、掉落、市场、PVP、UI。
**这一份补的是"只有这个世界才会有的玩法"。**

起点是[世界观](worldbuilding.md)里三条已经写死的事实：

| 不变量 | 原文 | 它其实是一条玩法规格 |
|---|---|---|
| **10** | 元息**不能被采集、封存或运走**；其变化规律仍是待探索的中原秘密 | 受益的唯一方式是**人待在那里**——这就是泡点 |
| **4** | 各门派的解释和修行道路**不可互相替代** | 十派的**挂机方式**本就该不同 |
| 编年史 **K-1** | 当代测绘发现元息盛区与 K-82 旧图**明显不合**，变迁原因未定 | **盛区会移动**，而且这是正典里的悬案 |

第三条最要命：**世界观说元息的分布是流动的、成谜的，
而我们把泡点做成了每个场景一个固定系数**——
把这个世界最动态的东西做成了最静态的。

## 一、元息潮汐：让核心循环活起来

### 规则

```
每个时辰轮回（2 小时），全图元息强度重新分布
每个区域得到一个元息档：  枯 0.7 ·  平 1.0 ·  盛 1.3 ·  极盛 1.6
分布不是随机数，而是沿着「地脉」缓慢移动的波
```

场景的泡点收益 = [场景卡](场景卡全集.md)的固定系数 **×** 当前元息档。

于是同一个场景，**今晚和明早值不一样**；
同一时刻，**这里和那里也不一样**。

### 为什么这比固定系数好

| 固定系数 | 元息潮汐 |
|---|---|
| 算一次就知道最优点，之后再不用想 | 每天都要重新判断去哪 |
| 所有人挤在同一个最优场景 | 人被分散到不同区域 |
| 地图上大部分场景永远没人去 | 每个场景都会轮到"它旺"的时候 |
| 没有信息价值 | **"哪里旺"成了值得说出口的话** |

最后一行是关键。[原则第三条](原则.md)说社交是目的——
**元息潮汐凭空造出了一种值得在频道里交换的信息**。

### 玩家怎么知道哪里旺

**绝不做"打开地图直接看到全图元息"。** 那样它就退化成一张自动寻优表。

| 途径 | 精度 | 代价 |
|---|---|---|
| **身在其中** | 当前场景的档位，精确 | 免费——你在那儿就感觉得到 |
| **同区域他人告知** | 精确 | 靠[聊天](UI与信息架构.md) |
| **四海会馆公示图** | 全图，但**滞后一个时辰** | 免费查阅 |
| **通译馆测绘** | 全图，当前 | 花银两，或做测绘任务 |
| **门派堪舆**（武当／奥术学院） | 预测**下一个时辰** | 门派任务解锁 |

**信息不对称是有意的。** 会馆的图滞后一个时辰，所以"现在正旺"这条消息
只能从人嘴里得到。这让"有人在线"变得有实际价值——
不是情怀，是真的有用。

> 武当能预测下一时辰，接的是世界观里
> "武当道人发现断潮消散的年份与某次罕见星象完全重合"这条线索。

### 三条护栏

1. **极盛（1.6）每个时辰全图只有一处**，且不会连续两次落在同一区域。
2. **枯（0.7）不是惩罚**，它只是让别处更值得去；
   而且[任务、打怪、市场](玩法与核心循环.md)完全不受元息影响——
   不想追潮汐的人可以永远不管它。
3. **潮汐不改变产出总量的上限**，只改变分布。
   [经济与成本](经济与成本.md)的闸门照常生效。

## 二、六种修行：十派的挂机方式各不相同

不变量 4 说各派修行道路不可互相替代。
现在的实现是**只有名字不同**（内力／魔力／圣息／忍气／怒气／神力），
机制完全一样——**这等于把不变量 4 架空了**。

改成六种真正不同的挂机方式：

| 传承 | 说法 | 挂机机制 | 性格 |
|---|---|---|---|
| **中原五派** | 内力·吐纳 | **连续性**：不间断挂机越久，收益逐级递增；离开场景或战斗则重置 | 静得下来的人 |
| **奥术学院** | 魔力·符文 | **前置**：挂机前布设符文（消耗内力与材料），符文越足收益越高，会随时间耗尽 | 爱准备的人 |
| **王冠骑士团** | 圣息·誓约 | **同伴**：同场有同门或[结拜](社交与关系.md)成员时收益显著提高，独处最低 | 抱团的人 |
| **影之忍宗** | 忍气·收束 | **独处**：同场人越少收益越高，`solo` 场景最高；人多反而降 | 独来独往的人 |
| **北海战团** | 怒气·战意 | **交替**：刚结束战斗后的一段时间收益翻倍，久不战斗则衰减 | 闲不住的人 |
| **太阳神殿** | 神力·日月 | **时辰**：昼夜收益差最大（白天高／夜里低，随派内选择可反转） | 有作息的人 |

### 这一条的分量

它把"选哪个门派"从**选一套技能**变成了**选一种玩法**。

- 骑士团玩家会主动去人多的地方，忍宗玩家会去 `solo` 场景——
  **两派的地图使用方式完全不同**
- 战团玩家的一天是"打一场挂一会儿再打一场"，
  中原玩家的一天是"找个地方一直挂着"
- 神殿玩家会因为作息而选派，或因为选派而改作息

**而且它跟元息潮汐是乘法关系**：忍宗玩家要找的是"人少且元息旺"的地方，
骑士团要找的是"人多且元息旺"的地方——**两者天然不抢同一个点位**。

### 边界

- 六种机制的**长期期望收益必须相等**，只是路径不同。
  由[数值基准](数值基准.md)校验，谁高了就是设计失败。
- 不做"换派换机制"的套利：择承后机制固定，
  [换派](门派加入任务.md)本就有代价。
- 机制只影响**泡点**，不影响打怪、任务、市场——
  否则会渗透进战斗平衡。

## 三、共鸣：需要跨门派协作的挂机事件

世界观线索里有一条一直没人用：

> 五处中原传承之所相隔甚远，元息却偶尔在同一时辰出现强弱相呼应的波动。

**做成玩法**：

```
当五处中原传承之所同时各有至少一名本派玩家在挂机
→ 触发「五脉共鸣」，持续一个时辰
→ 全服泡点收益 +25%，并在编年史留下一条记录
```

海外同理，需要五处海外传承之所同时有人——
但那要求所有人分散出海，更难，所以给更高的加成与一个专属称号。

### 为什么这个设计好

- **它是唯一需要"组织"的挂机内容**。有人得在频道里喊
  "少林缺人，谁去嵩山挂一会儿"——[社交是目的](原则.md)的最直接实现。
- **它奖励的是分散，不是集中**。别的多人玩法都把人聚到一起，
  共鸣把人推开，反而让整张地图活起来。
- **它对人少的服务器友好**：五个人就能凑齐一次共鸣，
  这在十来人的服里是可达成的目标，而不是遥不可及的团本。
- **它是纯挂机的**，符合[挂机本位](玩法与核心循环.md)——
  不需要操作，只需要"人在那儿"。

## 四、悬案：把十三条世界线索做成可推进的内容

世界观第 13 节列了十三条"可继续生长的线索"，
现在它们只是设定，不是玩法。

### 悬案系统

```
每条线索 = 一桩悬案
玩家在世界各处拾得「证据」（残页、物件、对话、观察记录）
证据积累到一定程度 → 可在四海会馆「立论」
立论会被记入编年史，署你的名字
```

| 项 | 规则 |
|---|---|
| 证据来源 | [见闻线](见闻与收藏.md)的残页、场景描述、装备来历、NPC 对话 |
| 立论 | 从系统给的几种解释里选一种，或选「存疑」 |
| **可以立错** | 后续证据可能推翻你的结论——**推翻本身也进编年史** |
| 奖励 | 称号 · 青色 · 编年史署名；**不给战力** |
| 协作 | 证据可以互相**告知**（不可交易，见闻线护城河），多人可共同立论 |

### 「可以立错」是这套系统的灵魂

按[原则第十条](原则.md)，未定猜想那一层"可以互相冲突，不急着给官方正解"。

所以悬案不是答题，**是修史**：

```
K-3  某某立论：黑帆船员的无痛是幽潮所致
K-7  某某某提出反证，前论被推翻
K-9  两人共同立论：无痛与断潮余雾中的星象有关
```

**这三行会永久留在编年史里。** 十来个朋友玩上一年，
编年史就是他们共同写出来的一部江湖史——
这比任何称号都更"名望"。

### 十三条悬案的初始难度分档

| 档 | 悬案 | 为什么 |
|---|---|---|
| **易**（10~25 级可推进） | 白垒堡盾徽出现在旧货市场 · 丐帮童谣各地歌词不同 | 证据在中原就能找到 |
| **中**（25~45 级） | 无船员的破船 · 冒用忍宗名义的刺客 · 黑帆船员无痛 | 需要到万国码头与航线 |
| **难**（45~60 级） | 断潮消散与星象重合 · 太阳神殿"黑日"记录更早 · 少林西来残卷"大雾闭海" | 需要海外传承之所 |
| **终局**（60 级） | 五脉同时辰呼应 · 气盛之地与今图不合 · 洛阳为何是枢纽 | **三条指向同一个答案，但不在早期给解**（不变量 8） |

最后三条**故意不给答案**——不变量 8 说幽潮是共同谜团，
不在早期确定唯一解释。它们是留给续作或长期运营的钩子。

## 五、元息与物产：给地图一层经济纹理

不变量 10 说元息"对当地物产的影响仍是待探索的秘密"。

**做成**：元息档影响该区域的**材料掉落率**，不影响装备掉落。

```
枯 0.7   材料掉落 −20%
平 1.0   基准
盛 1.3   材料掉落 +20%
极盛 1.6 材料掉落 +40%，且有低概率出现该区域的稀有材料
```

于是[跑商](市场与家业.md)有了真正的价格波动来源——
元息枯的地方材料短缺、价格高，盛的地方过剩、价格低。
**商人开始关心元息，而不只是关心价差**。

这也让[家园](家园系统.md)的选址有了意义（若家园可迁）。

## 七、这一份补的是什么

前十份文档搭的是**任何 MMO 都需要的层**。
这一份里的四个系统，**换一个世界观就不成立**：

- **元息潮汐**——因为元息不能被采集运走，所以只能人去那里（不变量 10）
- **六种修行**——因为修行道路不可互相替代（不变量 4）
- **五脉共鸣**——因为传承之所相隔甚远却会呼应（世界线索）
- **悬案修史**——因为幽潮是不给早期答案的共同谜团（不变量 8）

**世界观越具体，能长出来的玩法就越独特。**
反过来，如果一套玩法搬到别的游戏里也照样成立，
那它多半没有用到这个世界。

## 待拍板

1. **元息四档（0.7/1.0/1.3/1.6）跨度合适吗？** 极盛 1.6 叠上场景系数 1.5
   就是 2.4 倍，可能太诱人；或许极盛封顶到 1.4。
2. **潮汐每 2 小时变一次会不会太频繁？** 上班族一天只上一两次，
   可能永远赶不上极盛。或许改成每 6 小时（三个时辰）。
3. **六种修行机制的期望值相等，怎么验？** 需要一个挂机行为模拟，
   而现有的[战斗模拟](combat-balance-simulation.md)不覆盖。
4. **共鸣要五派各有人在线，十人服能凑齐吗？** 若五派人数不均会永远差一派。
   或许允许[江湖散人](江湖散人.md)顶替——但那又有"跟机器人共鸣"的空虚问题。
5. **悬案立论错了会不会让人不敢立？** 或许"存疑"也算一种立论并给少量奖励。
6. **十三条悬案要不要一次全开？** 建议按等级分档逐步开放，
   终局那三条留到 60 级。
