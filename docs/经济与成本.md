# 经济与成本

这一篇是**最容易在不知不觉中把游戏做废的地方**。已经踩过一次（刷怪比泡点快 858 倍），
下面记录的是现存的窟窿和堵法。

> **注**：本文引用的实测数字全部来自 **v1**。v2 清档重来，
> 这些数字不是约束，而是**踩过的坑的证据**——留着是为了别再踩一遍。

## 一、v1 暴露的问题（实测数据）

### 打怪几乎没有成本

| 付出 | 实际代价 |
|---|---|
| 时间 | 5～15 秒 |
| 内力 | 几十点，几秒回满 |
| 气血 | **打坐免费回 35%，无限次、无冷却** |
| 金疮药 | 30 两，但打怪 15% 掉落 → **根本不用买** |

**净成本约等于零，收益全是白赚。** 有了这个前提，任何"多打就多得"的设计都会被刷爆。

### 死亡不痛

丢一成银两，被抬回客栈，打坐三次满血继续。**经验不掉、装备不损、没有冷却。**
结果是越级挑战、送死试探都没有代价，风险设计全部失效。

### 升级需求跟不上输出增长

```
等级   升级需要    同级怪给   要打几只
 10       3774       150     25.2 只
 30      24273      1800     13.5 只
 50      58409      9500      6.1 只
 80     131598     28000      4.7 只   ← 越高级越轻松
```

`need(lv) = 60·lv^1.75 + 40·lv`，而玩家输出是
**属性(线性) × 武功倍率(4.5→6.8) × 装备打造倍率(1→2.08)**，三者相乘，涨得远比 need 快。

**这是数值膨胀的根子**：不压制的话，等级越高升级越轻松，最后必然爆炸。

## 二、堵法

### ① 让主动战斗有真实成本

**注意区分两种"时间成本"**：

- ✓ **让行为本身变慢**（打坐要 30 秒冷却、战斗一场要十几秒）——这是节奏，可以接受
- ✗ **让玩家干等着什么都不能做**（赶路读条、死后禁战、体力耗尽下线）——这是剥夺，别做

前者约束的是"刷的效率"，后者拿走的是"玩的机会"。挂机的人不缺时间，
但没人有耐心盯着一个进度条。

| 措施 | 建议 | 效果 |
|---|---|---|
| **打坐加冷却** | 一次回 35%，但 **30 秒内不能再打坐** | 刷怪循环变成"打→打→歇 30 秒"，效率自然降下来 |
| **金疮药不掉落** | 只能买，30 两 | 补给成为真实开销 |
| **装备耐久** | 每场战斗 −1，满值 100 | 见下 |

### ② 装备耐久：最好的持续金币回收

一次性开销（买装备、学武功）总会买完，**只有维护费是永续的**。

```
耐久        满值 100，每场战斗 −1，死亡额外 −10
掉到 0      装备属性减半（不消失，别太狠）
修理费      原价 × (已损耐久 / 100) × 1.0
```

按玄铁重剑（8000 两）算：打 100 场修一次要 8000 两，**平均每场 80 两**。
而 20 级打怪一场约得 400 两——**维护费占收益两成**，这个比例合适：
不痛，但让"无限刷"变成有边际成本的事。

**高级装备维护更贵**（屠龙宝刀 90000 两），这是好事：它让高级玩家的产出也被回收。

### ③ 死亡要有痛感，但别剥夺游玩时间

**「一段时间内不能战斗」这类惩罚要避免**——它拿走的是游玩本身，玩家记恨的不是
"我损失了什么"，而是"我干坐着"。惩罚应该落在**游戏内的东西**上，
让人心疼，但随时可以继续。

```
死亡时       丢一成银两 + 8% 经验 + 装备耐久 −15
             外加「重伤」状态，持续 1 分钟

重伤期间     气血上限 −30%，攻击 −20%
             照常能打架、能泡点 —— 只是虚着，更容易再死

解除         ① 自然恢复：1 分钟后自动好
             ② 请郎中：客栈花 等级 × 20 两，立刻痊愈
```

这个设计有四层好处：

1. **不阻止继续玩。** 想立刻再战就再战，只是虚着，风险自负——是"我的选择"，
   不是"系统不让我玩"。
2. **痛感真实。** 带着 −30% 气血上阵，很可能二次送命，那才是真的疼。
3. **多一个回收口。** "请郎中"是自然的花钱理由，而且**按等级收费**，
   高等级玩家付得更多，正好回收他们的产出。
4. **武侠味对。** 重伤未愈、花钱疗伤，比"N 分钟内禁止战斗"这种系统腔调贴题。

**重伤期间泡点不受影响** —— 挂机的人本来就没在打架，不该被连坐。

### ③-2 连续送死才加重

```
重伤未愈时又死一次  →  加深（血上限 −50%、攻击 −35%），时长翻倍（2 分钟）
再死                →  继续加深，上限 −70% / −50%，时长 4 分钟
```

**一分钟是刻意定短的**：它要的不是"罚站"，而是**让人不敢立刻头铁再冲**。
真正的痛感来自那 8% 经验和耐久损失，重伤只是一个"缓一缓"的提示。
连送才会滚雪球，这样偶尔失手的代价始终很轻。

把**偶尔失手**和**莽撞连送**的代价分开：前者是学习成本，后者才该挨罚。
**惩罚鲁莽，不惩罚尝试。**

### ④ 经验获取的等级压制

打比自己低太多的怪，经验大幅衰减：

```
经验倍率 = max(0.05, 1 − (我的等级 − 怪的等级) × 0.06)
```

- 同级或更高：全额
- 低 5 级：70%
- 低 10 级：40%
- 低 16 级以上：5%（下限）

**这条必须做**，否则高级玩家永远靠刷低级怪滚雪球。

### ⑤ need 曲线（已定）

**等级上限 60**（参考魔兽：上限低，满级后横向发展，从根上避免数值膨胀）。

```
need(lv) = 60 · lv^2.2 + 40 · lv        指数从 1.75 提到 2.2
```

按泡点框架推算的节奏（**具体数字要等新地图的场地收益定下来再复算**，
这里先给量级）：

| | 到 10 级 | 到 30 级 | 满级总计 | 每天挂 8 小时 |
|---|---|---|---|---|
| `^1.75` | 3.2 小时 | 33 小时 | 82 小时 | 10 天 |
| **`^2.2`** | 6.7 小时 | 118 小时 | **约 389 小时** | **约 49 天** |

一个半月满级，跟魔兽经典的量级对得上。新手第一天挂满能到 10 级左右，
不至于开局就卡。

**新地图的每个场地定 `exp` 时，回来用这张表校准**——
保证"照着最优路线走"的总时长落在 350～450 小时。

**为什么指数要提**：玩家输出是 属性 × 武功倍率 × 打造倍率（相乘），
`^1.75` 追不上，会出现"等级越高升级越轻松"。`^2.2` 才压得住。

## 三、货币的进与出（现状盘点）

### 进（产出）

| 来源 | 量级 | 有没有上限 |
|---|---|---|
| 打怪 | 怪身上的 0.7~1.3 倍 | **无上限**，能刷多少是多少 |
| 械斗 | `20 + 等级×14` | 无上限 |
| 擂台 | 80~7000 | 无上限 |
| 泡点奇遇 | 挂机被动 | 有上限（受时间限制）✓ |
| 赌坊 | 期望 0 | 零和 ✓ |

### 出（回收）

| 去处 | 类型 | 够不够 |
|---|---|---|
| 打造 | **无底洞** ✓ | 最有效的一个 |
| 装备、武功 | 一次性 | 买完就没了 |
| 请客、送花、成亲 | 社交消费 | 有效，但频次低 |
| 集市抽头、押注彩头 | 一成 | 有效 |
| 药品、酒菜 | 小额 | 因为药会掉落，形同虚设 |
| **车马费** | 跨区域移动，按等级收 | 高频小额，且高等级付得多 ✓ |
| **请郎中** | 立刻解除重伤，按等级收 | 同上 |
| 战败损失 | 一成身家 | 没人故意送死，形同虚设 |

**结论**：回收口的种类不少，但**产出是无上限的**，所以长期必然通胀。
装备耐久是当前最缺的那一环——它同时解决"打怪无成本"和"缺持续回收"两个问题。

## 三之二、天赋体系

天赋点由**升级固定发放**（已定），不经产出系统，因此不受本文约束。
天赋与技能归[天赋体系](talent-system.md)管，那边如果引入了可交易或可刷取的资源，
再回到本文第四节的三问过一遍。

## 四、加任何新东西之前，先回答这三问

1. **它的产出是泡点的几倍？** 超过 5 倍就要警惕，超过 20 倍一定出事。
2. **它有没有上限？** 无上限的产出必须配上限机制（冷却、次数、等级压制）。
3. **对应的回收在哪？** 新增产出必须同时想好这些钱去哪儿，不能只管发不管收。
