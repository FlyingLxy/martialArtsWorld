### 旧问题如何对应本轮方案

1. 打坐保留免费35%恢复，但只在安全处、30秒个人冷却；场景风险有保护线和免费撤离，不用禁战/赶路读条剥夺操作机会。风险连续练功时长与总有效升级小时分开计算。
2. 主动世界奖励有精力衰减、差级限制、按自然小时的确定上限；不把“基准60场/小时”误当成引擎必然限制。金疮药等未登记药不放进世界包，也不虚计购药/修理回收；完整药品扩展仍受范围约束。
3. 普通PvE死亡XP损失取当前级已有XP的8%与0.25E较小值，不降级；银两取余额10%与0.10H较小值。重伤60/120/最高240秒可继续玩，郎中ceil(0.05H)治好并补满，始终可免费等恢复。本轮推荐不收耐久费；其他战斗模式不套这份死亡经济。
4. 必经交通与公共安全撤离免费。可选跨区快行ceil(0.005H)只减少导航操作，始终有无真实等待、同等权限的免费通行；不把玩家必须赶路当银两主回收。
5. 普通换装有固定价系统购买/铸造，十声不进入个人毕业。长期回收主要是有明确成本的打造/重洗；分解不返还高档品质增材，传承仅抵扣目标实际升级费用且继续正常概率。
6. 当前无额外社交/竞技/跑商新奖流入基础收支。D05/D09若选入，要先补来源、上限与回收，不把旧v1货币表直接复用。

### 时长与供需证据边界

need指数2.2和60上限沿既有规则；每小时E/H与场景成本是本轮推荐。四故乡公开路线的静态积分约417有效修行小时到60级，按每天8有效小时约52.2天；安全路线约647.4小时。它们忽略任务奖励及实际移动/恢复/在线情况，不能当实测日历周期。旧389小时/49天只是旧地图框架估计，已不作为当前结果。

普通六件蓝装购价约0.96H；同级8小时有效公共修行＋5日常净2.5H，给普通玩家确定换装入口。30普通红核心每个24碎片、每周4片，六核心36有效周；六红铸造加六件+15陨铁期望约130.107枚，周3折43.369周供应量，两进度可并行。精确概率期望不是实际毕业日期或分位数，也未证明玩家接受这一极长线。

骑士独处、符文准备成本、不同风险档的恢复时间、真实主动操作≤15分钟、材料市场价格与P95回收边界都未完成动态验证；本轮没有声称通胀稳定。字段完整后，第5项写账本/命令/跨期恢复，第6项写玩家流程与验收。

## 一、v1 暴露的问题（实测数据）

### 打怪几乎没有成本

| 付出 | 实际代价 |
|---|---|
| 时间 | 5～15 秒 |
| 内力 | 几十点，几秒回满 |
| 气血 | **打坐免费回 35%，无限次、无冷却** |
| 金疮药 | 30 两，但打怪 15% 掉落 → **根本不用买** |

**净成本约等于零，收益全是白赚。** 有了这个前提，任何"多打就多得"的设计都会被刷爆。

### 死亡不痛

丢一成银两，被抬回客栈，打坐三次满血继续。**经验不掉、装备不损、没有冷却。**
结果是越级挑战、送死试探都没有代价，风险设计全部失效。

### 升级需求跟不上输出增长

```
等级   升级需要    同级怪给   要打几只
 10       3774       150     25.2 只
 30      24273      1800     13.5 只
 50      58409      9500      6.1 只
 80     131598     28000      4.7 只   ← 越高级越轻松
```

`need(lv) = 60·lv^1.75 + 40·lv`，而玩家输出是
**属性(线性) × 武功倍率(4.5→6.8) × 装备打造倍率(1→2.08)**，三者相乘，涨得远比 need 快。

**这是数值膨胀的根子**：不压制的话，等级越高升级越轻松，最后必然爆炸。

## 三、货币的进与出（**v1 现状盘点**）

> 下面这张表是 **v1 跑出来的实况**，列在这里只有一个用途：
> **看清哪些口子没有上限**。v2 的产出数值全部重定，不继承这里任何一个数。

### 进（产出）

| 来源 | 量级 | 有没有上限 |
|---|---|---|
| 打怪 | 怪身上的 0.7~1.3 倍 | **无上限**，能刷多少是多少 |
| 械斗 | `20 + 等级×14` | 无上限 |
| 擂台 | 80~7000 | 无上限 |
| 泡点奇遇 | 挂机被动 | 有上限（受时间限制）✓ |
| 赌坊 | 期望 0 | 零和 ✓ |

### 出（回收）

| 去处 | 类型 | 够不够 |
|---|---|---|
| 打造 | **无底洞** ✓ | 最有效的一个 |
| 装备、武功 | 一次性 | 买完就没了 |
| 请客、送花、成亲 | 社交消费 | 有效，但频次低 |
| 集市抽头、押注彩头 | 一成 | 有效 |
| 药品、酒菜 | 小额 | 因为药会掉落，形同虚设 |
| **车马费** | 跨区域移动，按等级收 | 高频小额，且高等级付得多 ✓ |
| **请郎中** | 立刻解除重伤，按等级收 | 同上 |
| 战败损失 | 一成身家 | 没人故意送死，形同虚设 |

**结论**：回收口的种类不少，但**产出是无上限的**，所以长期必然通胀。
以上是旧v1审计判断；不能据此把装备耐久直接当成首版已启用回收。


## 增加新来源时的检查

每个新来源须回答：在哪个真实内容ID触发；按每小时/日/周能发多少；与哪些既有来源共享额度；具体消费或回收在哪里；失败/重试/跨期是否多发。候选存在不等于正式开启，无法回答时不得以0/免费/无限作为默认值。

天赋点仍由每6级升级固定发放、60级最多10点，不在经济来源中增发。首版D项与参数评审保留在[范围表](首版范围表.md)；本页历史实测均属于旧v1，不是本次新方案验证。
