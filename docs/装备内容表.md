## 2. 短描述规则

- 每件只写一句，目标为 12～40 个汉字；装备卡默认展示短描述，完整来历仍放在 `lore`。
- 凡品、精品写用途、作坊或使用痕迹；珍品写局部逸闻；绝品、神兵写人物、事件或留下的后果。
- 描述不承诺未配置的伤害、控制、命中或掉落效果，不代替属性与技能说明。
- `K0` 等开发纪年不进入玩家文案；旧籍、古碑与旧物不倒灌“元息”等后定术语。
- 断潮、余雾与幽潮不得互换；黑日旧记与“黑日坠海”神谕不得写成同一事件。
- 未定谜团只保留见闻、争议或使用痕迹，不由装备描述宣布真相。
- `contentVisibility` 默认继承装备模板与来源的解锁条件；正式名与短描述只在合法预览或获得时显示，
  不绕过主线和地图的术语可见性。

1. 为其余 45 件套装防具逐件命名并写短描述。
2. 按等级档补齐基础防具、高品阶散件与套装等级版本。
3. 在不改写短描述的前提下，补齐 `templateId`、装备等级、Icon、来源、掉落、词条与完整 `lore`。
4. 对所有橙红名称及描述做公开前关键词、近义名与商标碰撞复核。
