# 万国江湖术语表

> 状态：设定基线 v0.1
>
> 用途：统一世界观、主线、地图、任务、UI、物品文案与本地化所使用的标准名词
>
> 设定母本：[万国江湖世界观](worldbuilding.md)
>
> 年代坐标：[万国江湖编年史](编年史.md)
>
> 叙事分层：[设计原则第十条](原则.md)

## 1. 玩家侧可见性

| 标注 | 含义 | 可用载体 |
|---|---|---|
| **公开** | 不构成揭秘，可由系统、主线或普通 NPC 直说 | UI、地图、教程、必经对话 |
| **随进度** | 玩家可见，但首次出现不得早于相应主线或地图解锁 | 章节主线、到达新地区后的 UI 与对话 |
| **仅碎片** | 可被玩家找到，但不由早期主线或百科直接公布 | 旧籍、物品、场景、支线、互相印证的见闻录 |
| **否（开发侧）** | 只是制作约定，世界内人物不使用 | 设计文档、数据表、注释 |

“仅碎片”不等于事实未定；它可以是开发侧已经确定、但玩家需要找到证据才能知道的历史。

## 2. 核心现象与历史

| 标准词 | 定义 | 玩家侧 | 文案与本地化约束 |
|---|---|---|---|
| **元息** | 天地间无处不在的生命与精神之息；不同传承的力量对它有不同解释。 | **公开（系统）/ 随进度（叙事）** | K-1 才定下的跨文化译名。系统属性统一用此词；中原旧籍、古碑、旧舆图和古人留言禁用。不得写成可采集、封存或运输的物质。 |
| **断潮** | K-16 起阻断大部分远洋航路的无向海雾，K-4 起退去但未消失。 | **公开** | 专名，不是普通“断流”，也不是历法名。不与“幽潮”互换。 |
| **余雾** | 断潮退去后仍残留在深海与部分航线上的海雾。 | **公开** | 是断潮的残留状态，不是第三种独立异常。 |
| **幽潮** | 在深海与偏僻航线出现、漆黑如油又近似雾的潮汐，会以不同方式扰动十派力量。 | **随进度** | 归航者的共用名，不是经证实的学术分类。不得写成断潮的必然后继、唯一本体或已确定最终敌人。 |
| **气盛之地** | 中原旧语，指山川气机相对浓郁的地域。 | **公开** | 用于旧籍、古碑、旧舆图与传统人物；这些来源不得改称“元息盛区”。 |
| **元息盛区** | 通译馆对当代测绘中元息相对浓郁区域的统称。 | **仅碎片** | 当代跨派学术用语。与“气盛之地”是不同年代的描述，差异不能本地化成同一词而被抹掉。 |
| **黑日 / 黑日坠海** | “黑日”是 K-218 旧记的当代译名；“黑日坠海”特指 K-5 当代神谕。 | **仅碎片** | 两者关联但不等同，不得缩成同一条历史记录，也不得由名称相似推定同源。 |
| **大雾闭海** | 对西来残卷中 K-216 闭海事件的当代索引名。 | **仅碎片** | 不是残卷原文的固定四字术语，不得直接改写为“上一次断潮”。 |

## 3. 传承与玩家身份

| 标准词 | 定义 | 玩家侧 | 文案与本地化约束 |
|---|---|---|---|
| **传承** | 对十种力量道路、组织、礼法与共同记忆的跨文化上位称呼。 | **公开** | 不是“技能树”的世界内同义词。中原日常可说“门派”，海外组织不强行都称门派。 |
| **传承之所** | 十个传承专属地域的统称，同时包括建筑、周边山川、道路、居民、礼法与日常生活。 | **公开** | K-1 跨文化译名。只在统称时使用；具体场景必须用“藏经坪”“群星回廊”等专名。不等于据点或某一栋建筑。 |
| **选择传承 / 择承** | 玩家选择愿意藉以理解和修行世界的一条传承；“择承”为 UI 和跨派语境简称。 | **公开** | 不以“拜师”代称十派全部加入仪式。各派内部仍用受戒、入学、宣誓、受印等自有说法。 |
| **门望** | 个人在所属传承中的名声、责任和受认可程度。 | **公开（系统）** | 可量化，但不是钱币、官职或可交易余额。各派叙事使用师门贡献、学分、功勋、功德等自有名称。 |
| **外传之技** | 可由本门之外的人通过具体任务真正学会、但不足以替代该派完整道路的技艺。 | **随进度** | 十派都有，不是海外专属；不是“公开课”“万国授艺”，不得只用“声望到了”解释获得原因。 |
| **四案** | K0 四个出生地在同一段时间发生的异常事件合称。 | **随进度** | 玩家开场只知自己的故乡事件；到洛阳汇总证言后才可把“四案”作为固定合称。 |
| **行走见证人** | 四海会馆授予玩家的调查与送证身份，核心是责任而非特权。 | **随进度** | 只能在《空旗之下》第三幕获授后使用；不得写成会馆审判十派的授权。 |

## 4. 地点与组织

| 标准词 | 定义 | 玩家侧 | 文案与本地化约束 |
|---|---|---|---|
| **万国码头** | 由东海旧港扩建而来、连接中原与海外五条航线的事实独立中立港。 | **公开（名称）/ 随进度（地图）** | 专名。K-2 定名，不得写成断潮前就存在的同名港口，也不得写成一个国家或十派之上的都城。 |
| **四海会馆** | 由官员、海商、通译、退役船长和各方见证人组成，依靠航图、通译、身份见证与共同需要维持港内秩序。 | **随进度** | 专名。是裁决与协调组织，不是朝廷官署、世界政府或能压服十派的超级门派。 |
| **通译馆** | 万国码头内整理各国语言、礼节、地图和传承称谓的机构，由早期临时通译桌发展而来。 | **随进度** | 专名。是译名与档案的来源，不是所有语言和力量的终极解释者。 |
| **万国行栈** | 洛阳东水门的客货中转处；在地图与任务中同时概括从洛阳到东海港口的整段旅程。 | **公开** | 场景专名与地图抽象共用；不得把它写成与万国码头同地的另一座码头。 |
| **无名蓝旗** | 四海会馆悬挂、没有文字与纹章的蓝旗，表示无人能声称拥有整片海洋。 | **随进度** | “无名”指不归属单一文字、国家或门派，不是会馆成员必须隐去个人姓名。 |
| **海客街** | 沿码头仓库自然形成的商贸与消息集散地。 | **随进度** | 专名。不与“万国码头”互译或代指整座港口。 |
| **万国江湖** | K-1 定下的跨文化总称，指中原与海外传承开始长期共处后的共同世界。 | **公开** | 是方便沟通的折中译名，不表示所有文化已合并为同一个组织。 |

## 5. 主线调查用语

| 标准词 | 定义 | 玩家侧 | 文案与本地化约束 |
|---|---|---|---|
| **黑帆舰队** | 无国家纹章、袭击过北海长船的船队；部分船员对疼痛没有正常反应。 | **随进度** | 不得把全体船员统称为守雾人、幽潮怪物或同一类敌人。 |
| **守雾人** | 《空旗之下》中试图通过伪证、仇恨与人为危机迫使万国码头闭港的群体。 | **随进度** | 主线调查确立其存在后才作固定称呼。他们利用幽潮而非制造幽潮，也不是一个延续两百年的古老教团。 |
| **断潮沉船** | 主线后开放的沉船禁地类内容总名。 | **随进度** | 内容名，不是 K-4 首批归港商船的代称，也不预示其中必然藏有断潮唯一真相。 |

## 6. 编写与本地化检查清单

新增世界观、任务、地图、物品或 UI 文案时，至少检查以下五项：

1. 每个年份是否已换算到 K0，并与[编年史关键年份表](编年史.md#2-关键年份表)一致。
2. 文本中的人物是否有资格在那个年代使用该术语，尤其不要让 K-1 之前的文本使用“元息”。
3. 同一概念的统称和各文化自称是否被保留，不要把内力、魔力、圣息等全部叙事对话机械替换成“元息”。
4. 玩家第一次看到该词的时机是否符合“公开／随进度／仅碎片”标注，不要让 UI 或教程提前剧透。
5. 神谕、残卷、口传和舆图只能证明其确实存在；如果其解释仍属“未定猜想”，本地化不得用更确定的语气替玩家下结论。
