# 设计文档 · v2

**这里是 v2 的设计，不是对 v1 的改造。**

v1 是已经跑起来的那版（根目录 [README](../README.md) 描述的），
v2 会**清档重来**，不继承它的等级、地图、任务、数值。
唯一沿用的是**泡点框架**（每 2 秒结算、场地门槛、超出衰减、挂着就涨关掉就停）。

文档里凡是提到 v1 的地方，都只有一个用途：**它是踩过的坑的证据**。
不是约束，也不是要修复的对象——v2 照着避开就行。

想清楚了再动手，先不写代码。只看未来规划时先读
[规划目标总览](规划目标总览.md)。

## 怎么用这些文档

- 多数玩法草案末尾有「待拍板」，那是设计里还没定的岔路口。定了就把结论写回文档，别留在聊天记录里。
- 数据结构示例是给实现时参考的**形状**，不是最终代码，动手时可以调整。
- 觉得某条设计不对，**直接改文档并说明理由**——文档是活的，改文档比改代码便宜得多。
