## 怎么用这些文档

- **每篇末尾有「待拍板」**，那是设计里还没定的岔路口。定了就把结论写回文档，别留在聊天记录里。
- 数据结构示例是给实现时参考的**形状**，不是最终代码，动手时可以调整。
- 觉得某条设计不对，**直接改文档并说明理由**——文档是活的，改文档比改代码便宜得多。
