## 2. ID、字段和权威关系

| 命名空间 | 单一权威 | 使用边界 |
|---|---|---|
| scene / location / instance | 场景表；两实例玩法由家园表维护 | scene可独立进入，location是景内地点，instance是私有运行模板；不可混算完成度 |
| mob / encounter / behavior | 怪物表；40学艺与10公开试演入口由任务表有限登记 | 模板与战斗实例分开；同模板多次刷新不生成新模板ID |
| equip / set / affixPool | 装备表；词条数值在装备与打造 | template不是背包uid；名称不是兼容判定；十声唯一性另有合同 |
| jing / xuan / mat / recipe / blueprint | 材料表 | 保留已有精铁/玄晶ID；材料档M1～M4不等同开发阶段；图纸资格不是可卖材料 |
| GX/LY/MT/ZC/WX/HY/HID/HOME/DG/DQ/WQ、npc/evidence/interaction | 任务表；HOME/DG由家园表；DQ/WQ由日常表 | 保留大小写；案卷不占交易背包；主线结果不被地区任务重写 |
| skill / talent | 技能/天赋索引映射原技能/天赋合同 | 不复制数值；隔离教学借用不写永久习得；不从装备名生成新技能 |
| reward / bonus / drop / source | 奖励表及五经济分表 | 来源是渠道、掉落包是载荷、领取是一次事件；三者不是三个独立奖励 |
| crop / seed / food / relic / curse / supply / layout / event | 家园表 | 本局奇物/补给与永久物品分开；事件不额外算任务或世界scene |
| achievement / codex / display / ticket | 收藏索引、奖励表 | 候选与已发布分开；展示不给战斗属性，门票不增加周次数 |

已有ID保留；本轮新增ID一旦采纳即冻结身份，改名只改显示名。删除留停用记录，不重排复用编号。技能和同名天赋不互换，空手不是装备模板。编号中的n01等是登记号，不是运行数组下标。任何有限展开必须写明允许集合和载荷，未知字符串不能自动创建奖励、怪物或物品。

每类行至少有：ID、显示名/原文、类型、等级/范围、前置或来源、阶段、数值/行为权威、状态。状态分成多项，不能仅用“已完成”掩盖缺口：

- **沿用合同**：原规则/名称/ID有权威；不代表运行实现存在。
- **本轮提案**：具体值可评审，未等同用户批准。
- **待范围裁定**：D01～09相关项，不能自动投放或计入完成度。
- **待经济参数**：仅用于仍未进入本轮推荐的扩展/D项；当前首版基础五表的cost/quantity/chance/cap已有具体推荐值，不能仍用pending-economy代替，也不能将未知值默认0/无限。
- **待平衡/体验验证**：有参数/课题，但未证明实际可打赢/可完成。
- **待制作/实现**：图标、文字与显示仍未交付；第5项已有存档字段/命令合同，尚未开发。
