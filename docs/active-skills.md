# 门派主动技能体系设计

> 状态：主动技能平衡基线 v0.5（已完成全量构筑复验）
>
> 范围：10 个门派，每派固定 5 门本门主动技能，共 50 门；同时定义外传之技的系统边界。本文不设计被动技能。
>
> 依赖：[回合制战斗机制](turn-based-combat.md)与[门派天赋体系](talent-system.md) v0.5。玩家自由分配天赋点，改变同一组主动技能的玩法侧重。

## 1. 设计结论

- 每个门派只有 5 门主动技能，角色上场时五门全部可用，不再按天赋路线各做一套技能。
- 五门技能分别承担基础循环、主要输出、战术反制、生存续航、绝学收束。
- 每个门派只有第 5 门技能是绝学，每场战斗限用 1 次。
- 不设官方构筑、主副路线、推荐配点或固定技能组合；构筑完全由玩家自由分配天赋点形成。
- 本文只定义玩家主动选择施放的技能。入场、受击、致命保护等被动效果仍以天赋文档为准。
- 克制通过 `heavy`、`multi`、`weapon`、`spell`、`guard`、`shield`、`dot`、`cast` 等标签实现，不写门派对门派的固定增伤。

## 2. 通用规则

### 2.1 五技能职责与预算

| 槽位 | 职责 | 基准数值 |
|---|---|---|
| 1·起手 | 无冷却的稳定招式，生成门派资源 | v0.5 实际威力 0.74～1.09，消耗 7%～9% 最大内力 |
| 2·主攻 | 消耗资源或形成主要伤害循环 | v0.5 基础威力 0.87～1.28，消耗 10%～13%，CD 1～2 回合 |
| 3·战术 | 控制、打断、破盾、净化或换招 | v0.5 威力 0.52～0.95，消耗 12%～15%，CD 3～4 回合 |
| 4·生存 | 护体、护盾、闪避或恢复 | v0.5 威力 0.34～0.62，消耗 13%～16%，CD 4 回合 |
| 5·绝学 | 兑现资源并结束一轮循环 | v0.5 基础威力 0.99～1.57，资源完整时再叠加明文增量，消耗 24%～28%，每场一次 |

普通拳脚是内力不足时的系统保底，威力 0.60，不占五技能之一、不生成门派资源，也不受专属天赋强化。

### 2.2 数值口径

- “威力”进入角色攻击、防御公式后，再应用玩家实际天赋产生的增减益。
- 所有战斗场景沿用本表明文数值，不设置模式专属倍率；平衡依据见[战斗数值模拟与平衡结论](combat-balance-simulation.md)。
- 固定最大气血百分比伤害、恢复比例、护盾比例、控制概率和资源层数不受伤害增益影响。
- 护体按比例降低直接伤害；护盾优先于气血承伤；同名状态只刷新持续时间，不叠加数值。
- 控制最多令目标损失一次行动。沉默、武器封锁等标签限制不跳过回合，只迫使目标改用其他技能；缠兵只降低符合技能威力，不限制宣告。
- 持续伤害默认可净化、不暴击、不触发吸血；提前结算后移除对应持续效果。
- 冷却在技能完成支付后登记，本次行动不推进刚登记的冷却；持续时间按效果类型锚定，具体时序以[回合制战斗机制](turn-based-combat.md)为准。

### 2.3 标签与结算

| 标签 | 含义与主要反制 |
|---|---|
| `fist` | 拳掌、爪指，可被拳掌招架识别。 |
| `weapon` | 剑、棒、枪、斧、针和苦无，可被缠兵、破剑识别。 |
| `spell` | 元素、咒术、神术，不受武器封锁影响。 |
| `heavy` | 高威力单段重击，可被卸力、招架反制。 |
| `multi` | 多段攻击；触发型效果只按整招首次命中完整结算一次。 |
| `cast` | 吟唱或蓄力，可被打断；被打断返还 50% 已支付内力。 |
| `guard` | 产生护体、招架或反击窗口。 |
| `shield` | 产生优先承伤的护盾。 |
| `heal` | 直接或持续恢复，受重伤影响。 |
| `dot` | 毒、灼烧、流血或诅咒，可被净化。 |
| `ultimate` | 绝学，每场战斗限用一次。 |

统一结算顺序：支付消耗 → 宣告吟唱／蓄力 → 命中 → 直接伤害 → 护盾与气血变化 →
吸血／恢复 → 附加状态 → 生成或消耗资源 → 反击与追加攻击 → 致命保护 → 回合末持续效果。

## 4. 外传之技

外传之技是可由本门之外的玩家真正学会、但不能代替该派完整传承的技艺。
它属于技能系统，不作为世界观设定维护；十派都应有外传之技，不是海外五派的特例。

每门外传之技必须满足以下边界：

- 不依赖只有本门弟子才能承担的誓言、秘药、血脉、禁书、身份或核心仪式。
- 外门玩家学到的是一门完整可用的技艺，但不会因此获得该派身份、核心传承或整套门派循环。
- 不设统一授艺 NPC、公开课程或到点自动解锁；具体获得原因与过程由[任务系统](任务系统.md)承载。
- 技艺名称、战斗效果、强度预算、可掌握数量和装配方式都在本文后续版本确定，不由任务、世界观或场景文案各自定义。

当前 v0.5 的十派固定五技能和全量构筑复验**不包含外传之技**。
在上述数量、装配与预算规则定案前，实现不得把外传之技直接加成第六个无条件可用的主动技能，
已有五技能的平衡结论也不能作为外传之技已完成设计的依据。

## 5. 主动技能与玩家构筑的边界

五门主动技能是门派固定工具，构筑来自玩家对天赋的自由混合，不来自额外技能池：

- 主动技能基础威力、内力消耗、冷却、命中与基础状态只在本文维护。
- 天赋可以修改已有技能或资源规则，但不增加第六个主动技能，不替玩家自动选择路线。
- 没有相关天赋时，五门主动技能仍须形成完整循环，不能依赖被动天赋才能正常施放。
- 本文不提供推荐配点、主副路线、官方套路或克制表答案。
- 同名主动技能的基础效果以本文表格为准；点出同名天赋后的增量、触发和数值以天赋文档对应条目为准。实现时必须使用不同内部 ID，不能因同名把天赋增量当成无条件技能基础值。

本文是主动技能设计的唯一来源。现有 `gamedata/skills.js` 中的旧技能只作为名称迁移参考，不代表最终机制和倍率。
