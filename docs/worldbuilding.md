# 万国江湖世界观设定

> 状态：世界观草案 v0.2
>
> 范围：海外传承入世、万国码头、十派传承之所、力量体系与世界矛盾
>
> 关联文档：[门派天赋体系设计](./talent-system.md)

## 1. 文档边界

本文是后续玩法设计共同依赖的“设定母本”，只回答以下问题：

- 为什么海外门派会在此时进入中原江湖。
- 中原与海外为何能够理解、学习和对抗彼此的力量。
- 万国码头在世界中是什么地方。
- 十个门派分别生活在哪里，如何维系自己的传承。
- 哪些历史、矛盾和谜团可以供后续内容继续生长。

本文不规定具体任务、奖励、数值、开放等级、战斗流程或活动形式。后续玩法可以从这些设定中衍生，也可以在不破坏核心事实的前提下补充新的历史细节。

## 2. 从“中原江湖”到“万国江湖”

过去十余年间，东海深处常年笼罩着一片无法穿越的海雾。雾中没有星辰、日月和方向，罗盘也会失去作用。出海者称它为“断潮”。

断潮隔绝了大部分远洋航路。中原仍能从旧书、舶来器物和少数幸存船员口中听到海外传闻，却无人能够证明那些学院、城堡、忍村、战团和神殿是否真实存在。

直到近年，断潮开始退去。

最初回来的只是几艘遍体鳞伤的商船，随后是护送商旅的骑士、记录海雾的学者、追踪仇敌的忍者和循着古老预言而来的祭司。不同航线在东海旧港重新汇合，中原朝廷遂将旧港扩建，赐名“万国码头”。

海外来客并非以征服者身份进入中原。他们有人寻找知识，有人追查失踪者，有人重建贸易，也有人相信断潮消散意味着一场更大的灾难正在靠近。

中原武林最初对海外传承抱有戒心。数次公开切磋之后，人们发现海外技艺虽然形貌奇异，根本上却与内功、身法、阵法和奇门术数存在能够互相解释的部分。江湖因此第一次真正从“中原武林”变成了“万国江湖”。

## 3. 元息与诸国异名

不同文明对超凡力量有各自的解释，但这些力量都来源于天地之间一种无处不在的生命与精神之息。四海会馆的学者将其统称为“元息”。

“元息”不是所有门派共同使用的日常称呼，而是跨文化交流时采用的译名。

| 传统 | 常用称呼 | 对力量的理解 |
|---|---|---|
| 中原门派 | 内力、真气 | 元息行于经脉，通过吐纳、心法和招式发劲。 |
| 奥术学院 | 魔力、奥术 | 元息可以被符文、语言、意志和元素结构塑形。 |
| 王冠骑士团 | 圣息、斗志 | 誓言使人的意志与武器、盾牌及同伴产生共鸣。 |
| 影之忍宗 | 忍气 | 元息应当被收束、隐藏，在最短一瞬间完成行动。 |
| 北海战团 | 怒气、战意 | 伤痛、勇气和群体传唱能够唤醒沉睡于血肉中的力量。 |
| 太阳神殿 | 神力、神谕 | 元息随日月、死亡和时间流转，人只能解释征兆，不能完全支配它。 |

这套解释使不同传承可以彼此对抗，也解释了为什么一个中原武者能够理解最基础的海外技艺。但“能够理解”不等于“能够掌握核心传承”：真正的绝学仍依赖门派长期训练、独有仪式和对本门道路的认同。

## 4. 世界地理

游戏地图不是按真实距离逐里展开，而是呈现江湖人物会长期停留、相遇和发生故事的重要地点。

```text
杏花村
└─ 村外与后山
   └─ 洛阳官道
      └─ 洛阳城
         ├─ 中原山门
         │  ├─ 嵩山·藏经坪       少林寺
         │  ├─ 武当·紫霄宫       武当派
         │  ├─ 峨眉·金顶云台     峨眉派
         │  ├─ 洞庭·君山总舵     丐帮
         │  └─ 华山·思过崖       华山派
         │
         └─ 洛阳·万国行栈
            └─ 东海·万国码头
               ├─ 雾海航线 → 星辉学院·群星回廊
               ├─ 西陆航线 → 白垒堡·誓约厅
               ├─ 扶桑航线 → 胧月里·影庭
               ├─ 北海航线 → 鲸骨湾·英灵长屋
               └─ 金沙航线 → 日轮圣城·神殿前庭
```

洛阳仍是中原江湖的中心。中原门派从洛阳通往各自山川，海外航路则必须经由万国行栈和万国码头。万国行栈代表从洛阳搭乘漕船、车马前往东海的整段旅程，因此地图上不必表现沿途每座城镇。

海外传承之所位于不同大陆、岛屿和海域。它们并不真的聚集在码头背后，而是只有从万国码头才能找到可靠船只、通译和熟悉断潮余雾的领航者。

## 5. 传承之所

“传承之所”是十个门派专属地域的统一称呼，用来替代宽泛而缺少文化意味的“据点”和千篇一律的“本门·后山”。

传承之所不仅是建筑，也包括周围山川、道路、居民、礼法和日常生活。一个门派之所以成为门派，不只是因为它拥有几门技能，还因为一群人长期在同一个地方以相似方式理解世界、传授技艺并维系共同记忆。

“传承之所”只作为世界设定中的统称，各地始终使用自己的专名。

## 6. 中原五派传承之所

### 6.1 少林寺：嵩山·藏经坪

藏经坪位于少室山深处，背靠藏经阁，前临千级石阶。晨钟暮鼓传遍山谷，武僧在天色未明时便开始挑水、扫阶、负鼎和诵经。

少林相信身体与心性不可分割。横练不是为了不受伤，而是为了在承受痛苦时仍然守住本心。寺中最受尊敬的未必是拳脚最强的人，也可能是几十年如一日守着山门、药庐或藏经阁的老僧。

藏经阁保存着不同年代的武学与见闻，其中也有关于古代海外方士和西来修行者的残卷。少林因此是中原五派中最早承认海外力量与内力可能同源的门派之一。

### 6.2 武当派：武当·紫霄宫

紫霄宫依山势而建，宫墙之外便是翻涌云海。弟子在松下推手，在石台观云，于水声、钟声和风声中体会阴阳变化。

武当不认为力量必须被正面抵挡。山势、水势、人心和敌意都在变化，真正的修行是听清变化从何处开始，再让它走向另一处。

宫中道人对海外天文学和奥术学院的星图颇感兴趣，却对把一切力量写成固定符文的做法保留意见。在他们看来，图可以描述一时之理，却不能代替对变化本身的体悟。

### 6.3 峨眉派：峨眉·金顶云台

金顶云台立于万丈云海之上，日出时整座山峰如同被金光托起。山中泉流和药圃众多，门人既练剑、刺与掌，也精于辨药、疗伤和经脉之学。

峨眉武学强调细微、连贯与分寸。救人和制敌所认的往往是同一处穴位，差别只在落手轻重。门中因此极重视判断，不推崇只凭威力决定高下。

海外毒物和神殿护符进入中原之后，峨眉成为最早系统辨析这些异物的门派。她们既不盲目排斥，也不允许来源不明的药物在江湖中随意流传。

### 6.4 丐帮：洞庭·君山总舵

君山总舵外表只是几座风雨侵蚀的祠堂和棚屋，真正维系丐帮的却不是房屋，而是遍布渡口、城镇、驿道和市井的人。

丐帮认为消息、道路和人情本身就是一种力量。一个看似不起眼的叫花可能认得三十条小路，也可能知道某艘海外商船昨夜卸下了什么货物。

新航路重开后，丐帮很快把耳目延伸到万国码头。他们不懂所有异国语言，却能从货价、脚印、口音和酒桌上的沉默判断许多事情。四海会馆既需要他们，也始终提防他们知道得太多。

### 6.5 华山派：华山·思过崖

思过崖终年罡风不息，石壁上遍布年代不同的剑痕。有人认为剑痕记录着失传招式，也有人认为那只是前人在孤独中留下的执念。

华山内部长期存在剑与气、技巧与根基、规则与自由之间的争论。门人虽然道路不同，却都相信剑必须指向真正的问题，而不是被形式束缚。

海外技艺出现后，华山年轻弟子对骑士剑术和忍宗暗器极有兴趣，长辈则更关心这些招式背后的道路是否经得起长期磨炼。奥术学院“以符文固定力量”的做法，也成为剑气两派新的争论题目。

## 7. 万国码头

### 7.1 港口景象

万国码头建在东海旧港之上。桅杆密得像一片林子，异国旗帜在海风中猎猎作响。码头工人用不同口音吆喝，披甲骑士、长袍学者、北海水手、沉默忍者与中原商旅擦肩而过。

港口没有统一的建筑风格。中原木楼旁可能立着西陆石砌仓库，北海长屋的鲸骨装饰正对着太阳神殿的金色日晷。每次有新船抵达，港口的边界都会再向外延伸一点。

万国码头既繁华又不安。这里的人比洛阳更愿意接受陌生事物，也更清楚一次翻译错误、一件来历不明的货物或一场酒后的冲突会带来什么后果。

### 7.2 四海会馆

四海会馆位于码头中央，悬挂一面没有文字和纹章的蓝旗，表示它不属于任何国家与门派。

会馆由中原官员、海商、通译、退役船长和各方共同认可的见证人组成。它没有足以压服十派的武力，真正维系秩序的是所有人都需要它保存航图、安排领航者、确认身份并解决语言造成的误会。

四海会馆坚持三条原则：

- 各派可以展示公开技艺，但不得以公开交流为名传播禁术。
- 任何人在码头上的身份首先是旅人、商人或求学者，其后才是门派弟子。
- 海上出现无法归属于任何一方的威胁时，争端必须暂时让位于共同生存。

### 7.3 通译馆

通译馆最初只是几张摆在仓库外的桌子，后来逐渐成为港口最嘈杂的地方。这里整理各国语言、礼节、地图和门派称谓，也记录那些无法准确翻译的概念。

“元息”“传承之所”和“万国江湖”都是通译馆创造的折中说法。没有任何传统认为这些词完全准确，但所有人暂时都能接受。

### 7.4 海客街

海客街沿码头仓库自然形成。这里可以买到舶来布料、香料、书籍、护符、棋具和各地酒食。真正重要的不是商品本身，而是这些物件带来的故事：某枚盾徽属于失踪骑士，某页残书记录着不存在的星座，某只木箱内侧留有被幽潮侵蚀的痕迹。

### 7.5 无名蓝旗

四海会馆的蓝旗没有文字，是因为最早参与建港的人找不到一个能被所有语言正确书写的名称。蓝色代表海，而空白代表任何人都不能声称自己拥有整片海洋。

这面旗逐渐成为万国码头最重要的象征。即使彼此敌对的人进入蓝旗下，也必须暂时放下旧怨。

## 8. 万国授艺

海外五派在万国码头保留有限的公开授艺传统。它的目的不是广收门徒，而是证明自己的技艺并非邪术，也让不同传统拥有最基础的共同语言。

公开技艺被称为“外传之技”或“见闻技”。它们必须满足三条世界观原则：

- 属于门派中广为流传的基础手段，不涉及誓言、秘药、血脉、禁书或核心仪式。
- 外门之人可以模仿其形，却无法仅凭这一招理解该门派的完整道路。
- 传授行为受到四海会馆见证，避免有人以假乱真或借授艺之名招揽私徒。

五派目前愿意公开的技艺是：

| 来源 | 外传之技 | 在门派中的原本用途 |
|---|---|---|
| 奥术学院 | 奥术飞弹 | 学徒学习稳定聚拢魔力时使用的第一种法术。 |
| 王冠骑士团 | 盾缘格挡 | 扈从理解盾牌角度与受力方向的基础练习。 |
| 影之忍宗 | 烟丸遁步 | 用烟雾改变视线、掩护离开的通用技巧。 |
| 北海战团 | 北海战吼 | 水手在风浪和混战中保持勇气、确认同伴位置的呼喊。 |
| 太阳神殿 | 日轮祷言 | 旅人在烈日与沙海中平复呼吸的短祷。 |

这些技艺的存在只确定“玩家有机会从世界中接触并学会一门普通海外技能”。具体如何获得、能够掌握多少、如何装配和表现，由后续玩法设计决定。

## 9. 海外五派传承之所

海外传承之所只能经由万国码头所掌握的航线抵达。这并非人为禁止，而是因为断潮并未完全消失，普通船只仍无法稳定穿越残余海雾。

### 9.1 奥术学院：星辉学院·群星回廊

星辉学院位于雾海深处一座无法被普通海图准确标记的岛屿。岛上夜晚漫长，星光异常明亮，学院的高塔和回廊依照星轨排列。

群星回廊的墙壁刻满会随天象缓慢变化的符文。学徒在这里学习控制最微弱的光与热，资深学者则争论符文究竟是在命令世界，还是在说服世界接受另一种可能。

学院内部存在三种主要传统：研究元素秩序的元素学派、研究语言与意志的咒术学派，以及相信万物可以交换形态的炼金学派。三派经常争论，却共同守护学院最古老的星图。

学院来到中原，是因为断潮海雾中出现了不属于火、冰、雷或任何已知元素的力量。有人认为那是一种尚未命名的元素，也有人认为它根本不该被称为元素。

### 9.2 王冠骑士团：白垒堡·誓约厅

白垒堡立于西陆海崖，城墙使用当地近乎银白的石材砌成。风暴来临时，海浪会一直拍到堡垒下方的岩洞。

誓约厅中挂着历代骑士的盾徽。盾徽并不只代表荣耀，也记录主人曾经违背、修正或重新立下的誓言。骑士团相信从未犯错的人不一定值得信任，真正重要的是一个人是否愿意为自己的选择承担后果。

骑士团并非一个王国的军队。最初的王国早已分裂，骑士们仍以“王冠”为名，是为了纪念一种高于具体君主的责任：强者必须为无法持盾的人站在前面。

他们来到万国码头，一方面护送西陆船队，另一方面寻找一支在断潮中失踪多年的远征队。港口偶尔会出现属于那支远征队的旧盾徽，却从未有人见过幸存者。

### 9.3 影之忍宗：胧月里·影庭

胧月里藏在扶桑群山的竹雾之间。外人沿山路走到尽头，只会看见一座荒废村落；真正的影庭位于暗门、水道和层层错置的庭院之后。

忍宗认为力量越引人注目，留下的破绽就越多。门人学习隐藏呼吸、改变脚步、辨认气味，也学习如何在不拔刀的情况下结束冲突。

毒术在忍宗并不被视为卑劣手段，而是一种要求严格分寸的知识。能够杀人的毒也可能成为救命的药，区别在于剂量、时机和使用者是否愿意承担结果。

影之忍宗来到中原，是为了追查一批冒用忍宗印记的刺客。这些人使用来源不明的变异毒物，并故意让尸体指向海外门派。忍宗没有公开自己追查到了什么，只确认那些毒物曾经经过断潮海域。

### 9.4 北海战团：鲸骨湾·英灵长屋

鲸骨湾位于北海群岛之间，巨大的鲸骨撑起长屋屋脊，火塘终年不灭。每当有人远航归来，长屋便会增加一段新的歌。

北海人相信，只要名字仍被传唱，死者就没有完全离去。战歌不仅歌颂胜利，也会记录失败、怯懦、错误判断和没有归来的船。删去失败被视为比失败本身更可耻。

战团并非只崇尚蛮力。能够在风暴中分辨绳索断裂声、在混战中听出同伴呼喊、在愤怒中停下战斧，同样被视为真正的勇武。

他们来到中原，是为了追逐一支袭击北海长船的黑帆舰队。黑帆船不悬挂任何国家纹章，船员也像感受不到疼痛。战团相信这些人把某种来自断潮深处的东西带到了陆地。

### 9.5 太阳神殿：日轮圣城·神殿前庭

日轮圣城建在金沙洲的大绿洲旁，巨柱、长阶和水渠依太阳轨迹排列。神殿前庭遍布日晷，不同季节会在地面投下不同图案。

太阳神殿不把神谕理解为不可更改的命令。神谕只是世界投下的影子，而影子会因为观察者、时间和位置改变。祭司真正学习的是如何区分警告、诱惑和自我欺骗。

神殿同时保存与太阳、死亡和记忆有关的传统。日轮祭司关注生命和秩序，冥府祭司研究结束、诅咒与代价，神佑祭司则守护人们不被无法理解的力量伤害。

大祭司在断潮消散前看见了“黑日坠海”的神谕。不同祭司对此有完全相反的解释：有人认为黑日代表灾难，有人认为它代表被遮蔽的真相终于浮出海面。

## 10. 十派在万国江湖中的位置

十个门派并非按中原与海外简单分成两个阵营。它们在知识、秩序、道路和责任上存在复杂关系。

- 少林与骑士团都重视守护，但对誓言是否必须写下存在分歧。
- 武当与奥术学院都研究世界规律，却分别相信变化不可固定与规律可以书写。
- 峨眉与太阳神殿都掌握治疗和身体知识，对诅咒是否可以作为治病手段争论不休。
- 丐帮与北海战团都重视口耳相传，一个依靠消息网络，一个依靠战歌保存记忆。
- 华山与影之忍宗都追求在关键一瞬解决问题，却对“正面”与“隐蔽”的价值看法不同。
- 骑士团尊敬少林的自律，却难以理解丐帮没有成文誓约也能维持庞大组织。
- 奥术学院希望研究神殿神谕，神殿则认为被观察的神谕会改变含义。
- 忍宗与丐帮都拥有广泛耳目，因此既容易合作，也最容易互相怀疑。

这些关系是观点和历史造成的张力，不代表固定敌对或联盟。后续故事可以让其中任何两派合作，也可以让同一门派内部出现不同立场。

## 11. 通用称谓

### 11.1 选择传承

“拜师”无法准确描述所有组织，因此跨门派语境使用“选择传承”或“择承”。各门派保留自己的加入说法：

| 门派 | 自有说法 |
|---|---|
| 少林寺 | 受戒入门 |
| 武当派 | 录入门墙 |
| 峨眉派 | 敬茶拜师 |
| 丐帮 | 接袋入帮 |
| 华山派 | 登山拜师 |
| 奥术学院 | 正式入学 |
| 王冠骑士团 | 宣誓受封 |
| 影之忍宗 | 受印入门 |
| 北海战团 | 饮下盟酒 |
| 太阳神殿 | 接受祝圣 |

### 11.2 门派领袖

跨门派语境使用“领袖”，各派内部使用方丈、掌门、帮主、院长、大团长、影主、战团首领和大祭司等称谓。

### 11.3 门望

“门望”表示一个人在所属传承中的名声、责任和受认可程度。它不是单纯的钱币，也不完全等于官职。

不同门派会称其为师门贡献、帮贡、学院学分、骑士功勋、忍务功绩、战团声望或神殿功德，但这些称呼表达的是同一类社会关系：门派愿意把多少责任与秘密交给这个人。

## 12. 幽潮

断潮海雾虽然退去，却没有真正消失。深海和偏僻航线上偶尔会出现一种漆黑如油、靠近后又像雾的潮汐。接触过它的人称其为“幽潮”。

幽潮能够影响不同形式的元息：

- 中原武者会感到真气逆行，经脉中出现不属于自己的运转方式。
- 奥术符文会自行增殖，写出施法者从未学过的结构。
- 骑士会听见誓言以自己的声音要求他们做出极端选择。
- 忍宗毒物会产生无法按剂量预测的变化。
- 北海战士会在没有敌人的地方感到无法平息的愤怒。
- 太阳神殿会同时得到互相矛盾、却似乎都正确的神谕。

没有人知道幽潮究竟是什么。目前存在几种说法：

- 它是断潮海雾留下的残余。
- 它是某种沉没文明使用元息的方式。
- 它不是力量，而是元息失去解释之后呈现的状态。
- 断潮并非阻止人们出海，而是在阻止幽潮靠岸。

上述说法在当前世界观中都没有被证实。幽潮应长期保持为可补充、可重新解释的共同谜团，而不是立即写死来源和最终敌人。

## 13. 可继续生长的世界线索

以下内容是开放线索，不预设具体玩法形态：

- 万国码头停泊着一艘没有船员、船籍和航海日志的破船。
- 白垒堡失踪远征队的盾徽偶尔出现在中原旧货市场。
- 奥术学院古星图上存在一颗只在断潮海雾中才能看见的星。
- 冒用影之忍宗名义的刺客似乎能够使用多个门派的基础技艺。
- 黑帆船员身上没有伤痕，却不会对疼痛产生反应。
- 太阳神殿关于“黑日”的记录比断潮出现的年代更早。
- 少林藏经阁中的西来残卷提到过一次与断潮极其相似的“大雾闭海”。
- 丐帮掌握一首流传在不同港口的童谣，各地歌词不同，结尾却都提到蓝旗下的无名之人。
- 武当道人发现断潮消散的年份与某次罕见星象完全重合。
- 华山思过崖最深处有一道不像剑痕、也不像任何中原兵器留下的刻痕。

这些线索可以被未来内容采用、合并、否定或重新解释，只要不破坏已经确定的世界核心事实。

## 14. 世界观核心不变量

后续补充设定时，应尽量保持以下事实稳定：

1. 海外航路曾被断潮隔绝，近年才重新开放。
2. 万国码头是中原与海外传承交汇的中立港口。
3. 四海会馆依靠航图、通译、见证和共同需要维系秩序，不是压服十派的超级组织。
4. 不同力量同源于元息，但各门派的解释和修行道路仍不可互相替代。
5. 每个门派都有唯一且具体的传承之所，不再共用“本门·后山”。
6. 海外传承之所必须通过万国码头和对应航线抵达。
7. 万国码头允许公开交流基础海外技艺，但不传播任何门派的核心传承。
8. 中原与海外不是固定敌对阵营，门派关系应当是交错、多边且会随人物和事件变化的。
9. 幽潮是共同谜团，不在早期确定唯一解释和最终答案。
10. 新文化应当拥有内部差异，不能把任何现实地域整体写成单一性格或天然反派。
