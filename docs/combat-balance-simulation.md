# 战斗数值模拟与平衡结论

> 状态：逐节点校准记录 v0.4
>
> 依赖：[门派天赋体系](talent-system.md) v0.4 与[门派主动技能体系](active-skills.md) v0.4
>
> 适用范围：所有战斗场景沿用同一套技能、天赋、事件和数值，不设置模式专属倍率。

## 1. 本轮结论

- 十派固定 50 门主动技能与 180 个天赋节点均进入构筑枚举；玩家使用 10 点自由配点，不设官方构筑。
- 每派得到 75 个合法构筑，共 750 个构筑；全量两两对战 280,875 场。
- 十派平均胜率为 47.04%～53.32%，平均战斗长度为 18.89 回合。
- 最强门派级克制为影之忍宗对奥术学院 67.94%，没有对局超过 70% 克制上限。
- 门派底座与机制克制达到本阶段的近似平衡，可以作为后续装备、属性和操作系统的共同底座。
- 任意合法配点并不等于有效构筑。单构筑全局胜率仍为 18.29%～72.56%；低值主要出现在资源出口、终极触发条件和自动出招策略互不匹配的配点。本轮不据此宣称“任意乱点都等强”。
- 163 个节点按具体事件钩子执行；17 个尚依赖目标选取、位移、材料换元素或精确分段等未来能力的节点，按对应阶段的保守预算折算。上线前仍须在正式事件引擎中逐节点复验。

## 2. 平衡目标与验收口径

| 范围 | 目标 | v0.4 结果 | 结论 |
|---|---:|---:|---|
| 十派平均胜率 | 47%～53%；设计阶段允许 ±0.5% 统计误差 | 47.04%～53.32% | 通过 |
| 明确机制克制 | 60%～70% | 最高 67.94% | 通过 |
| 非克制对局 | 原则上不超过 60% | 需要结合触发日志判定 | 持续复验 |
| 平均战斗长度 | 12～20 回合 | 18.89 回合 | 通过 |
| 同一控制链 | 最多连续剥夺一次行动 | 最多一次 | 通过 |
| 隐藏门派倍率 | 不允许 | 无 | 通过 |

70% 是当前明确克制的设计上限，不是期望常态。装备词条、属性差、操作选择和环境机制后续都可以改变结果，因此本阶段保留 60%～70% 的清晰克制空间；超过 70% 才视为需要强制调整的红线。

单构筑极值只用于寻找陷阱配点和自动策略缺陷，不作为“所有自由配点必须等强”的目标。后续应重点检查真实玩家采用率较高的构筑，但仍不得发布官方推荐配点。

## 3. 合法构筑枚举

### 3.1 前置规则

每个门派有三个分支，每支 6 个单点天赋，共 10 点。单支投入与可选节点严格如下：

| 本系投入 | 合法选择 |
|---:|---|
| 0 | 不选本系天赋 |
| 1 | 两个第一层天赋任选其一 |
| 2 | 两个第一层天赋全部点满 |
| 3 | 两个第一层 + 两个第二层任选其一 |
| 4 | 第一层与第二层全部点满 |
| 5 | 前四个节点 + 第三层 |
| 6 | 点满本系并激活第四层终极 |

第二层必须已有本系 2 点。其他分支的投入不能解锁本系第二层；因此不存在“本系只点一个第一层、靠跨系点数选择第二层”的合法构筑。总点数必须等于 10，单支最多 6 点，整套构筑最多一个终极天赋。

该规则得到每派 75 个合法构筑。模拟器同时断言以下不变量，任一失败即停止运行：

```text
天赋节点总数 = 180
构筑总数 = 750
每个构筑总点数 = 10
任一第二层节点 => 同系两个第一层节点均已选择
终极天赋数量 <= 1
```

### 3.2 为什么不是 36 种配点

`6-3-1` 只描述三个分支的点数，不足以唯一决定构筑：投入 1 点时可在两个第一层中选择，投入 3 点时可在两个第二层中选择。v0.3 的 36 种只枚举了点数分布；v0.4 展开了节点选择后，每派实际有 75 种合法构筑。

## 4. 统一阶段模型

正式实现和模拟器应共享以下顺序。阶段只能向后推进；需要延后处理的效果进入事件队列，不能直接跳过护盾、致命保护或状态结算。

| 阶段 | 名称 | 主要内容 |
|---:|---|---|
| 0 | 战斗建立 | 载入属性、5 门主动技能、10 点天赋；校验前置；创建初始资源与入场状态。 |
| 1 | 回合开始 | 递增回合号；处理“回合开始”天赋、优先级与仍在等待的行动。 |
| 2 | 决策与宣告 | 选择技能与目标，声明标签；此时尚未支付内力，也未判定命中。 |
| 3 | 支付与冷却 | 应用消耗替换、增减耗与返还；支付内力；登记冷却和每场次数。 |
| 4 | 吟唱／反制 | 建立 `cast` 或蓄力窗口；结算打断、反咒、抢先和取消附加效果。 |
| 5 | 命中判定 | 结算必中替换、命中、闪避和后续段修正；产生命中或未命中事件。 |
| 6 | 直接伤害 | 计算威力、暴击、穿防、减伤；依次扣护盾和气血。每一伤害段独立进入本阶段。 |
| 7 | 命中后效果 | 结算吸取、恢复、标记、破甲、重伤、资源生成与资源消耗。 |
| 8 | 反应与追加 | 结算反击、追加攻击、控制和控制抵抗；追加攻击回到阶段 5，但默认不能再次生成追加攻击。 |
| 9 | 致命结算 | 结算保留 1 点气血、紧急净化、低血自动恢复与死亡；死亡后不再创建新触发。 |
| 10 | 回合结束 | 结算持续／延迟伤害、持续恢复、状态到期、自然回内和冷却递减。 |

“持续 1 回合”必须至少覆盖目标下一次相关行动或自身下一次相关受击，不能因为先后手而在未生效时直接过期。护体属于直接伤害阶段；护盾先于气血承伤；延迟伤害到期后重新进入完整的直接伤害流程。

## 5. 天赋触发事件

### 5.1 事件清单

| 事件 | 最小载荷 | 常见订阅者 |
|---|---|---|
| `BattleStarted` | 角色、构筑、初始资源 | 举盾、战斗配方 |
| `RoundStarted` | 回合号、双方快照 | 不落壁垒、资源自然恢复 |
| `SkillDeclared` | 施法者、目标、技能、标签 | 观招、反咒、绊字诀 |
| `CostCalculating` | 原消耗、资源、增减耗来源 | 抱元守一、血染战意、紫气东来 |
| `CastWindowOpened` | 吟唱类型、剩余时间 | 反咒、拨字诀、威压 |
| `BeforeHit` | 命中率、必中、段序号 | 飞针探穴、踏罡步斗、替身术 |
| `HitResolved` | 命中结果、技能标签、段序号 | 苦无试探、横扫、醉步 |
| `DamageCalculating` | 原始伤害、穿防、暴击、伤害标签 | 金刚怒目、气贯长剑、重斧专精 |
| `DamageMitigating` | 护体、招架、标签减伤 | 云手、坚守阵线、空蝉无形 |
| `ShieldChanged` | 变化前后、来源、是否击破 | 盾牌反击、代偿神佑、凯旋歌 |
| `HpChanged` | 实际变化、来源、是否溢出 | 慈航护念、峨眉心法、怜悯誓言 |

| `ResourceChanged` | 资源类型、前后值、原因 | 铜皮铁骨、伤痛为薪、初阳印记 |
| `ResourceSpent` | 资源类型、消耗量、用途 | 七星落位、剑气护身、破阵枪 |
| `ControlResolved` | 控制类型、成功、抵抗来源 | 不动根、牺牲誓言、不屈歌 |
| `ExtraAttackRequested` | 来源天赋、威力、可否再触发 | 连环不绝、天下无狗、影分身 |
| `LethalDamagePending` | 致命伤害、剩余资源 | 不坏法身、达摩渡厄、骑士不倒 |
| `DelayedEffectDue` | 原施法者、原技能、等待回合 | 初阳术、太阳审判 |
| `RoundEnded` | 回合号、状态列表 | 佛光普照、持续伤害、冷却递减 |

### 5.2 同事件内顺序

同一事件中按以下优先级结算：

1. 规则替换：必中改写、消耗替换、死亡保留等改变事件性质的效果。
2. 固定加减：威力、命中、穿防、状态层数的加减。
3. 比例修正：增伤、减伤、恢复增减；同类相加后统一设上限。
4. 状态提交：护盾、气血、资源和状态实际写入。
5. 结果触发：命中后、击破后、净化后、致命后等监听者。
6. 追加事件入队：反击、追加攻击和延迟效果，不在当前监听器中递归执行。

同优先级按“防守方替换 → 进攻方替换 → 防守方减免 → 进攻方收益 → 天赋编号”稳定排序。随机判定只读取注入的随机源；同一种子与同一输入必须得到相同结果。

### 5.3 防止无限触发

- 一个天赋对同一个来源事件默认最多响应一次；允许重复时必须写明“每段”“每回合”或冷却。
- 追加攻击默认带 `no_extra_chain`，不能再次触发追加攻击。
- 反击不是新的主动施法，不支付技能消耗，不刷新主动技能冷却。
- 资源变化事件必须携带原因；由资源变化天赋产生的资源默认不能再次触发同一资源天赋。
- 每场一次的效果在创建事件时即占用次数，不能等效果成功后才占用。
- 控制最多使目标连续损失一次行动；新控制只能刷新该次窗口，不继续排队。

## 6. 模拟模型

### 6.1 基础参数

| 项目 | 数值 |
|---|---:|
| 标准气血／攻击／防御／内力 | 1200／112／42／100 |
| 基础命中／暴击／暴击伤害 | 95%／8%／1.45 倍 |
| 普通拳脚 | 0.60 威力、0 消耗 |
| 每回合自然回内 | 2% 最大内力 |
| 最长战斗 | 40 回合 |
| 随机种子 | `20260903` |

直接伤害公式为：

```text
原始伤害 = 攻击 × 技能威力 × 暴击修正
护甲后伤害 = 原始伤害 × 100 ÷ [100 + 防御 × (1 - 穿防)]
实际伤害 = 护甲后伤害 × 标签减伤 × 护体修正
结算去向 = 先扣护盾，剩余部分再扣气血
```

自动出招只用于校准，不代表推荐玩法。它依次检查致命净化、可用绝学、生存血线、反制窗口、资源完整度、目标标签和内力；若均不满足，则使用主攻、起手或普通拳脚。

### 6.2 逐节点覆盖边界

所有 180 个节点都会影响合法构筑枚举。163 个节点已接入明确事件条件；以下 17 个节点因正式位移、材料选元素、分段命中或玩家主动选择尚未落地，暂按所在层级和触发阶段折成保守预算：

```text
七截共鸣、雪影回旋、清心诀、生生相济、见龙在田、养吾气、
寒霜塑形、强制解除、万用解毒剂、元素催化剂、挥发药剂、
追击、王者冲锋、虚实相生、以血换怒、威压、战吼
```

这些折算值只用于设计校准，不是运行时隐藏倍率。正式实现上述节点后必须删除对应折算并复跑。

## 7. v0.4 全量结果

### 7.1 样本

- 10 个门派 × 每派 75 个合法构筑 = 750 个构筑。
- 750 个构筑两两对战，共 `750 × 749 ÷ 2 = 280,875` 场。
- 每场随机先后手，平局按双方各 0.5 胜计。
- 每组门派对局聚合 5,625 个构筑组合，因此门派级克制结果比单构筑极值稳定。

### 7.2 门派平均胜率

| 门派 | 胜率 | 门派 | 胜率 |
|---|---:|---|---:|
| 少林寺 | 47.04% | 奥术学院 | 47.24% |
| 北海战团 | 47.29% | 丐帮 | 48.98% |
| 王冠骑士团 | 49.03% | 武当派 | 50.40% |
| 华山派 | 51.04% | 影之忍宗 | 52.46% |
| 太阳神殿 | 53.21% | 峨眉派 | 53.32% |

这些数值用于检查门派底座，不代表门派排名，也不构成官方构筑建议。

### 7.3 主要克制结果

| 优势方 | 被克方 | 优势方胜率 | 形成原因 |
|---|---|---:|---|
| 影之忍宗 | 奥术学院 | 67.94% | 标记终结与毒伤迫使材料和净化提前消耗，绕过单次反咒窗口。 |
| 丐帮 | 北海战团 | 66.34% | 缠兵、打断和失衡破坏连续重击及高怒终结。 |
| 峨眉派 | 丐帮 | 65.49% | 多段与封穴压缩丐帮慢速重击的完整出手机会。 |
| 峨眉派 | 奥术学院 | 65.16% | 连段不依赖吟唱，穴位控制绕过反咒姿态。 |
| 影之忍宗 | 少林寺 | 64.32% | 持续伤害与爆毒减少护体对直接伤害的收益。 |
| 太阳神殿 | 影之忍宗 | 63.65% | 净化和护盾能拆毒与暗杀标记，但仍保留忍宗的爆发窗口。 |
| 太阳神殿 | 丐帮 | 62.79% | 法术不受普通缠兵完整限制，延迟伤害可错开醉步窗口。 |
| 武当派 | 丐帮 | 61.73% | 卸力克制重击，但数值已压在 70% 上限以内。 |
| 武当派 | 王冠骑士团 | 61.48% | 借力和阵眼能利用骑枪的准备与重击标签。 |
| 太阳神殿 | 华山派 | 60.03% | 诅咒与延迟伤害迫使华山在回内和净化之间取舍。 |

### 7.4 单构筑诊断

全量枚举中的最低构筑为少林 `5-0-5`，胜率 18.29%；最高构筑为华山 `6-3-1`，胜率 72.56%。这两个值不用于定义门派强弱，原因包括：

- 自动出招没有针对每套天赋重新学习策略；主动换元素、以血换怒、阵眼时机等只能近似。
- 合法配点可以主动放弃资源出口、终极或主动技能联动，规则允许但不会自动获得补偿。
- 17 个低频节点仍是阶段预算而非完整行为。
- 每个具体构筑对每个对手只运行一次，个体结果比 5,625 场聚合的门派对局更受随机波动影响。

因此 v0.4 的通过结论限于“门派平均与机制克制近似平衡”。若要保证常用自由构筑也收敛，需要正式技能选择 AI 或玩家对战日志，并对采用率较高的构筑追加至少 1,000 场重复模拟。

## 8. 结算示例

### 8.1 第二层前置

武当 `1-3-6` 中，投入 3 点的分支必须是两个第一层加一个第二层。以下选择合法：

```text
第一层：抱元守一、气沉丹田
第二层：生生不息（纯阳护体未选）
```

只选“抱元守一”，再用其他分支的点数凑够 2 点，不能解锁“生生不息”。

### 8.2 直接伤害

标准属性下，0.85 威力的《大力金刚指》无暴击、无穿防时：

```text
112 × 0.85 × 100 ÷ (100 + 42) = 67.04
```

若目标有 8% 护体，则进入护盾前约为 `67.04 × 92% = 61.68`。护盾不足时，溢出的部分才扣气血。

### 8.3 追加攻击

峨眉拥有“连环不绝”、连势达到 3 层并用多段攻击命中时：

1. 主攻击先完成命中、穿防、护体与护盾结算。
2. 消耗 1 层连势，登记 3 回合触发间隔。
3. 创建相当于本次实际伤害 5% 的追加攻击事件。
4. 追加攻击回到命中阶段，但携带 `no_extra_chain`，不会再次触发“连环不绝”。

### 8.4 延迟伤害与净化

《初阳术》命中后创建等待 2 回合的日轮印记。印记自然到期时先创建 `DelayedEffectDue`，随后重新经过法术伤害、护体、护盾和致命保护；到期成功后才获得神谕。

若印记到期前被合法净化，则移除等待事件，不造成伤害也不生成神谕。《提前宣判》则按 75% 基础比例提前结算；点出同名天赋后提高到 85%。

### 8.5 胜率聚合

门派 A 的 75 个构筑与门派 B 的 75 个构筑形成 5,625 场。若 A 获得 3,650 胜、50 平，则：

```text
A 对 B 胜率 = (3650 + 50 × 0.5) ÷ 5625 = 65.33%
```

## 9. 后续复验要求

- 正式战斗引擎按第 4、5 节实现事件与阶段，不允许技能自行绕过统一承伤和状态流程。
- 为 180 个天赋分别编写触发、不触发、冷却、次数和前置测试。
- 优先把 17 个预算折算节点改为真实事件行为，然后重新运行全量矩阵。
- 接入装备和属性差后，重新检查十派平均、明确克制、净化覆盖率、绝学使用回合和资源溢出率。
- 有真实玩家数据后，只按采用率分层观察构筑，不发布官方构筑或推荐配点。
