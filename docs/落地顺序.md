# 落地顺序

## 眼下最紧急的不是新功能，是补窟窿

**已经有玩家 118 级，而游戏内容只做到 65 级。** 他现在待在星宿海，
收益衰减到底（0.25 倍），能打的最强的怪比他低 53 级。
**对这个玩家来说游戏已经结束了**，再做别的都是给别人做的。

所以第 0 步：**把 65→130 的内容补上**（新场景 + 新怪 + 新武功档位）。
这件事不需要任何新机制，纯配置，投入最小、见效最快。

## 分期

| 期 | 做什么 | 依赖 | 大概工作量 |
|---|---|---|---|
| **0** | 补 65→130 的怪、场景、武功档 | 无 | 小（纯配置） |
| **0.5** | **堵经济窟窿**：等级压制、装备耐久、打坐冷却、死亡代价 | 无 | 中 |
| **1** | 地图机制字段：`risk` `night` `crowd` `solo` `need` `mat` `zone` | 无 | 中（要动 idle 的 tick 和 state） |
| **2** | 场景扩充到 34 个 + 区域折叠 UI + 赶路 | 期 1 | 中（配置为主，UI 要改） |
| **3** | 日常任务 + 门派任务 + 帮贡产出 | 无（可与 1/2 并行） | 中 |
| **4** | 场景时间窗 + 门票 + 秘境 | 期 1 | 中大（要活动调度器） |
| **4a** | **禁地**（随进随出的肉鸽副本） | 期 0.5（先堵住刷怪经验） | 中大（新模块 + 一局 UI，不依赖调度器） |
| **5** | 江湖散人（机器人） | 期 2（要有地方待） | 中 |
| **6** | 攻防战 | 期 4 + 在线人数够 | 大 |
| **7** | 玩家发布的任务（悬赏／求购） | 期 3 | 中 |
| **8** | [天赋体系](talent-system.md)：技能槽改造 + 十派天赋树 | 期 0.5 | **大** |
| **9** | 海外五派 + [万国码头](worldbuilding.md) | 期 2、期 8 | 大 |

**期 0.5 为什么排这么靠前**：现在打怪净成本为零、死亡不痛、越高级升级越快，
在这个地基上加任何新玩法（日常、秘境、活动）都会被刷爆——**先堵窟窿再加水**。
详见[经济与成本](经济与成本.md)。

## 为什么是这个顺序

- **期 1 在期 2 之前**：先有机制再填内容，否则 34 个场景填出来还是一个样
- **期 3 可以并行**：日常任务不依赖地图改造，谁先做完先上
- **期 4 依赖期 1**：秘境本质是"带时间窗和门票的场景"
- **期 4a 可以比秘境更早**：禁地随进随出、一人一局，复用现有 1v1 战斗，不需要活动调度器；但必须在等级压制之后做，否则又是一条无上限刷经验的管子。详见[禁地](禁地.md)
- **期 5 在期 2 之后**：机器人得有足够多的地方可去，否则全挤在一起更假
- **期 6 最后**：人数撑不起来就是自娱自乐

**天赋体系（期 8）为什么排在后面**：它要改技能槽结构、加 180 个天赋节点、
还要重整现有五派武学，是目前所有计划里最大的一块；而且它依赖期 0.5 的经济修补
——在数值还会膨胀的地基上做构筑系统，平衡根本没法验。
天赋文档自己也写了"先实现一个中原门派和一个海外门派验证运行时模型"，这个思路对。

## 每期都要守的两条

1. **动数值前先算跟泡点的比值。** 已经踩过一次：刷怪比泡点快 858 倍，
   把核心玩法废掉了。新增任何产出前，先问"这是泡点的几倍"。
2. **提交前跑 `npm test`。** 51 项，包含两个静态检查（跨文件引用、循环依赖）。
   加了新模块记得让 `server/check.js` 也能覆盖到。

## 还没决定的事（汇总）

各文档末尾都有「待拍板」，这里汇总一份，定了就回填到对应文档：

**地图**
- 地图全部可见，还是去过才显示？
- 跨区域赶路要不要？
- 时辰用真实时间还是游戏内时间？
- `solo` 场景怎么防止长期占坑？

**任务**
- 每天 5 次 / 攒 15 次 / 凌晨 5 点刷，这组数合适吗？
- 帮贡 20~50 导致绝学攒两天，快了还是慢了？
- 要真人的任务（较技）出不出？
- 给没门派的人做衙门日常吗？

**活动**
- 秘境开几点？一天几场？
- 门票纯掉落还是日常保底？
- 副本里死了怎么处理？

**禁地**（详见[禁地](禁地.md)文末）
- 浅探收不收门票？
- 禁地给不给经验？
- 每周 4 次够不够？
- 绝境失败是「丢本层」还是「几乎全丢」？
- 进门是「2 奇物」还是「1 把临时兵器 + 2 奇物」？

**经济**
- 装备耐久做不做？（最有效的一环，但玩家要多操心一件事）
- 打坐冷却 30 秒合适吗？
- 死亡掉 5% 经验，对高等级玩家会不会太狠？
- `need` 指数从 1.75 改到 2.0 吗？改了老玩家会觉得"变慢了"
- 金疮药取消掉落吗？

**机器人**
- 明示还是不明示？
- 能不能被杀？杀了给不给经验？
- 要不要用它凑活动人数？
