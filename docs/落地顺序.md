完整首发保留 60 级、四故乡与十派。可以先把一条小流程的文档和实现做完整，再展开内容；任何先行样例都不代表缩减正式首发。

## 为什么采用 M0～M5

| 阶段 | 依赖理由 |
|---|---|
| M0 地基 | 四维、角色/装备/怪物基准、资源命令、存档和时钟影响所有内容，共同规则已按M0基线采用，先实现并验证 |
| M1 新手 | 新号首先需要故乡任务、公共日常、战斗、换装与赴洛；不能把任务引擎和序章等到最后才做 |
| M2 10～30 级 | 十派择承依赖洛阳与驻洛/外院；18/26 级学艺依赖任务和码头；《姑存》在 25 级收束，应在此期闭合 |
| M3 长期循环 | 五条线需要可积累和展示的实际内容；家园和古墓接入已经存在的材料消费、战斗与恢复合同 |
| M4 完整首发 | 补中后期地区、38/50 级学艺、全档装备、完整古墓与唯一武器；不是第一次才做洛阳和码头 |
| M5 发布 | 联验、修正、清档和恢复准备；复杂玩法在此前完成，避免上线前才第一次验证其依赖 |

材料文档中的 M1～M4 是**材料阶级**，与这里的开发里程碑无关。讨论依赖时写“材料阶 4”或“开发 M4”，不要混用。

## 必须保住的顺序

- **先统一数值，再批量生产数据。** 第 2 项已整理[数值基准](数值基准.md)与[属性合同](属性成长与叠加规则.md) v0.2，供第 3 项按同一规则填表；新系数尚待动态验证，本篇不复制第二套数值。
- **基础装备和材料消费先于扩大产出。** 家园原矿、禁地材料和图纸都必须接真实消费；高档材料渠道与普通慢速成长承诺需一起验。
- **天赋与早期技能跟十派成长同行。** 不再把天赋放到 30 级内容已经做完的“期 8”，也不把海外五派的可选身份等到“期 9”。
- **海外身份与海外地图分开。** 海外派先在洛阳成礼/学艺，中后期通过各自路线进入传承之所；主线止于码头不等于删除海外成长地图。
- **加入装备就开始联合战斗验证。** 分阶段技能、修习、天赋与装备一起验证；完整满装在 M4 闭合，M5 复核。只验精品标准装不能代表终局。
- **每期同时给 UI 和恢复路径。** 可见入口必须能执行、解释失败、退出恢复；不用最后一期补齐前几期全部界面。

## 本轮替代了哪些旧排法

原来的“期 0～9、34 景、天赋期 8、海外五派/码头期 9”仅是早期建议，不再用于本次首版排期。历史内容可从 Git 记录查阅。

这次调整的原因是十派加入、技能学习节拍和《姑存》已经提供更具体的前置关系。旧计划中的地图机制、任务、禁地、装备、家园仍按范围表保留；机器人、定时活动、攻防、玩家悬赏及共同体扩展是否首发，按范围表 D 项和既有后续分层处理，不因旧表排过日期就自动变成必做。

## 决策放在哪里

- “某玩法是否首发、后置后会断哪些依赖”记录在[首版范围表](首版范围表.md)的待决定项。
- “规则如何计算、物品是什么、任务如何判定”写回对应专题与内容表。
- “某阶段交付什么、如何验收”记录在[开发里程碑](开发里程碑.md)。

提出范围变更时，同时检查场景、任务、奖励/材料、成就/收藏和存档五类消费方。没有替代来源的必需物品、未开放的任务前置和永远达不到的收藏目标，都不能通过首发验收。
