# 任务系统

## 设计基线

**这是 v2 的任务设计，不继承 v1**（v1 只有一种随机悬赏：宰 N 只怪，一次一个，做完就没），
上线时清档。

v1 留下的唯一教训：**任务如果只有"打怪计数"一种形式，它就只是换了个说法的刷怪**，
不构成独立玩法。所以下面按"每种任务把玩家推向什么行为"来分类，而不是按奖励分。

## 一、日常任务

**目标是粘性，但不能变成打卡上班。** 三个机关保证这一点：

### ① 次数可累积

```
每天发放    5 次
攒存上限    15 次（三天量）
刷新时间    每天凌晨 5 点   ← 不是 0 点，熬夜的人还在玩，别在半夜切
```

出差三天回来一次补完，不亏。粘性几乎不减——人还是会天天来，
因为**攒满了会浪费**，这是"损失厌恶"的温和版本。

### ② 一半任务挂着就能完成

这是最要紧的一条。日常不该逼人操作：

| 任务 | 完成方式 | 性质 |
|---|---|---|
| **今日功课** | 在本门后山修行满 30 分钟 | **挂着自动完成**，回来一看已经好了 |
| **巡山** | 在指定地点宰 8 只怪 | 要点几下 |
| **献纳** | 上交 3 块精铁 | 打怪顺手就攒够 |
| **采办** | 去洛阳买一坛女儿红带回山门 | 跑一趟腿 |
| **较技** | 跟一位同门切磋一场 | 逼社交，难度看在线人数 |

每次随机出 2～3 个让玩家挑。**挑到「功课」的人今天什么都不用干**——
主动做的人快，挂机的人也不掉队。

「修行满 N 分钟」这类判定直接挂在 `server/idle.js` 的每秒 tick 上，是现成的钩子。

### ③ 不做只是慢，没有惩罚

不掉帮贡、不掉称号、不清进度、不断连击。

> **注意**：门派已从五个扩到十个（见[世界观](worldbuilding.md)），
> 门派任务的文案要按各派气质分别写——少林抄经、骑士团巡守誓约、
> 战团出海捕鲸，不能十派共用一套"巡山"。
>
> **天赋点由升级固定发放**，不经任务系统（已定）。天赋与技能是两套东西，
> 归[天赋体系](talent-system.md)管，本文不涉及。

> **等级上限 60**（已定，见[经济与成本](经济与成本.md)）。日常任务的目标数量、
> 悬赏的怪物等级都要按这个基准重算——原来按 118 级的服务器实况写的数值全部作废。

## 二、门派任务与帮贡

日常的主要奖励是**帮贡**。v1 里帮贡只能靠械斗攒，是个明显的缺口——
v2 要给它一条稳定来源。

**绝学和镇派绝技各要多少帮贡，等[天赋体系](talent-system.md)定了再填**，
不沿用 v1 的 300／600。定的时候按"每天做满日常，攒几天能换一样"来推，
而不是先定价再看要攒多久。

```
每次帮贡    20 ~ 50（按任务难度）
```

按平均 35 算：

- 40 级绝学 300 点 ≈ **9 次日常**（约两天）
- 60 级镇派 600 点 ≈ **17 次日常**（约四天）

**注意**：上限定在 60 之后，"40 级绝学、60 级镇派"正好落在中后期和满级线上，
这个节奏是合适的——绝学在冲刺阶段拿到，镇派绝技成为满级后的第一个目标。

加上械斗那条路，节奏应该不难受。**待验证：这个速度是快了还是慢了。**

### 没门派的人怎么办

门派任务要 3 级拜师后才能接。建议**衙门那边也开一条日常**
（用现有的捕头 NPC，给银子和材料而不是帮贡），入门派之前有事做，
入了之后两条都能接。

## 三、任务类型（长期）

每种对应一种不同的玩家行为：

| 类型 | 做什么 | 把玩家推向哪 |
|---|---|---|
| **讨伐** | 宰 N 只某种怪 | 特定地图 |
| **收集** | 要某种掉落物 | 跟场景的 `mat` 独有产出联动 |
| **跑腿** | 去某地找 NPC／**把东西交给某个玩家** | ← 制造真实社交 |
| **护送** | 限时赶到某地，路上遇袭 | 跟赶路机制联动 |
| **门派** | 只有本门能接 | 给帮贡，解锁绝学 |

## 四、主线：五条来自世界观的线索

[世界观第 9 节](worldbuilding.md)给每个海外门派都写了"为什么此时来中原"，
**这五条动机本身就是五条任务链**，而且它们指向同一个谜团（断潮／幽潮）：

| 门派 | 世界观给的线索 | 能长出的任务链 |
|---|---|---|
| 奥术学院 | 断潮里出现不属于火冰雷的未知力量 | 采样 → 争论它该不该被命名 → 元素／咒术／炼金三派各执一词 |
| 王冠骑士团 | 找断潮中失踪的远征队，港口偶尔出现旧盾徽 | 追查盾徽来源 → 谁在流通它 → 远征队到底遇上了什么 |
| 影之忍宗 | 有人冒用忍宗印记行刺，用来源不明的变异毒物 | 追凶 → 辨毒 → 毒物经过断潮海域 |
| 北海战团 | 追一支黑帆舰队，船员像感受不到疼痛 | 海上追踪 → 为什么不知痛 → 他们从断潮带回了什么 |
| 太阳神殿 | 大祭司看见"黑日坠海"的神谕 | 解读神谕 → 五位祭司给出互相矛盾的解释 → 谁在自我欺骗 |

**这个结构的好处**：五条线各自独立可玩，玩家跟哪派走就看哪条；
但五条线索**最终会互相印证**——这就是长线内容的天然接口，
以后要开新篇章，只需要往幽潮那个方向再推一层。

### 跨门派任务

[世界观第 10 节](worldbuilding.md)写了十派之间的张力（少林与骑士团对誓言是否要写下、
武当与奥术学院对规律能否书写、峨眉与神殿对诅咒能否治病……）。
**每一对张力都是一个任务模板**：让玩家替本门去跟对方交涉、辩论、或者合作办一件事。

这类任务的价值在于：它让玩家**接触到自己没选的那九派**，
知道江湖上还有别人，而不是只盯着自己门派的日常。

## 五、任务链

一环扣一环，有叙事。例如：

```
悦来客栈的酒钱  →  铁匠铺的旧账  →  后山的那具尸首  →  ……
                                        ↓
                              第五环解锁「无名谷」
```

**任务不只是给钱，是给"你没见过的东西"**——解锁新场景、新武功、新称号。
这才是让人愿意从挂机中站起来的真正理由。

## 六、玩家发布的任务（最有潜力）

把任务系统和社交长在一起，**内容由玩家自己生产**：

- **悬赏某人**：挂银子求人打赢他的擂台影子
- **求购**：「收玄晶三块，每块 5000」，别人做完直接成交
- 抽成同集市（一成），既是回收口又防刷

## 七、别处对任务的依赖（接口清单）

| 谁 | 依赖什么 |
|---|---|
| [家园系统](家园系统.md) | 引导任务「安家」发地契；稀有种子（雪莲等）由任务链产出；藏宝图作为任务奖励 |
| [地图系统](地图系统.md) | 出海引荐任务链解锁万国码头；隐藏场景（无名谷、魔教总坛）由任务链解锁 |
| [禁地](禁地.md) | 待确认：禁地的入场券是否由日常／任务发放 |

**注意**：家园把「安家」当成引导任务在用，禁地可能要入场券——
这两处都会占用日常任务的发放额度，**数值要一起算**，别各发各的。

## 八、数据结构草案

```js
p.daily = {
  day  : '2026-09-01',       // 上次刷新是哪天
  stock: 5,                  // 攒着的次数
  list : [ {...}, {...} ],   // 今天可选的
  doing: {...},              // 手上这个
};
```

任务定义放 `gamedata/quests.js`（新文件），写成配置：
名字、目标类型、数量范围、帮贡区间、**判定方式**（打怪计数／修行时长／
交物品／到达某地）。逻辑放 `server/social.js`，复用悬赏那套计数机制。
