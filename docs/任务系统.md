# 任务系统

> 第4项日常/周常制作入口：[日常任务与周常委托表](日常任务与周常委托表.md)。本轮28日常、2周委托及净奖公式是建议方案，未获逐项批准、未实现或实测；以下与之冲突的旧帮贡解锁口径已更正。一次性152任务仍读[任务与交互数据表](任务与交互数据表.md)。合计182任务定义（152一次＋28DQ＋2WQ），加初始化共183个reward定义，门票bonus另记；共同E/H与费用以[日常与经济方案](日常与经济方案.md)及其四份专题经济表为权威。

## 设计基线

**这是 v2 的任务设计，不继承 v1**（v1 只有一种随机悬赏：宰 N 只怪，一次一个，做完就没），
上线时清档。

v1 留下的唯一教训：**任务如果只有"打怪计数"一种形式，它就只是换了个说法的刷怪**，
不构成独立玩法。所以下面按"每种任务把玩家推向什么行为"来分类，而不是按奖励分。

## 一、日常任务

公共与十派共用每日5份授予、最多15份库存，服务端按`Asia/Shanghai`每日05:00补算。进入任务预留额度，成功领取才扣一份；进行中和已完成待领也计入库存。离线可攒三日量，已接进度跨日保留；重复点击、换入口、重连不重发。

首批8条公共题覆盖四故乡与洛阳，1～9级和永久散人始终有免费可达题；十派各2条责任题在10级成礼后开放。公共与门派奖励相同，不能把两池各做5次变成每日10次。每个题都可主动核查，或在责任点安全修行累计6分钟；批次逐份分配时长，同一段时间不复制完成15份。

净奖推荐每份`E(L)/12`经验与`H(L)/10`银两，按接取等级冻结；材料采购由委托方直结或换免费核查，不要求玩家先垫钱。普通5份与15份补做都以主动操作不超过15分钟为制作目标，实测未完成；28条逐行目标、成本和回退见[新表](日常任务与周常委托表.md)。

不做日常不掉称号、门望、关系或已得技能，不清除学习进度。战斗、真实玩家协作、特定时辰、家园扩展均不能成为唯一完成方式。有效修行需要服务端结算事件；现有`server/idle.js`的tick不等于这些判定已实现。

## 二、门派责任与周累计

门派首个责任日常沿用[十派加入任务](门派加入任务.md)第13.1节；本轮先发相同经验/银两和责任履历，不新增可兑换战力的帮贡。旧“每次20～50帮贡、40级绝学/60级镇派花300/600兑换”的算例废止。

**50门本门技能仍在10/18/26/38/50级，通过对应ZC/WX学习任务习得**，不买帮贡、不加每日完成次数前置，也不增加第六技能。天赋点仍由升级固定发放。门派声望/展示等其他用途继续按各自范围与专题评审，不能由旧帮贡例子自动批准。

永久散人与入门前角色都可做公共日常；入门后可以全部选公共题，经济奖励不打折。入门只解锁本派责任选择，不封公共成长。

周委托是累计选项：已有日常、公共修行、普通战斗或独立免费公共核查任选推进，不增加强制每日次数。推荐50级开始每周4神兵碎片、40级开始每周3陨铁；公共与门派共用各自周领奖位，资格可攒两份，进行中进度不清零。碎片实际库存须可积到24以上，与两周资格库存分开。24碎片→指定核心→60级再铸造的数量、费用与长线节奏已在[装备材料经济表](装备材料经济表.md)给出推荐账；静态参数已填写，D范围审定与动态体验仍未完成，不保证自动毕业。

## 三、任务类型（长期）

每种对应一种不同的玩家行为：

| 类型 | 做什么 | 把玩家推向哪 |
|---|---|---|
| **讨伐** | 宰 N 只某种怪 | 特定地图 |
| **收集** | 要某种掉落物 | 跟场景的 `mat` 独有产出联动 |
| **跑腿** | 去某地找 NPC／**把东西交给某个玩家** | ← 制造真实社交 |
| **护送** | 限时赶到某地，路上遇袭 | 跟赶路机制联动 |
| **门派** | 只有本门能接的责任叙事 | 与公共题同奖；正式技能仍走独立学习任务 |

## 四、主线：《姑存》

> 主线的幕章、玩家身份、四地开篇与万国码头收束见
> [主线剧情《姑存》](首发主线剧情-姑存.md)。本文仍只负责任务类型、奖励与数据结构。
> 1～25 级的等级节拍、35 个玩家任务节点、失败恢复与制作验收见
> [《姑存》主线任务设计](主线任务设计-姑存.md)。
>
> 主线任务只承载公开明线，不负责把世界观讲完。角色动机、隐藏因果和未定谜团必须按
> [设计原则第十条](原则.md)拆到装备、NPC、场景、招式与其他玩家可见文案中。

《姑存》与择承解耦。玩家可以加入任何门派，也可以保持散人身份；不入门可以让护送、救人和战斗更难，但不得因身份直接断开主线。

洛阳篇展示另外三个出生点案卷时，“当地解决者”字段读取同一公共世界中、对应出生点上一位完成该案的真实玩家角色名。玩家只有在洛阳回函正式撤销故乡处罚后，才进入该公共完成记录。姓名在当前玩家第一次阅卷时写入个人任务快照，此后不因新的完成者或角色改名而更新。若没有前序完成者，则使用主线文档规定的默认姓名。该动态姓名只进入文书正文与见证记录，不改变任务分支、奖励或证据判定。

动态姓名不延伸到万国码头裁决书；码头案始终记录当前玩家本人。

首发主线按以下内容节拍推进；等级门槛已在任务制作规格中定为故乡 1～10 级、
洛阳 10～18 级、万国码头 18～25 级：

| 阶段 | 主要内容 | 边界 |
|---|---|---|
| 四地开篇 | 玩家只亲历自己故乡的一案，替熟人排除造假、盗窃或失职嫌疑 | 不公布四案同时性，不提幕后组织 |
| 洛阳勘误 | 复核四地旧录，确证气盛之处会缓慢迁移，并承担公布真相的现实代价 | 不要求玩家重跑其他三地，不由门派给出唯一正解 |
| 万国码头 | 洛阳只核准旧港航图的年代与出处；玩家用带有日期和条件的勘误抄本重审维拉号航图案，并促成《白沙道待行附页》 | 航路是否可行由四海会馆当地复核；不出海，不进入幽潮因果，不追加下一版本钩子 |

[世界观第 8 节](worldbuilding.md)中海外五派“为什么此时来中原”的动机，仍是各自地区、门派与后续版本任务链的种子，但不在《姑存》中五线汇流，也不指向首发幽潮终局。

### 跨门派任务

[世界观第 9 节](worldbuilding.md)写了十派之间的张力（少林与骑士团对誓言是否要写下、
武当与奥术学院对规律能否书写、峨眉与神殿对诅咒能否治病……）。
**每一对张力都是一个任务模板**：让玩家替本门去跟对方交涉、辩论、或者合作办一件事。

这类任务的价值在于：它让玩家**接触到自己没选的那九派**，
知道江湖上还有别人，而不是只盯着自己门派的日常。

## 五、任务链

一环扣一环，有叙事。例如：

```
悦来客栈的酒钱  →  铁匠铺的旧账  →  后山的那具尸首  →  ……
                                        ↓
                              第五环解锁「无名谷」
```

**任务不只是给钱，是给"你没见过的东西"**——解锁新场景、新武功、新称号。
这才是让人愿意从挂机中站起来的真正理由。

### 外传之技任务

[主动技能体系第 4 节](active-skills.md)定义外传之技的技能边界、战斗归属与待定项；
本文只负责它的获得过程。每一门外传之技都必须通过自己的任务或任务链获得，
**没有统一授艺场所、公开课程或到档自动解锁**。

任务至少要交代：

- 玩家从谁手里学会，或者通过哪些线索自行复原。
- 传授者为什么破例、报恩、认可或默许这一次外传。
- 玩家做了什么换来认可，以及这次外传为何不动摇本门核心。

声望可以解锁任务的消息、引荐人或深层场景，但“声望到档”本身不是学会招式的剧情。
具体技艺的名称、效果、数量与装配方式以主动技能体系为准；本文只在场景卡和任务链中建立技艺与获得任务的对应关系。

## 六、玩家发布的任务（最有潜力）

把任务系统和社交长在一起，**内容由玩家自己生产**：

- **悬赏某人**：挂银子求人打赢他的擂台影子
- **求购**：「收玄晶三块，每块 5000」，别人做完直接成交
- 抽成同集市（一成），既是回收口又防刷

## 七、别处对任务的依赖（接口清单）

| 谁 | 依赖什么 |
|---|---|
| [家园系统](家园系统.md) | 引导任务「安家」发地契；稀有种子（雪莲等）由任务链产出；藏宝图作为任务奖励 |
| [地图系统](地图系统.md) | 《姑存》后段解锁万国行栈至万国码头；海外航线与隐藏场景（无名谷、魔教总坛）分别由后续任务链解锁 |
| [禁地](禁地.md) | 摸金令可由日常任务保底获得，但不额外占用日常次数；具体产率以[禁地](禁地.md)和经济表为准 |

**注意**：家园的「安家」是一次性引导任务，禁地的摸金令是普通奖励来源；两者都不能额外消耗日常任务次数。

已定的接口：安家是一次性引导任务，不占日常次数；摸金令可以由日常任务提供保底，但不从日常任务次数中额外扣除。家园“短工”日常在低在线时允许接 NPC 的诚实标记契约完成，获得任务奖励但不增加玩家善名，避免把真人在线人数变成任务卡点。

## 八、数据结构草案

本轮只登记内容与经济建议，不把现有单个`doing`槽当作已支持批次。第5项需分别记录：

- 服务端日/周period、已处理边界与资格库存，预留/完成待领也受库存帽约束。
- 每份日常资格的首次接取等级、奖励版本、所选定义与目标进度；取消再接不重算奖励。
- 两类周资格的原period、累计单位、已处理事件与领取状态；旧进度跨周保留。
- 采购供方直结凭据、净奖励、材料或门票入账结果，失败/重试不能复制付款或产出。

未来任务定义可落配置，具体运行文件与存档字段在实现前另定；本文没有新增`gamedata/quests.js`或服务端处理器。一次性学习/剧情、可重复日常、周委托与附加门票里程碑必须区分，不共享一个永久完成布尔值。
