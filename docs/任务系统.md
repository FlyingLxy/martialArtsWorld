# 任务系统

## 现状

只有一种：衙门悬赏（`server/social.js` 的 `newQuest`）——随机挑一种怪，
让你宰 3～6 只，一次只能接一个，做完就没了。

## 一、日常任务

**目标是粘性，但不能变成打卡上班。** 三个机关保证这一点：

### ① 次数可累积

```
每天发放    5 次
攒存上限    15 次（三天量）
刷新时间    每天凌晨 5 点   ← 不是 0 点，熬夜的人还在玩，别在半夜切
```

出差三天回来一次补完，不亏。粘性几乎不减——人还是会天天来，
因为**攒满了会浪费**，这是"损失厌恶"的温和版本。

### ② 一半任务挂着就能完成

这是最要紧的一条。日常不该逼人操作：

| 任务 | 完成方式 | 性质 |
|---|---|---|
| **今日功课** | 在本门后山修行满 30 分钟 | **挂着自动完成**，回来一看已经好了 |
| **巡山** | 在指定地点宰 8 只怪 | 要点几下 |
| **献纳** | 上交 3 块精铁 | 打怪顺手就攒够 |
| **采办** | 去洛阳买一坛女儿红带回山门 | 跑一趟腿 |
| **较技** | 跟一位同门切磋一场 | 逼社交，难度看在线人数 |

每次随机出 2～3 个让玩家挑。**挑到「功课」的人今天什么都不用干**——
主动做的人快，挂机的人也不掉队。

「修行满 N 分钟」这类判定直接挂在 `server/idle.js` 的每秒 tick 上，是现成的钩子。

### ③ 不做只是慢，没有惩罚

不掉帮贡、不掉称号、不清进度、不断连击。

> **注意**：门派已从五个扩到十个（见[世界观](worldbuilding.md)），
> 门派任务的文案要按各派气质分别写——少林抄经、骑士团巡守誓约、
> 战团出海捕鲸，不能十派共用一套"巡山"。
>
> 另外[天赋体系](talent-system.md)引入了天赋点和门派核心资源，
> **日常任务很可能是它们的主要来源**，两边的数值要一起定，别各发各的。

## 二、门派任务与帮贡

日常的主要奖励是**帮贡**，因为帮贡现在只能靠械斗攒，而绝学要 300 点、
镇派绝技要 600 点，正缺一条稳定来源。

```
每次帮贡    20 ~ 50（按任务难度）
```

按平均 35 算：

- 40 级绝学 300 点 ≈ **9 次日常**（约两天）
- 60 级镇派 600 点 ≈ **17 次日常**（约四天）

加上械斗那条路，节奏应该不难受。**待验证：这个速度是快了还是慢了。**

### 没门派的人怎么办

门派任务要 3 级拜师后才能接。建议**衙门那边也开一条日常**
（用现有的捕头 NPC，给银子和材料而不是帮贡），入门派之前有事做，
入了之后两条都能接。

## 三、任务类型（长期）

每种对应一种不同的玩家行为：

| 类型 | 做什么 | 把玩家推向哪 |
|---|---|---|
| **讨伐** | 宰 N 只某种怪 | 特定地图 |
| **收集** | 要某种掉落物 | 跟场景的 `mat` 独有产出联动 |
| **跑腿** | 去某地找 NPC／**把东西交给某个玩家** | ← 制造真实社交 |
| **护送** | 限时赶到某地，路上遇袭 | 跟赶路机制联动 |
| **门派** | 只有本门能接 | 给帮贡，解锁绝学 |

## 四、任务链

一环扣一环，有叙事。例如：

```
悦来客栈的酒钱  →  铁匠铺的旧账  →  后山的那具尸首  →  ……
                                        ↓
                              第五环解锁「无名谷」
```

**任务不只是给钱，是给"你没见过的东西"**——解锁新场景、新武功、新称号。
这才是让人愿意从挂机中站起来的真正理由。

## 五、玩家发布的任务（最有潜力）

把任务系统和社交长在一起，**内容由玩家自己生产**：

- **悬赏某人**：挂银子求人打赢他的擂台影子
- **求购**：「收玄晶三块，每块 5000」，别人做完直接成交
- 抽成同集市（一成），既是回收口又防刷

## 数据结构草案

```js
p.daily = {
  day  : '2026-09-01',       // 上次刷新是哪天
  stock: 5,                  // 攒着的次数
  list : [ {...}, {...} ],   // 今天可选的
  doing: {...},              // 手上这个
};
```

任务定义放 `gamedata/quests.js`（新文件），写成配置：
名字、目标类型、数量范围、帮贡区间、**判定方式**（打怪计数／修行时长／
交物品／到达某地）。逻辑放 `server/social.js`，复用悬赏那套计数机制。
