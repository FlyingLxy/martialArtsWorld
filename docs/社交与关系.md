# 社交与关系（人情线）

> 第5项补齐（2026-09-08，仅文档）：数值/费用与权限细则见[数据模型与接口](数据模型与接口.md)§4，原子扣发见[资源合同](资源事务与幂等合同.md)，有效在线/日界/衰减见[时钟合同](时钟与断线恢复合同.md)。下列新增参数为待评审建议，未开发、未验证；仇人扩展仍从D05决定。

这是[五条追求线](玩法与核心循环.md)里的**人情**线，
也是唯一一条**必须由别人替你完成**的线——
你不能一个人把它刷出来。

[原则第三条](原则.md)说"社交是目的，不是手段"。
这一篇是那句话的实现。

## 一、先做一个减法：不做玩家帮会

[门派](worldbuilding.md)已经是社群单位——十派各有驻地、任务、帮贡、绝学。
**在十来个人的服务器上再分玩家帮会，只会把人切得更碎**：
两个三人帮会打不起来，还让同门变成外人。

所以人情线建立在**玩家与玩家之间的关系**上，不是组织上：
师徒、结拜、交情、仇人、称呼。

> 注意区分：世界观里的"[拜师](worldbuilding.md)"是**择承入派的仪式**
> （峨眉敬茶拜师、华山登山拜师），跟本文的**玩家师徒**是两件事。
> 前者是你和门派的关系，后者是你和另一个玩家的关系。

## 二、交情：这个游戏独有的社交货币

交情是**两个玩家之间**的数值，不是个人属性。它的来源决定了它的性格：

| 来源 | 涨多少 | 为什么这样设计 |
|---|---|---|
| **同场泡点** | 每同时挂满 10 分钟 +1 | ← **这是本作独有的机制** |
| 一起打怪 | 每场 +1 | 需要真的一起 |
| 切磋 | 每场 +2（不论胜负） | 打过一场就是交情 |
| 串门（[家园](家园系统.md)） | 每有向访客→宅主每日首次，双方交情+3 | 上门是礼数；重连不再触发，同向日去重 |
| 同桌请客 | 同场双方同意，付款者20两→交情+1；无向pair每日3次，付款者每日6次 | 第5项推荐，NPC服务消费；不开放道具直送绕过绑定/市场 |
| 留言簿留言 | 已启用时每日首次 +2 | M3若只做宅名不先发留言奖励 |

**「同场泡点累积交情」是这份设计的核心。**

这个游戏的底层就是"挂在某个地方"，而聊天室的本质是"待在一起"。
两个人挂在同一处、聊着天，交情自然就涨——
**这不需要玩家做任何额外操作，它就是这个游戏本来的样子。**

对比一下：别的游戏要你专门去做"友情任务"；
这里你什么都不做，只要一起待着，关系就在长。
这正是[原则第一条](原则.md)"核心是待着"和第三条"社交是目的"的交点。

### 交情的衰减

```
两人超过7×24小时无正向互动，再每满24小时−1（第8天首次）
历史最高档0/10/30/80/200对应下限0/0/10/30/80；保存已衰减水位
```

曾达到熟识及以上的交情不会归零；仅到相识的下限为0。当前档位权限按当前值计算，历史最高档只决定衰减下限。
这也给"许久不见，上来聊两句"一个具体的理由。

### 交情档位

| 档 | 交情 | 解锁 |
|---|---:|---|
| 相识 | 10 | 上线时能看到对方在不在 |
| 熟识 | 30 | 可互相设[称呼](#五称呼)；能看对方[江湖名帖](玩法与核心循环.md)全部内容 |
| 交厚 | 80 | 可结拜；串门免逐次许可，但宅主全关/黑名单仍优先 |
| 知交 | 200 | 对方上线单独提示你；名帖上互相列名 |

**档位只解锁社交能力，不给任何属性。**
一旦交情能换战力，它立刻变成必须刷的东西（[原则第十一条](原则.md)）。

## 三、师徒

参照梦幻西游最成功的那套，但改掉它的通货膨胀问题。

| 项 | 规则 |
|---|---|
| 拜师条件 | 徒弟 ≤ 20 级，师父 ≥ 40 级 |
| 同时带徒 | 师父最多 3 人 |
| 出师条件 | 徒弟满 40 级 |
| 关系可解 | 可以，但双方都留一条中断关系记录；公开展示按建立关系时双方确认的规则 |

### 指点：精力换经验，明确计入产出

师父消耗20精力，徒弟得到20场同级普通战的XP，即`E(徒L)/12`。不同资源不能称“零和”；这是`source.mentor.guidance`登记的新增XP，使用徒弟世界每小时0.5E的同一上限，不能独立绕过产出闸门。

第5项推荐每对每日1次、师父合计3次、徒弟合计1次；师≥40、徒<40且关系active。师父发出10分钟有效指点提议，徒弟亲自接受时重验双方资格、原锁定等级/版本、师精力与徒小时余量；必须容纳整包，否则整笔不扣、不发、不卡占额度。师精力−20、徒XP与小时/日账一起提交，不转移银两、材料、装备或技能点。

其余保留能力：每日每对一次安全带游，只读参观不开放徒弟的练功、战斗、课程或任务权限；师父离开/掉线即免费回原合法地点。旧装只能走合法市场交易，D04未批准的装备或绑定装备不能通过师徒直送绕开规则。在频道替徒弟说话不构成替对方接受关系或授权付款。

### 出师：这条线最重的一笔

徒弟满 40 级出师时：

| 谁 | 得到什么 |
|---|---|
| 师父 | 永久称号（累计带出 N 人升级）· **师承树上永久记一笔** |
| 徒弟 | 永久称号（记着师父是谁）· 名帖上列出师承 |
| 双方 | 交情置`max(当前值,200)`并更新历史最高档· **进[编年史](编年史.md)** |

**经双方确认展示的师承历史永久保留，正式进度清档不重置**——
参照[成就系统](玩法与核心循环.md)里"首个"的处理。
十来个人的服务器上，"你是谁的徒弟"会被记很多年。

### 为什么师徒对这个项目特别重要

十来个朋友里，必然有人晚入坑。**师徒是唯一能让"晚来"变成优势的系统**：
新人有人带、有人陪，老玩家有了新的目标（带人出师）。
没有它，晚入坑的人只能一个人补进度，很快就走了。

## 四、结拜

| 项 | 规则 |
|---|---|
| 人数 | 2 ~ 5 人 |
| 条件 | 两两交情均达「交厚」（80） |
| 代价 | 第5项推荐每人100两、总100n；逐人同意同一名单/字号并托管自己的钱，全部合格时成立和公示 |
| 字号 | 共同取一个（如"竹林三友"），显示在**名字旁** |
| 解除 | 需全体同意，或单方"割袍"——割袍者留永久记录 |

邀请最长24小时；变更名单/字号即退原托管并清旧签名，超时未成全退，重复接受不再扣。割袍或解散不返已完成仪式费；只有未成立托管才退款。

结拜给的全是展示与社交：

- 共同字号挂在名字旁（[名望线](玩法与核心循环.md)最贵的地段）
- 成员的成就互相可见
- **共同事迹进编年史**（如"竹林三友首次通关绝境"）
- 成员上线互相提示

**办酒花钱是有意的**：它既是[银两回收口](经济与成本.md)，
也让结拜有分量——不花代价的关系不值钱。

## 五、称呼

**你可以给别人设一个称呼，而且对方看得见你怎么叫他。**

| 项 | 规则 |
|---|---|
| 条件 | 交情达「熟识」（30） |
| 长度 | ≤6个Unicode字符，纯文本 |
| 可见性 | 默认仅当事双方；对方接受后生效，不全服广播 |
| 拒绝 | 对方可以拒收某个称呼，或关闭全部称呼 |

这是个极便宜、极有趣的设计。在聊天室里，
"老张头""竹林那位""欠我三百两的"——**称呼本身就是内容**。
它会自然产生玩笑、绰号和小圈子文化。

**必须能拒绝**，否则会变成骚扰工具。

## 六、仇人簿

参照传奇的仇人机制。此节依D05非切磋PVP选入；尚未批准的送礼/销案价格不执行，不能借第5项预留命令收费。

| 项 | 规则 |
|---|---|
| 记录条件 | 在**非切磋**场合被某人击败（见 [PVP](玩法与核心循环.md)） |
| 提示 | 仇人上线时你收到一条提示 |
| 了结方式 | ① 赢回来 ② 对方赔礼（送礼达一定额度）③ 花钱销案 |
| 上限 | 同时最多 10 个仇人，满了自动挤掉最旧的 |

**仇人簿是人情线的负值部分**，但它同样制造关系——
"我跟他有旧账"和"我们是知交"一样，都是江湖上的人际网。

三条防线：
1. **切磋不记仇。** 友好比试不该产生敌意。
2. **仇人不给任何战力加成**（不做"复仇伤害 +10%"这类东西），
   否则会变成刷仇人。
3. **可以花钱销案。** 给不想纠缠的人一个出口，也是个银两回收口。

## 七、展示位

按[名望线的地价规则](玩法与核心循环.md)，人情线的露出位置：

| 展示面 | 放什么 |
|---|---|
| 聊天里的名字旁 | **结拜字号** · 师承标记（如「峨眉·某某之徒」） |
| 此地人物列表 | 与你的交情档位（相识／熟识／交厚／知交） |
| 上线提示 | 知交、结拜兄弟、师徒、仇人上线时单独提示 |
| **江湖名帖** | 交情榜 · 师承树 · 结拜成员 · 仇人簿 |
| 风云榜·人情 | 交情总和排名 · 带徒出师数排名 |
| [编年史](编年史.md) | 出师、结拜、割袍 |

**「师承树」值得单独做一个页面。** 十来个人玩几个月之后，
谁是谁的徒弟、谁带出过谁，会形成一张真实的关系图——
**那张图本身就是这个服务器的历史**。

## 八、防滥用

十来个朋友的服，恶意刷的动机不强，但机制要经得起：

| 风险 | 防法 |
|---|---|
| 小号刷交情 | 交情档位不给属性，刷了没用；同场泡点计时需双方都在线且同场 |
| 请客刷交情 | 同意、实付与交情/日次数同commit；无向pair3/付款者6每日上限 |
| 反复拜师出师 | 同一唯一域无向accountId对终身一次；角色删除/换名/反转师徒/正式进度清档均不重置 |
| 称呼骚扰 | 可拒收、可全关 |
| 刷仇人 | 仇人不给任何加成 |

## 待拍板

1. **同场泡点 10 分钟 +1 会不会太慢？** 挂一晚上八小时才 +48，
   到「知交」（200）要四晚。也许对"知交"这个词来说正合适。
2. **指点产出是否合适？** 当前推荐E/12、共用徒弟小时XP帽与双方日限；精力换XP不是零和，真实成长速度和社交负担待测。
3. **结拜上限 5 人够吗？** 十人服里 5 人结拜就是半个服务器。
   或许 3 人更有味道。
4. **仇人上线提示会不会让人不敢上线？** 或许只提示"有仇人在线"，不点名。
5. **新增社交参数评审**：请客20两、结拜每人100两、10分钟普通邀请/24小时结拜及默认双方昵称可见，是否满足朋友局体验；本轮有明确建议，不等于已经批准。
